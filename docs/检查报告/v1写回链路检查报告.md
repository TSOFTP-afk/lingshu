## 1. codebase-mapping — V1 链路调用图与模块边界 ✅ PASS

**详细报告**: `reports/01-codebase-mapping.md`

### 1.1 完整调用图

```
REST: POST /api/workspace/books/{book_id}/analysis-v1/one-shot
  └─ workspace.py:603 create_analysis_v1_one_shot_run
       ├─ ai_service.analyze_book_one_shot(...)        [novel_app/ai/book_analysis.py:242, DEPRECATED]
       └─ AnalysisPipeline.create_draft_run(...)       [novel_app/analysis/pipeline.py:64, DEPRECATED]
            └─ analysis_runs (pipeline_version="p2_entity_cards_v1")
              + analysis_cards (card_type="full_payload")

REST: POST /api/workspace/analysis/runs/{run_id}/apply
  └─ workspace.py:712 apply_analysis_run
       └─ apply_analysis_cards(...)                    [novel_app/analysis/diff_apply.py:359]
            ├─ evidence_writeback_gate(...)            [diff_apply.py]
            ├─ capture_apply_snapshot(...)             [diff_apply.py:323]
            └─ apply_book_analysis_payload(...)         [novel_app/analysis/writeback.py:29]  ← V1 写回核心
                 ├─ books:           update_book_outline_form / update_book_world_form
                 ├─ characters:      create_character / update_character_form
                 ├─ chapters:        update_chapter / create_chapter_event / delete_chapter_event
                 └─ (不写 world_entries 表)
            └─ mark_analysis_card_applied(applied_table="analysis_runs", applied_id=run_id)
            └─ create_analysis_audit_log
       └─ store.update_run_status(run_id, "applied", ...)
```

### 1.2 V1/V3 边界（关键结论）

- **V1 与 V3 写回路径完全分离**：`writeback.py`（V1）与 `v3_writeback.py`（V3）互不引用
- `apply_book_analysis_payload` **未被 V3 复用**，全局仅 3 处引用，全部属于 V1 链路
- V3 使用独立的 `writeback_v3_card`（单卡写回 + schema 白名单）
- 两者仅通过 `Database` 门面间接共享底层表操作

### 1.3 循环依赖与紧耦合

- **循环依赖**: 无（通过 `TYPE_CHECKING` 导入和函数内惰性导入规避）
- **紧耦合问题（5 项）**:
  1. `writeback.py:46` 跨模块调用 Database 私有方法 `_book_outline_volume_specs`
  2. `diff_apply.py:323` 绕过门面直接执行原生 SQL（`capture_apply_snapshot`）
  3. `apply_book_analysis_payload` 单函数 ~140 行，承担 4 表写回
  4. V1/V3 写回逻辑重复造轮子（已知技术债，V1 已标 DEPRECATED）
  5. `AIBookAnalysisMixin` 与 `SimpleAIService` 的 mixin 隐式组合

## 2. code-reviewer — V1 核心文件代码质量 ⚠️ WARN

**详细报告**: `reports/02-code-reviewer.md`

### 2.1 质量评分

| 文件 | 评分 | 说明 |
|------|:----:|------|
| `lingshu_api/routers/workspace.py`（V1 端点段） | 6/10 | 章节加载 N+1，异常信息泄露 |
| `novel_app/analysis/pipeline.py`（DEPRECATED） | 5/10 | 无运行时弃用告警，存在 dead code |
| `novel_app/analysis/diff_apply.py` | 7/10 | 绕过门面执行原生 SQL |
| `novel_app/analysis/writeback.py` | 5/10 | 无事务保护，N+1 删除+插入，函数过长 |
| **链路总体** | **5.5/10** | |

### 2.2 阻塞性问题（5 项 🔴）

1. **`writeback.py` 无事务保护** — `apply_book_analysis_payload` 依次写 4 表，每个 `database.update_*` 各自 commit，中途失败导致半写回状态无法回滚
2. **`writeback.py` N+1 删除+插入** — chapter_events 逐条 delete + 逐条 insert + 每条 commit，100 章节 × 6 事件 = 1200 次 commit
3. **`writeback.py` 函数过长** — `apply_book_analysis_payload` 140 行，圈复杂度 >15，混合 4 个职责
4. **`workspace.py` 章节加载 N+1** — L617-621 每章节一次 `asyncio.to_thread` + 一次 DB 查询
5. **`pipeline.py` DEPRECATED 无告警** — 顶部注释标注弃用但无 `DeprecationWarning`，仍被 V1 端点直接调用

### 2.3 安全验证

- ✅ 所有 DB 调用使用参数化查询，无 SQL 注入风险
- ✅ `require_login` + `check_book_owner` 双重校验正确应用
- 🟡 `workspace.py:L680-682` 将 `str(exc)` 返回客户端，存在信息泄露
- 🟡 `writeback.py:L46` 调用 `database._book_outline_volume_specs` 私有方法

## 8. 改进建议（按优先级排序）

### P0 — 紧急修复

1. **`writeback.py` 增加事务保护** — `apply_book_analysis_payload` 应在单事务内执行所有写回，失败时回滚
2. **Token 改为 hash 存储** — `auth_tokens` 表用 `token_hash` 作主键，`get_user_by_token` 按哈希查询
3. **`workspace.py` 500 错误脱敏** — `detail=str(exc)` 改为通用提示，详情仅入日志

### P1 — 高优先级

4. **V1 端点标记弃用** — 装饰器传 `deprecated=True`，响应头加 `Sunset`
5. **`writeback.py` 拆分函数** — 140 行拆为 `_writeback_book` / `_writeback_characters` / `_writeback_chapters`
6. **`writeback.py` 批量操作 chapter_events** — 用批量 INSERT 替代逐条 insert
7. **`pipeline.py` 增加运行时弃用告警** — `warnings.warn("V1 pipeline is deprecated", DeprecationWarning)`

### P2 — 中优先级

8. **V1 端点统一命名** — 所有 V1 端点统一使用 `analysis-v1/` 前缀
9. **V1 端点增加 response_model** — 用 Pydantic 模型替代 `dict[str, Any]`
10. **V1 端点增加限流** — 与 V3 一致的 rate limiting
11. **补充 V1 E2E 测试** — 本次已补充 `test_v1_writeback_bookdata_verify.py`，建议扩展为完整 E2E

### P3 — 低优先级

12. **`workspace.py` 章节加载优化** — 批量查询替代 N+1
13. **`diff_apply.py` 消除原生 SQL** — 通过 Database 门面操作
14. **`writeback.py` 消除私有方法调用** — `_book_outline_volume_specs` 改为公开接口
