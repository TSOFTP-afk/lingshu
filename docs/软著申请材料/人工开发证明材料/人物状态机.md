# 人物状态机 · 设计规范 v2

> 本模型将人物定义为一台**因果引擎**：欲望驱动行动，认知决定路径，世界施加反馈，反馈重塑人物。人物不是属性的集合，而是循环的推演。

---

## 一、三轴定义（修订版）

### 轴1：星座——欲望层（What）

**定义**：人物**想要什么、害怕什么、离不开什么**。是原始驱动力，不涉及"怎么做到"。

| 字段 | 说明 |
|------|------|
| 终极欲望 | 这个人最核心的一件事——不是目标，是执念 |
| 情感引力源 | 这个欲望从哪来？哪段经历刻下的？ |
| 关系锚点 | 谁的存在定义了这个欲望？欲望通常锚定在某个人或某段关系上 |
| 欲望极端形态 | 如果完全不设限，这个欲望会变成什么样 |
| 恐惧镜像 | 欲望的反面——最害怕发生什么 |

**稳定性**：星座是最难动摇的轴。轻度反馈不会改变欲望，只有**根本性的存在论冲击**才会导致星座偏移。

### 轴2：MBTI——认知层（How）

**定义**：人物**用什么方式追求欲望、回避恐惧**。是策略、是路径选择、是信息处理偏好。

| 字段 | 说明 |
|------|------|
| 认知倾向 | I/E（向内消化 vs 向外索取）、N/S（看全局 vs 抓细节） |
| 决策倾向 | T/F（逻辑优先 vs 价值优先）、J/P（计划执行 vs 随机应变） |
| 策略原型 | 一句话概括这个人物的行动模式（如"以最小代价换取最大确定性"） |
| 认知优势 | 这个模式最擅长什么 |
| 认知盲点 | 这个模式系统性忽略什么 |

**稳定性**：MBTI会在**每个循环中迭代**。轻中度反馈只调整策略，不改变策略原型；重度反馈可能重写策略原型。

**关键区分**：星座的"F"和MBTI的"F"不同——
- 星座谈的是**欲望的内容**："我想要卡莲活着"（这是what）
- MBTI谈的是**决策的依据**："我依据什么来选择路径"（这是how）
- 一个人可以欲望完全由情感驱动（星座F），但选择路径时极度理性（MBTI的T）——奥托正是如此

### 轴3：命理——边界层（World）

**定义**：**这个世界因为这个人是谁、做了什么，而施加给它的结构性约束和反噬**。不是"命运"的神秘主义，而是因果的铁律。

| 字段 | 说明 |
|------|------|
| 命理类型 | □ 悖论型（行动本身制造对立面）□ 惯性型（出身/阶级/身份的持续约束）□ 衰变型（不可逆的生理/资源衰减） |
| 命理内容 | 具体描述这个约束是什么 |
| 触发条件 | 什么行为或状态会激活命理反噬 |
| 反噬方向 | 反噬会动摇哪个轴（星座/MBTI/两者） |
| 反噬极限 | 如果命理完全应验，最终状态是什么 |

**稳定性**：命理是最外层的轴，人物无法单方面改变命理，只能**与命理共处**或**以极端代价改写命理的触发条件**。

## 二、价值观筛选器

欲望经认知形成策略，策略经价值观决定优先级。

| 字段 | 说明 |
|------|------|
| 根本信条 | 遇到冲突时的第一优先级（"为了X，一切都可以牺牲"） |
| 信条来源 | 这个信条是哪次经历铸成的 |
| 信条与欲望的一致性 | □ 高度一致（路径顺畅，无内耗） □ 部分矛盾（需要合理化） □ 根本冲突（长期撕裂） |
| 可牺牲项 | 信条允许被放弃的东西 |
| 不可触碰项 | 即使符合策略也绝不触碰的底线（如果有） |

## 三、循环机制

### 3.1 循环结构

```
欲望（星座）→ 策略（MBTI）→ 行动 → 世界反馈（命理）→ 人物变化
     ↑                                                        |
     └────────────────────────────────────────────────────────┘
```

### 3.2 循环分类

| 类型 | 触发条件 | 影响范围 | 记录要求 |
|------|----------|----------|----------|
| 微循环 | 日常事件、小挫折 | 仅MBTI微调（策略调整） | 一行摘要 |
| 主循环 | 关键剧情节点 | MBTI显著迭代（策略转向） | 完整记录 |
| 重循环 | 存在论级别的冲击 | 星座偏移或命理应验 | 详细记录 + 前后对比 |

### 3.3 变化规则

1. **微循环不碰星座**：日常反馈只调整策略细节，不改变欲望
2. **主循环重写MBTI**：重大反馈导致策略原型迭代，但欲望内核不变
3. **重循环重塑星座**：只有当反馈动摇了"我为什么活着"这个根本问题时，欲望本身才会偏移
4. **命理不可单方面改写**：命理的约束只能通过"改变自身状态"来绕过，不能凭意志消除

## 五、奥托·阿波卡利斯 · 状态机实例

### 一、基础信息

| 项目 | 内容 |
|------|------|
| 角色姓名 | 奥托·阿波卡利斯 |
| 角色代号/别称 | 天命主教、天命之子、第一绿者、小丑α |
| 当前阶段 | ☑ 蜕变期（《阿波卡利斯如是说》中走向终局） |
| 核心冲突简述 | 为了复活挚爱卡莲，他不择手段地统治天命500年，犯下无数罪行；最终却必须通过"杀死"自己，才能在另一个世界线中让她活下来 |

---

### 二、三轴底层结构

#### 轴1：星座——欲望层

| 字段 | 填写 |
|------|------|
| 终极欲望 | 复活卡莲·卡斯兰娜 |
| 情感引力源 | 奥托是阿波卡利斯家族最小的儿子，体弱多病，从小被家人冷漠对待。唯独卡莲认可他的才能，两人青梅竹马——她是唯一给予他温暖与肯定的人。这份被认可的体验，成了500年执念的根源 |
| 关系锚点 | 卡莲·卡斯兰娜——她是他一切欲望的原点。她活着时的认可定义了他"被需要"的感觉，她的死定义了他"不可失去"的执念 |
| 欲望极端形态 | 为了复活卡莲，不惜一切代价——谋权篡位、人体实验、制造战争、主导他人死亡。只要卡莲能复活，不在乎背负多少罪孽 |
| 恐惧镜像 | 卡莲永远死去，而他无能为力——这是他无法接受的终极事实 |

#### 轴2：MBTI——认知层

| 字段 | 填写 |
|------|------|
| 认知倾向 | **I**（向内消化——从不向任何人倾诉真实意图，500年的计划只在他自己脑中运转）、**N**（看全局——他关注的从来不是眼前，而是跨世纪的宏大布局与"复活死者"这一终极可能性） |
| 决策倾向 | **T**（逻辑优先——一切行动经过精密计算，将人视为棋子，以成本收益衡量一切）、**P**（随机应变——不拘泥于单一方案，500年间尝试了无数条技术路线，任何能用的手段都不排斥） |
| 策略原型 | 以极致理性服务极致执念——用最聪明的头脑做最疯狂的事 |
| 认知优势 | 极高的智慧与战略视野：持有第一神之键"虚空万藏"，掌握前文明科技，统治天命500年，同时推进数十条技术路线 |
| 认知盲点 | 系统性忽略"他人的内在价值"——他将所有人都视为可替换的变量，无法理解卡莲"拯救苍生"的志向，也看不到自己的行为正在制造更多像他一样失去挚爱的人 |

**INTP的四维拆解如何驱动奥托的策略**：
- **I（内倾）**→ 不寻求盟友共鸣，独自承受500年的秘密，一切计划只有自己知道
- **N（直觉）**→ 不关注当下得失，永远在思考"下一步"和"终极方案"，愿意为远期目标承受短期代价
- **T（思维）**→ 决策时不考虑他人感受，人体实验、牺牲下属在他看来只是"必要的成本"
- **P（知觉）**→ 不执着于单一方案，崩坏能路线失败就转虚数之树路线，手段永远服从目标

#### 轴3：命理——边界层

| 字段 | 填写 |
|------|------|
| 命理类型 | ☑ 悖论型 |
| 命理内容 | **爱的悖论**——他越是用尽全力去爱卡莲，就越是在践踏卡莲所珍视的一切（生命、正义、苍生）。他的"拯救"本身就是最大的"毁灭" |
| 触发条件 | 每一次以"复活卡莲"为名采取的行动，都会制造新的悲剧，让更多人经历他当年的痛苦 |
| 反噬方向 | 两者——持续制造悲剧会动摇MBTI（策略代价越来越大），终局则直接动摇星座（复活的前提是他不存在） |
| 反噬极限 | 他必须以"自我湮灭"为代价才能复活卡莲——复活后的世界里没有他 |

### 四、循环日志

#### 微循环摘要（选取代表性事件）

| 时期 | 事件 | MBTI微调 |
|------|------|----------|
| 早期 | 人体实验被女武神发现并反抗 | P微调：学会更严密地隐藏实验，将道德成本内部化 |
| 中期 | 第一神之键"虚空万藏"获取成功 | N强化：确认"前文明遗产"是可行的技术路线，增加对历史遗迹的投资 |

#### 主循环1：卡莲之死——策略原型的根本转向

| 环节 | 填写 |
|------|------|
| 触发欲望 | 拯救将被处死的卡莲 |
| 信念过滤后策略 | "为了救卡莲，什么手段都可以"——释放崩坏兽制造骚乱 |
| 具体行动 | 释放崩坏兽，引发混乱，试图趁乱救出卡莲 |
| 世界反馈 | 卡莲挣脱绞架后为保护民众与崩坏兽战斗，被奥托释放的崩坏兽杀死 |
| 反馈烈度 | **重度**——他的"拯救"直接导致了卡莲的死亡 |
| MBTI迭代 | 策略原型从"临时手段解决问题"转向"追求根本性的、不可逆的解决方案"——既然临时手段杀死了卡莲，那就去改变死亡本身 |
| 星座状态 | 未偏移——欲望从"和卡莲在一起"异化为"让卡莲活过来"，但核心（卡莲）未变 |
| 命理状态 | 首次触发——"拯救即毁灭"的悖论以最残酷的方式首次显现 |

#### 主循环2：500年统治——策略的持续迭代

| 环节 | 填写 |
|------|------|
| 触发欲望 | 复活卡莲——在任何可能的维度上 |
| 信念过滤后策略 | "控制一切变量，穷举一切路径"——成为天命主教，将整个人类文明变成他的实验场 |
| 具体行动 | 研发女武神装甲、人体实验、操纵崩坏能、追踪前文明遗产、建立全球监控体系 |
| 世界反馈 | 无数人因他而死或受害；他变成了崩坏世界中最大的恶人——正是卡莲最痛恨的那种人 |
| 反馈烈度 | 持续中重度——每一次暴行都在加重命理反噬的势能 |
| MBTI迭代 | 多次策略转向：军事路线→科技路线→崩坏能路线→前文明遗产路线→虚数之树路线。手段越来越极端，时间跨度越来越长，但目标从未改变 |
| 星座状态 | 未偏移——500年间欲望内核完全稳固 |
| 命理状态 | 持续累积——"爱的悖论"的势能在不断增大：他犯下的罪越多，复活卡莲的代价就越高；代价越高，他需要犯更多的罪 |

#### 重循环：终局——星座重塑

| 环节 | 填写 |
|------|------|
| 触发欲望 | 在穷尽一切手段后，找到复活卡莲的唯一可行路径 |
| 信念过滤后策略 | "如果我的存在本身就是卡莲无法复活的障碍，那我就消除这个障碍" |
| 具体行动 | 辞去天命主教，前往虚数之树，以自身消亡为代价，在另一条世界线中让卡莲活下来 |
| 世界反馈 | 卡莲在另一条世界线中活了下来，但奥托再也无法见到她 |
| 反馈烈度 | **存在论级**——动摇了"我为什么活着"的根本答案。他活着的意义是复活卡莲，而复活卡莲的代价是他不再活着 |
| MBTI变化 | T（思维）最终确认——以最小代价（自己一个人的消亡）换取最大收益（卡莲的复活）。500年来最理性的一次决策，也是最后一次 |
| 星座重塑 | 欲望从"复活卡莲并和她在一起"升华为"让卡莲在另一个世界幸福地活着"——即使那个世界里没有自己。这是500年来星座的第一次、也是唯一一次偏移 |
| 命理应验 | "爱的悖论"以最极端的方式完成：他让卡莲活了下来，但代价是从她的世界中彻底消失。他越是爱她，就越无法存在于她的世界里 |
| 内耗 | 无——500年来第一次完全自洽：欲望、信念、理性在"自我牺牲"这一点上达成终极统一 |

### 六、创作备注

> 他是一个纯粹的恶人，也是一个纯粹的痴情者。他的恶和她的情源于同一条根——对卡莲的爱。这种"至恶与至情的同一性"让他成为崩坏3最复杂的人物。
>
> 如果他在另一条世界线中远远地看到活着的卡莲，但卡莲不认识他——他会是什么表情？
>
> 一个为达目的不择手段、罔顾他人生命的恶人，最终的选择居然是自我牺牲。他"恶"了500年，最后却用最"善"的方式完成了执念。
