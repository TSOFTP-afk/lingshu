灵枢智能写作工作台软件 V3.0 人工开发证明与AI因素占比说明 第 4 页
第三章 核心架构与算法的人类设计决策
本章列举本软件中若干关键的人类设计决策，证明这些决策涉及深度的工程权衡、领域知识与创新思考，无法由 AI
自动生成。
3.1 五层分层架构的工程权衡
本软件采用「表现层 / API 网关层 / 业务服务层 / 分析引擎层 /
数据持久层」五层架构。该设计由开发者基于以下工程权衡独立决策：
1. 表现层与 API 层分离：考虑到多端呈现需求（创作工作台、读者书城、管理后台、灵镜管理台），必须将 API
独立为统一网关，避免 UI 层与业务层耦合。
2. 分析引擎独立成层：V3 分析引擎包含九级流水线、12
项核心算法，其复杂度远超普通业务逻辑，必须独立成层以便独立演进、独立测试。
3. 数据持久层抽象：同时支持
SQLite（业务库）、本地向量库（RAG）、本地数据目录（文件），需要统一抽象避免上层直接耦合具体存储实现。
4. 选型决策：后端选择 Python FastAPI 而非 Django/Flask，是考虑到 FastAPI 原生支持异步、类型提示、自动 OpenAPI
文档；前端选择 Vue 3 而非 React，是考虑到 Vue 3 的 Composition API + Pinia 在中型项目中的开发效率更高。
3.2 V3 九级流水线的设计创新
V3 分析引擎的九级流水线（L1→M2→M3→ID→M4→M7→M5→POST→M8）是本软件的核心创新，由开发者基于对长
篇网文创作痛点的深度理解独立设计：
1. L1 语义感知分块：12K 字窗口结合场景边界识别，解决传统按章节分块无法捕捉场景变化的痛点。
2. M3 两级共指消解：第一级规则消解（子串匹配、别名表），第二级 LLM 消解（8000
字/批送入），结合向量辅助消歧，兼顾准确性与成本。
3. ID 全局身份消解：跨章节将『称号→本名』统一映射（如『剑圣→林逸』），仅在 AI
模式下启用，体现对成本与效果的人工权衡。
4. M7 ARS 记忆分层：借鉴认知科学记忆模型，对叙事信息按 Activation/Recency/Significance
四维评分分类，这是开发者将认知科学理论工程化的创新应用。
5. M8 文章探针：不依赖被动向量检索，而是基于长期记忆主动规划、定向搜索特定文本区域验证伏笔回收与一致性
，这是本软件区别于所有同类竞品的差异化设计。
3.3 写回门禁五道校验的设计动机
写回门禁是本软件安全设计的核心，其五道校验顺序由开发者基于实际开发中遇到的数据污染问题逐步演进：
1. AI 模式判断：区分 AI 模式与规则模式，规则模式无需后续校验直接放行。
2. candidate_entities 校验：防止待人工审核的候选实体污染正式数据。
3. pending_backtrack 校验：防止回溯任务进行中写回导致状态不一致。
4. probe_manual_review 校验：防止探针人工审核项未处理即写回。
5. Schema Gate：字段白名单 + 必填校验 + 类型校验，防止 LLM 输出未知字段注入业务表。
上述五道校验顺序不可调整，体现了开发者对数据完整性的深度思考。
3.4 人物状态机三轴模型的原创性
人物状态机采用「星座（欲望层）/ MBTI（认知层）/
命理（边界层）」三轴模型，这是开发者基于对小说创作理论的深度研究独立提出的人物建模方法：
1. 星座层解决『人物想要什么』（What），是最难动摇的轴。
2. MBTI 层解决『人物如何追求欲望』（How），会在每个循环中迭代。
3. 命理层解决『世界对人物的约束』（World），是因果的铁律。
该模型区别于传统静态表单式人物卡，使人物成为『因果引擎』而非『属性集合』，是本软件在小说创作理论方面的
原创性贡献。

第六章 AI 工具在本项目中的使用边界
6.1 AI 工具的使用范围
本项目中 AI 工具的使用严格限定在以下辅助性范围：
1. 代码补全：在开发者已编写上下文基础上，AI 工具补全后续若干行代码，开发者必须审阅修改后方可采用。
2. 样板代码生成：CRUD 接口、Vue 组件模板、数据库迁移脚本等重复性较高的样板代码可由 AI
生成草稿，开发者审查调整。
3. 单元测试辅助：AI 辅助生成边界用例与测试数据，测试逻辑与断言由开发者设计。
4. 文档辅助：docstring 草稿、英文翻译、Markdown 格式整理可由 AI 辅助，文档内容与结构由开发者主导。
5. 错误诊断：开发者遇到编译或运行错误时，AI 工具可辅助定位原因，修复方案由开发者决策。
6.2 AI 工具的禁止范围
本项目中以下内容严禁使用 AI 自动生成，必须由人类开发者独立完成：
1. 核心算法设计与实现：V3 分析引擎 12 项核心算法的设计与编码。
2. 系统架构决策：分层架构、模块边界、技术选型。
