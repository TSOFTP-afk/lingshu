# 写回卡片生成层 — 计划

## 当前问题

分析卡片直接写回业务表时，内容质量参差不齐：
- 人物卡 `profile_text` 是原始 fact 的机械拼接，缺乏可读性
- 世界卡 `content_text` 是片段式的，没有结构化
- 没有利用已有的业务表数据做增量补充

## 新增层级

```
当前: 卡片 → SchemaGate → 写回
计划: 卡片 → SchemaGate → 🆕写回卡片生成(LLM) → 写回
```

## 职责

在 schema gate 通过后、实际写表前，使用 LLM 将卡片 facts + 已有业务数据精炼为目标格式。

## 输入

| 输入 | 说明 |
|------|------|
| `card.payload` | 卡片摘要、facts 列表 |
| `existing_business_data` | 同名角色/条目的当前 profile/content（如有） |
| `writeback_target` | character / world_entry / book |
| `novel_context` | 书名、章节数等元信息 |

## 三种目标的 LLM 生成指令

### 1. character → 人物简介

输入：角色名 / facts / 现有 profile

输出：
```json
{
  "name": "古月方源",
  "role": "主角·蛊修",
  "profile_text": "古月方源，古月山寨方之一脉的遗孤。拥有丙等资质却凭智谋与隐忍..."
}
```

要求：
- 整合 facts 为连贯的叙事性简介（1-3 句）
- 推断 role（主角/配角/反派/路人）
- 不与已有 profile 重复

### 2. world_entry → 世界观条目

输入：条目名 / category / facts / 现有 content

输出：
```json
{
  "name": "青茅山",
  "category": "location",
  "content_text": "青茅山位于...是古月山寨的所在地。山间有...属于..."
}
```

要求：
- 整合 facts 为结构化描述
- 保持 category 语义（地点→地理 + 背景，概念→定义 + 规则）
- 追加到已有 content 末尾而非替换

### 3. book → 书籍大纲/世界观

输入：outline/world facts / 现有 outline_text / world_text

输出：
```json
{
  "outline_text": "第一幕：方源在古月山寨的开窍大典中...",
  "world_text": "斗气大陆以强者为尊。蛊师分为九转...青茅山、古月山寨为初始场景。"
}
```

要求：
- outline_text：按章节时间线组织伏笔/关键事件
- world_text：合并 world_rule 类 facts 为成段设定说明
- 追加到已有内容末尾

## 实现步骤

| 步骤 | 内容 | 文件 |
|------|------|------|
| 1 | 新增 `novel_app/analysis/writeback_card_generator.py` | 模块入口 |
| 2 | 定义 `WritebackCardGenerator` 类 + 三种目标的 LLM prompt | prompt 模板 |
| 3 | 在 `v3_writeback.py` 的 `writeback_v3_card()` 中插入调用 | 集成点 |
| 4 | 前端 `writebackCard()` 返回预览，让用户确认后再写 | 可选 UX 优化 |

## 耗时预估

| 步骤 | 量级 |
|------|------|
| 1-2 (模块+prompt) | ~150 行 |
| 3 (集成) | ~10 行改动 |
| 4 (预览) | ~50 行前端 |

## 架构影响

```
管道编排层 pipeline_v3
  M5 卡片生成 (CardCoordinator)
    └── card_generators_v3.py (规则生成)
    └── card_post_processor.py (LLM 后处理)
         ▼
写回引擎 v3_writeback
  Schema Gate
    └── 🆕 WritebackCardGenerator (LLM 精炼)
         ├── _generate_character() → 人物简介
         ├── _generate_world_entry() → 世界观条目
         └── _generate_book() → 大纲/世界观
              ▼
  _writeback_character/world_entry/book → 业务表
```
