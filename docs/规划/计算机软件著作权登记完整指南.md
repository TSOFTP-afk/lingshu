## 二、什么是计算机软件

计算机软件是指**计算机程序及其有关文档**：

- **计算机程序**：能由计算机等具有信息处理能力的装置执行的代码化指令序列，或被自动转换成代码化指令序列的符号化语句序列。同一程序的源程序和目标程序为同一作品。
- **文档**：描述程序内容、组成、设计、功能规格、开发情况、测试结果及使用方法的文字资料和图表，如程序设计说明书、流程图、用户手册等。

### 保护期限

| 著作权人类型 | 保护期限 |
|-------------|---------|
| 自然人 | 终生 + 死亡后 50 年（截止第 50 年的 12 月 31 日） |
| 合作开发软件（自然人） | 最后死亡的自然人死后第 50 年的 12 月 31 日 |
| 法人 / 非法人组织 | 首次发表后 50 年（自开发完成之日起 50 年内未发表的，不再保护） |

### 保护范围

软件著作权保护的是**程序及其文档的表达形式**，不延及开发软件所用的思想、处理过程、操作方法或数学概念。

## 三、办理流程（六步走）

```
账号注册 → 实名认证 → 填报提交 → 登记机构受理 → 登记机构审查 → 取得登记证书
```

### 步骤 1：账号注册

进入中国版权保护中心官网（https://www.ccopyright.com.cn）进行账号注册。

### 步骤 2：实名认证

注册成功后，在办理软件版权登记业务之前，按指引完成实名认证。

### 步骤 3：填报提交

实名认证通过后，选择"计算机软件著作权登记"业务，在线填报申请信息并上传申请材料（PDF格式），确认无误后提交。

### 步骤 4：登记机构受理

- 申请材料符合要求的，**予以受理**
- 申请材料存在问题的，发出补正通知书，需在 **30日内** 提交补正，逾期视为撤回
- 以下情况**不予受理**：
  - 软件被查封
  - 重复申请
  - 材料不齐全（如：申请确认签章页无签章、未上传正确的鉴别材料等）

### 步骤 5：登记机构审查

自受理日起 **60日内** 完成审查：
- 符合规定的，予以登记
- 不符合规定的，发出补正，30日内补正；逾期视为撤回
- 符合不予登记情形的，不予登记

### 步骤 6：取得登记证书

登记完成后，登录官网用户中心下载**软件版权登记电子证书**（PDF格式，含"计算机软件著作权登记专用章"电子签章）。

**验签方式**：
- **本地验签**：用 WPS 等 PDF 阅读器打开证书，点击印章图片，在签名属性中查看"自应用本签名以来，文档未被修改"
- **在线验签**：使用第三方平台上传 PDF 文件验证

## 四、所需申请文件清单

### 4.1 软件著作权登记申请表

在线填报，然后在线打印**申请确认签章页**（不得擅自更改内容、格式和打印比例），签章后上传扫描件（PDF格式）。

### 4.2 软件鉴别材料（核心材料）

#### 4.2.1 一般交存

| 材料 | 要求 |
|------|------|
| **源程序** | 连续的前 30 页 + 连续的后 30 页 |
| **文档（任选一种）** | 连续的前 30 页 + 连续的后 30 页 |
| 总页数不足 60 页 | 提交整个源程序和文档 |
| 程序每页 | **不少于 50 行** |
| 文档每页 | **不少于 30 行** |
| 页眉 | 标注软件名称、版本号（与申请表一致） |
| 页脚/右上角 | 标注页码（源程序从正文第 1 页编到第 60 页，文档从目录开始编） |

文档类型可包括：用户手册、设计说明书、流程图等任选一种。

#### 4.2.2 例外交存（含商业秘密时适用）

选择以下方式之一：
- a. 源程序前、后各 30 页，机密部分用黑色宽斜线覆盖，覆盖部分不得超过 50%
- b. 源程序连续前 10 页 + 任何部分连续的 50 页
- c. 目标程序前、后各 30 页 + 源程序任何部分连续 20 页

### 4.3 身份证明文件

| 申请人类型 | 所需文件 |
|-----------|---------|
| **企业法人** | 营业执照副本或统一社会信用代码证书（照片/扫描件） |
| **事业单位法人** | 事业单位法人证书副本或统一社会信用代码证书（照片/扫描件） |
| **机关法人** | 机关法人证书副本或统一社会信用代码证书（照片/扫描件） |
| **社团法人** | 社团法人登记证书或统一社会信用代码证书（照片/扫描件） |
| **民办非企业单位** | 民办非企业单位登记证书（照片/扫描件） |
| **非法人组织** | 工商或民政部门出具的身份证明文件（照片/扫描件） |
| **法人分支机构** | 法人书面同意声明或上级法人书面授权文件 |
| **外国自然人** | 护照 + 中文翻译件（翻译者签章） |
| **外国机构**（公约成员国） | 有效身份证明 + 该国附加证明书 |
| **外国机构**（非公约成员国） | 有效身份证明 + 中国驻当地使领馆认证（或当地公证） |
| **自然人（个人）** | 身份证（照片/扫描件） |

### 4.4 权利归属证明文件

| 开发方式 | 所需文件 |
|---------|---------|
| **独立开发** | 无需额外证明 |
| **委托开发** | 委托开发合同（照片/扫描件） |
| **合作开发** | 合作开发合同（照片/扫描件） |
| **下达任务开发** | 国家机关项目任务书或合同（照片/扫描件） |
| **修改他人软件** | 原著作权人许可证明（照片/扫描件） |
| **受让取得** | 软件著作权转让合同/协议（照片/扫描件） |
| **继承取得** | 被继承人死亡证明、有效遗嘱、关系证明、继承人身份证明、法院法律文书 |
| **承受取得**（法人变更） | 股东会/董事会决议、企业合并协议、清算报告、企业注销证明等 |
| **继受取得（已有登记证书）** | 需将原登记证书原件邮寄至版权中心 |

## 五、申请表填写说明（逐项）

### 5.1 软件基本信息

| 字段 | 说明 |
|------|------|
| **软件全称** | 简短明确、针对性强；不得违反宪法和法律；不得违背公序良俗；所有材料中保持一致 |
| **软件简称** | 简化名称；无简称留空，不填"无"；不得与全称完全相同 |
| **版本号** | 规范填写，如 `V1.0` 或 `1.0`；证书上以申请表填报为准；鉴别材料页眉版本号应与申请表一致 |
| **软件作品说明** | 原创软件 / 修改软件；修改软件需填修改说明和原登记号 |
| **开发完成日期** | 软件全部固定在某种有形载体上的日期 |
| **发表状态** | 已发表：填写首次发表日期和发表地点；未发表：选未发表 |
| **开发方式** | 单独开发 / 合作开发 / 委托开发 / 下达任务开发 |

### 5.2 著作权人

- 姓名或名称、类别（自然人/法人/非法人组织/其他）、证件类型、证件号码、国籍、省份/城市

### 5.3 权利说明

| 字段 | 选项 |
|------|------|
| **权利取得方式** | 原始取得 / 继受取得（受让/继承/承受） |
| **权利范围** | 全部权利 / 部分权利（需注明具体权项） |

### 5.4 软件鉴别材料

- 一般交存或例外交存
- 源程序页数、文档页数

### 5.5 软件功能和技术特点

| 字段 | 说明 |
|------|------|
| **硬件环境** | 开发和运行软件的计算机硬件和专用设备 |
| **软件环境** | 操作系统、支持软件的名称及版本号 |
| **编程语言** | 全部编程语言 |
| **源程序量（行数）** | 源程序总行数或总条数 |
| **主要功能和技术特点** | 开发目的、面向领域/行业、主要功能、技术特点（精简、完整） |

### 5.6 其他

| 字段 | 说明 |
|------|------|
| **申请办理方式** | 著作权人自行办理 / 代理人办理 |
| **申请人** | 著作权人；多著作权人的，为其中之一 |
| **代理人** | 委托代理的范围、权限和授权期限 |
| **申请人签章** | 自然人签名或加盖人名章；机构加盖公章（鲜章） |
| **证书领取** | 登录官网用户中心下载电子证书 |

## 六、常见问题解答（FAQ）

### Q1：只有登记后才享有版权吗？
**不。** 软件开发完成后版权自动产生，不论是否登记都享有版权。但登记后可以获得登记证书，在诉讼中减轻举证责任，还可用于企业减免税收。

### Q2：可以以个人名义申请登记吗？
**可以。** 非职务开发行为的独立开发完成的自然人，或通过合同约定、继承、受让取得著作权的自然人，均可以个人名义申请。

### Q3：软件名称可以和已登记的软件重名吗？
**可以。** 只要是独立开发享有著作权的软件，软件名称可以相同或相似。

### Q4：合作开发的软件由谁进行登记？
全体著作权人协商确定一名著作权人作为代表办理，由该代表签章。协商不一致的，任何著作权人均可在不损害其他著作权人利益的前提下申请登记，但须注明其他著作权人。

### Q5：升级版本需要重新登记吗？
修改后形成在功能或性能方面有**重要改进**的升级软件，申请人如有需要，可以再申请登记。

### Q6：可以在当地版权部门办理吗？
**不可以。** 中国版权保护中心是国家版权局认定的**唯一**软件登记机构，目前除北京设有代办机构外，其他各地均需在版权中心进行软件登记。

### Q7：是否必须委托代理人？
**不必须。** 可以自行办理，也可以委托代理人办理。

### Q8：申请中能否撤回？
在申请批准之前，可以随时请求撤回。

### Q9：如何界定职务开发软件？
自然人在单位任职期间，满足以下条件之一的为职务开发，著作权归单位：
- 针对本职工作中明确指定的开发目标所开发的软件
- 开发的软件是从事本职工作活动所预见/自然的结果
- 主要使用了单位的资金、专用设备、未公开的专门信息等物质技术条件，并由单位承担责任

### Q10：委托开发的著作权归谁？
由委托人与受托人签订书面合同约定；**无约定或约定不明的，著作权归受托人（实际开发者）**。

### Q11：算法软件可以登记吗？
算法本身是数学方法不受版权保护，但**用计算机语言实现的算法表达形式**可以登记。

### Q12：游戏可以登记吗？
游戏引擎（程序代码）可以申请软件著作权登记；游戏中动漫、视频、图片等属于其他作品，不能进行软件著作权登记。

### Q13：软件相似是否等于侵权？
因供选用的表达方式有限而与已存在软件相似的，不构成侵权。

### Q14：鉴别材料必须有页眉页脚吗？
**必须。** 页眉标注软件名称和版本号（与申请表一致），右上角标注页码（源程序正文第1页到第60页，文档从目录第1页到第60页）。

### Q15：补正期限是多久？
自发出补正通知之日起 **30日** 内补正，逾期视为撤回申请。

## 八、针对灵枢项目的实操建议

### 8.1 登记策略

| 项目 | 建议 |
|------|------|
| **申请人类型** | 自然人（个人） |
| **开发方式** | 独立开发 |
| **权利取得方式** | 原始取得 |
| **权利范围** | 全部权利 |

### 8.2 可登记的子软件

灵枢项目包含多个相对独立的子模块，建议考虑分别登记：

| 序号 | 建议登记名称 | 版本号 | 说明 |
|------|-------------|--------|------|
| 1 | 灵枢AI长篇写作工作台 | V3.0 | 主程序（Vue3 + FastAPI + Electron） |
| 2 | 灵枢V3分析引擎系统 | V1.0 | 核心分析管线（语义分块、共指消解、事实抽取等） |
| 3 | 灵枢ARS记忆分层系统 | V1.0 | 四维记忆评分 + 滑动窗口管理 |
| 4 | 灵枢文章探针一致性验证系统 | V1.0 | 探针规划与执行 |

### 8.3 鉴别材料准备要点

#### 源程序准备

- 从 `novel_app/analysis/` 核心模块选取关键代码（共指消解、事实抽取、记忆分类等核心算法）
- 确保每页不少于 50 行
- 页眉标注：`灵枢AI长篇写作工作台 V3.0`
- 取前 30 页 + 后 30 页

#### 文档准备

- 已有材料：`docs/软件设计说明书.md`、`docs/核心算法汇编.md`、`docs/架构/V3全链路架构图.md`
- 将这些文档整理为一份完整的《软件用户手册》或《技术设计说明书》
- 确保每页不少于 30 行

### 8.4 时间规划

| 阶段 | 预估时间 | 说明 |
|------|---------|------|
| 准备材料 | 1-2 周 | 整理源程序、编写文档、排版 |
| 账号注册 + 实名认证 | 1-3 个工作日 | 需身份证照片 |
| 在线填报 + 提交 | 1 天 | |
| 受理 | 1-2 周 | |
| 审查 | 60 日内 | 可能有补正流程 |
| **总计** | **约 2-3 个月** | 建议尽早启动 |

### 8.5 注意事项

1. **所有材料保持一致**：软件全称、版本号在所有申请表和鉴别材料中必须完全一致
2. **PDF 格式**：所有上传文件为 PDF 格式，照片应清晰、平铺、无反光、无遮挡
3. **签章页必须是鲜章**：申请确认签章页在线打印后签字或盖章，不得擅自更改
4. **留存备份**：所有申请文件自行留存一份，便于补正时保持一致
5. **通知在站内信**：审核中的各类通知（如补正通知书）通过官网用户中心消息中心发送，注意及时查收
