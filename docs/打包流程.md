# 灵枢打包流程

状态：当前流程文档，适用于 Windows / PowerShell / Electron + Vue 全栈版 (v2.0+)。

> v2.0 起，打包方式从 PyInstaller + C# Launcher 迁移至 **Electron Builder + Vite**。

## 打包入口

### PC 端（Electron 桌面壳）

```powershell
powershell -ExecutionPolicy Bypass -File .\build_electron.ps1 -Version "v2.0-preview" -ProductName "灵枢"
```

或使用快捷脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\build_pc_v2_preview.ps1
```

用途：先构建 `lingshu-app/` Vue 前端（Vite production build），再使用 electron-builder 打包为 NSIS 安装包。

### 桌面端 + Web 书城

```powershell
powershell -ExecutionPolicy Bypass -File .\build_v2_preview.ps1
```

用途：先构建 `web/` 书城 → 打包为 `lingshu-web-v2.0-preview.zip`，再构建 Electron 桌面端。

### 打包流程详解

`build_electron.ps1` 执行以下步骤：

| 步骤 | 操作 | 说明 |
|------|------|------|
| [1/4] | `npm run build` in `lingshu-app/` | Vue 前端生产构建（支持缓存复用） |
| [2/4] | 检查 `electron/node_modules/` | 自动 `npm install` 缺失依赖 |
| [3/4] | `npx electron-builder --win --x64` | NSIS 安装包打包（支持缓存复用） |
| [4/4] | 验证 + 重命名 + SHA256 | 将产物重命名为标准名称 |

### 前端构建缓存

`build_electron.ps1` 在 `lingshu-app/dist/.build-hash` 记录源文件哈希。若源代码未变更，跳过重复构建。

### Electron 打包缓存

`build_electron.ps1` 在 `release/electron-cache/<Version>.marker` 记录打包状态。若同名版本已有产物，跳过重复打包。

## 输出位置

- 桌面端安装包：`release/灵枢-v2.0-preview.exe`
- Web 静态包：`release/lingshu-web-v2.0-preview.zip`
- 打包缓存标记：`release/electron-cache/`

## 打包前检查

```powershell
# Python 后端检查
python -m compileall lingshu_api
python -c "from lingshu_api.main import app; print(f'OK: {len(app.routes)} routes')"

# 前端构建验证
npm --prefix lingshu-app run build
```

## 产物命名规则

| 参数 | 默认值 | 影响 |
|------|--------|------|
| `-Version` | `v2.0-preview` | exe 文件名、NSIS 安装包版本号、缓存标记 |
| `-ProductName` | `灵枢` | exe 文件名、安装向导标题 |

默认产物：`灵枢-v2.0-preview.exe`

## 版本更新清单

1. 更新 `CHANGELOG.md` 中的版本记录。
2. 若依赖变更，更新 `lingshu-app/package.json` 与 `electron/package.json`。
3. 若后端依赖变更，更新 `requirements.txt` 与 `requirements.lock`。
4. 打包后记录 exe/zip 的文件大小与 SHA256 到发布说明。
5. 新打包入口脚本：`build_electron.ps1`（主要），`build_pc_v2_preview.ps1` / `build_v2_preview.ps1`（快捷包装器）。

## 维护注意

- `build_electron.ps1` 为 UTF-8 with BOM 编码，避免 PowerShell 5.1 中文乱码。
- `packaging/app_icon.ico` 被 electron-builder 自动引用为安装包图标。
- `release/electron-cache/` 是打包缓存，加速重复构建；`release/` 下的 `.exe` 产物不在 Git 跟踪中。
- `lingshu-app/dist/` 是前端构建缓存，`electron/node_modules/` 是 Electron 依赖，均已加入 `.gitignore`。
- 旧版 PyInstaller 脚本 `packaging/build_first_exe_fast.ps1` 保留但不再维护。
