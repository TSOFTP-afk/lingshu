# 身份焦虑共鸣法

## 技能ID
`SKILL-026`

## 技能名称
写主角在某个时刻忽然意识到"自己不属于这里"或"自己不是自己以为的那个人"——精准戳中当代读者普遍的身份焦虑

## 触发场景
- 主角处于身份转换阶段（毕业/跳槽/离婚/穿越后醒来的第一天）
- 需要写一段让读者"这就是在说我"的内心戏
- 穿越/重生文中主角对"原身"身份的认知撕裂

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 身份落差类型 | string | 是 | 阶层跌落/格格不入/伪装被揭穿/不配得感/不知道自己是谁 |
| 触发场景 | string | 是 | 什么情境触发了这种焦虑——一个热闹的聚会/一个人待在出租屋/父母打来的电话 |
| 角色的隐藏自我 | string | 是 | 角色内心真正觉得自己是什么样的人（与外界的期待相反） |
| 收尾方向 | string | 否 | 接受/逃离/麻木/自嘲，默认自嘲然后继续走 |

## 执行步骤

### 步骤1：写"正常世界"的热闹——从外部视角（占25%）
**操作**：先写周围的人在做什么、说什么——聚会上的笑声、群聊里的表情包、朋友圈里的旅行照片。写他们"看起来都很好"。
**要点**：周围人的热闹必须写得足够真实——让读者也觉得"他们确实过得不错"。因为这种"别人看起来都很好"才是焦虑的真正来源。
**反例**：把周围人都写成肤浅的——那样主角的焦虑就没有说服力了——"一群傻子不理我"不是焦虑，"一群很好的人但我不属于他们"才是。

### 步骤2：主角的"抽离瞬间"（占30%）
**操作**：主角忽然从热闹中抽离出来——不是物理离开，是精神上"飘起来了"，像在看一部电影，而自己不是电影里的角色。
**要点**：抽离的触发点越小越好——杯子碰撞的声音、有人叫了另一个人的名字但不是叫他、手机屏幕亮了一下但只是天气预报推送。
**反例**：抽离的原因太重大——"因为想起了十年前被抛弃的经历"——太戏剧化，反而失真。

### 步骤3：内心的真相——"我到底是什么"（占30%）
**操作**：主角在抽离状态下对自己说了一段话（内心独白）。这段话必须是未经修饰的、有瑕疵的、甚至有点难堪的——不美化自己。
**要点**：
- 这段话不能是"总结陈词"——是碎片式的、跳跃的、反复推翻自己的
- 必须包含一个"只有自己知道的秘密"——不是对别人隐瞒的，是连自己都不敢正面承认的
**反例**：内心独白像一篇小作文——太工整就是假的。

### 步骤4：回到现实——"假装无事发生"（占15%）
**操作**：主角重新"落回"现实。有人跟他说了一句话，他应了一声。一切照旧。但读者知道——刚才那几秒里发生了什么。
**要点**：最后一句必须回到一个具体的日常动作——端起已经凉了的咖啡喝了一口/把手机翻过来屏幕朝下扣在桌上/鞋带松了，蹲下去系鞋带的时候才发现手指在抖。用动作封住情绪。
**反例**：抽离后主角做出重大决定——"从今天起我要改变"——太轻易了。现实是：焦虑过后继续过日子。

## 完整示例

**输入**：
```
身份落差类型：伪装——主角在顶级的投行工作，所有人都以为他属于这里，只有他自己知道他是从小县城考出来的，连刀叉从外往里用还是从里往外用都是入职前三天在百度上学的
触发场景：公司年会，在五星级酒店，所有人端着香槟举杯
角色的隐藏自我："我觉得自己是个赝品。迟早有人会发现。"
收尾方向：自嘲，然后继续走
```

**输出**：
```
【正常世界的热闹】
年会第十七个环节——某个VP在台上讲今年的业绩，背景墙上的PPT翻到一页柱状图，蓝色的柱子比红色的高出一大截。去年红色比蓝色高。今年反过来了。台下响起一片掌声——不是真的在庆祝，是那种年会里约定俗成的、均匀的、持续恰好三秒的鼓掌。坐在江辞旁边的同事凑过来低声说："你部门的数据。牛。"江辞笑了一下。他知道这个笑应该露出几颗牙——入职培训发的那本《职场礼仪》里其实没有这一条。入职培训没发任何书。他只有百度。

他从侍应生的托盘里拿起一杯香槟——从右往左拿的。不知道对不对。旁边的人都在用左手端杯。他不动声色换到左手。杯底的香槟晃了一下。

【抽离瞬间】
台上VP的声音还在继续。但江辞忽然听不清他在说什么了——不是走神。是这些声音忽然离他远了一些，像隔了一层玻璃。他看着自己的手——左手端着一杯香槟，指节修长，指甲修剪得整整齐齐。这双手是他在大学宿舍里一片一片剪出来的——他同宿舍的兄弟会用指甲钳，他以前只用剪刀。剪刀剪得不平整，会挂毛衣。刚入学那年冬天他所有的毛衣袖口都是毛边。后来他买了一把指甲钳。二十块。在超市日用品货架的最底下一层。

没有人教过他日用品应该在哪一层买。没有人教过他年会穿西装应该解开几颗扣子——他今天早上站在酒店洗手间的镜子前，扣了又解，解了又扣，反复试了三遍。隔壁隔间有人进来，他立刻装作在洗手。水龙头开了很久。不是因为手脏。

【内心的真相】
杯沿印出他嘴唇的形状。他忽然想——如果这杯香槟不是从侍应生托盘里拿的，是从小卖部门口的冰柜里自己掏钱买的，他现在会在哪里。他会在出租屋的阳台上对着晾衣架上的秋裤抽一根烟。他会在小县城家里的客厅看他妈用毛线织他那件袖口磨破了的旧毛衣。他会用剪刀剪指甲。他不会去想——"我配站在这里吗"。他配。他比这间屋子里百分之八十的人都配。他的部门数据就是他那根蓝色的柱子。但是"配"和"感到自己配"之间隔的不是实力。是他百度上那三百多条搜索记录——"西餐刀叉顺序""年会西装扣子""香槟杯端法"——每一条都是一个他用脚趾抠出来的阶梯，他从底层一级一级爬上来，但每级阶梯上都刻着同一个字：装。

他装得很好。好到他妈在视频电话里说"我儿子出息了"的时候，他不敢让镜头转到自己的书桌上——书桌上摊着一本翻到第143页的《葡萄酒品鉴入门》。他喝不出赤霞珠和梅洛的区别。年会餐前酒他每次都点"和旁边人一样的"。

【回到现实】
"江辞。"VP在台上叫他的名字。他抬起头。VP举着杯对他笑，"今年的销冠，说两句。"

江辞站起来。他想——站起来的时候扣子应该是解开的还是扣上的——算了。他端着那杯不知道什么年份的香槟，对着全场笑了一下。这回他没数应该露几颗牙。他只是说——"谢谢VP。其实我更喜欢喝冰红茶。"

全场笑了。笑声不再是那三秒均匀的、年会约定俗成的笑。有人在拍桌子，有人举杯碰了一下。侍应生端来一盘新的香槟——江辞从左边拿起一杯，手指很稳。不是因为学会了——是懒得装了。

他坐下的时候，旁边的同事凑过来低声说："刚才那句笑死我了。你怎么想出来的。"

江辞喝了一口香槟。他没说是真的。
```
