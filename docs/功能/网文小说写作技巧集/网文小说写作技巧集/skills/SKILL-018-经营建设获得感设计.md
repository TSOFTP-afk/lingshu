# 经营建设获得感设计

## 技能ID
`SKILL-018`

## 技能名称
设计"主角从零建设→资源累积→抵御外部冲击→据点成长"的积累型爽点，满足读者对"确定性增长"的心理需求

## 触发场景
- 种田文/基建文/领地经营/末世基地建设
- 需要"仓库里每一袋粮食都看得到"的累积快感
- 读者对"一次性爆发的爽感"疲劳，需要"可持续的满足感"

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 建设目标 | string | 是 | 建什么——基地/村庄/商铺/宗门 |
| 初始状态 | string | 是 | 起点有多"穷"——越穷后来的成就感越强 |
| 资源清单 | string | 是 | 每次建设新增了什么资源（必须具体量化） |
| 外部威胁 | string | 是 | 什么外部事件验证了建设成果的有效性 |
| 可感知的成长 | string | 是 | 怎么让读者"看见"进步——数字/对比/新功能解锁 |

## 执行步骤

### 步骤1：初始的"匮乏感"——具体化贫穷（占20%）
**操作**：列出3-5个具体数字定义初始状态。"穷"不是形容词——是一串让人看了就觉得"这也太难了"的数字。
**要点**：用精确数字而非模糊形容词。不说"很穷"，说"剩半袋米、十七枚铜钱、一把豁口的锄头"。
**反例**："主角来到一片荒芜之地"——没有数字就没有真实感。

### 步骤2：第一次微小收获——给出"希望"（占20%）
**操作**：主角通过一个最小的行动获得了第一个具体资源。量不大——但给了读者"这个游戏可以玩下去"的希望。
**要点**：第一次收获越小越好——三颗土豆、一枚鸡蛋、一把没生锈的铁钉。小收获让后面的爆发更有对比。
**反例**：开局就送大礼包——后面任何增长都感觉不到惊喜。

### 步骤3：连续3-5次"收获快照"——递进累积（占40%）
**操作**：用"快照"方式连续展示3-5次资源增长。每次比上次多一个维度——第一次是粮食，第二次加人口，第三次加防御，第四次解锁交易，第五次引来盟友。
**要点**：每次快照都必须有一个"可感知"的增长指标——不是"变得更好了"，而是"粮仓从只剩地板变成了堆到房梁"。
**反例**：跳过了累积过程直接写"三年后基地强大了"——读者错过了最爽的累积感。

### 步骤4：外部验证——建设成果抵御冲击（占20%）
**操作**：一个外部威胁——寒潮/山匪/上门找茬——袭来。主角的基地承受住了。在承受之后，主角和读者一起站在高处，回看建设成果。
**要点**：威胁不能太小——太小不值得建设；也不能太大——太大崩了读者心痛。恰到好处的威胁=读者替基地捏一把汗→松一口气→"值了"。
**反例**：建完了没人来打——建设成果没有经过"压力测试"，读者觉得"白忙活了"。

## 完整示例

**输入**：
```
建设目标：末世后建立一个小型生存基地
初始状态：主角＋一间漏风的木屋＋一把工兵铲＋半袋压缩饼干＋一只受伤的流浪狗
资源清单：第1次收获=发现地下泉眼→获得稳定水源；第2次=修好太阳能板→恢复电力；第3次=收留3个流民→解锁分工；第4次=截获废弃军车→获得武器和通讯设备；第5次=第一个新生儿出生→基地有了"未来"
外部威胁：一股三十人的劫掠团伙试图攻占基地，被基地的防御系统（第3次和第4次收获的成果）击退
可感知的成长：从"一个人在漏风木屋里啃压缩饼干"到"十七个人围着一锅野菜粥，收音机里在放一首三十年前的老歌"
```

**输出**：
```
【初始匮乏】
末世第七个月。苏央的资产清单写在木屋的墙上——他每用掉一样东西就在墙上划一道。今天早上他划掉了第十七道：最后一包压缩饼干。墙上现在只剩一行还没划掉的字——"狗粮半袋（给大黑的）"。大黑是上个月捡来的流浪狗，左后腿瘸了，苏央分了自己一半的口粮给它。不是因为善良——是因为半夜有东西在林子边上徘徊的时候，大黑会叫。

他的武器是一把工兵铲。铲刃上卷了一个口——上次砍变异藤蔓的时候磕在石头上。他的衣服是两件T恤叠着穿的，袖口已经磨成了絮状。

他的全部家当堆在墙角：半桶浑浊的雨水、七根火柴、一本泡过水的《野外生存手册》——翻开任何一页都会碎。

【第一次微小收获】
大黑在木屋北面的岩壁下刨了整整一个下午。苏央以为它找到了一只变异鼠——扒开碎石之后，他的手摸到了潮湿的苔藓。再往下，是隆起的一条石缝——里面有水在流。

地下泉眼。他趴下去喝了一口——不是过滤的雨水那种铁锈味，是冷的、清的、带着岩石矿物的一点点甜。大黑在旁边摇尾巴。

苏央在墙上最底下的位置写——"水源：∞"。这是末世以来他写的第一个正数。不是消耗，是产出。

【连续收获快照】

【快照1——第三个月】
屋后开出了三垄地。不是正经的田——是用工兵铲一铲一铲翻出来的碎土，垄沟歪歪扭扭。种了从废弃农场摸来的土豆种，一共十一颗。第一颗发芽的时候苏央蹲在地上看了三个小时。

【快照2——第五个月】
太阳能板修好了。不是他自己修的——他从路上捡回来一个老头，姓周，末世以前在光伏电站干了大半辈子。老周看到苏央那几块从垃圾场拖回来的破损光伏板，老花镜往鼻梁上一架，"这个简单。"三天后，木屋里亮起了末世以来第一盏灯。大黑趴在灯下面睡觉。

【快照3——第八个月】
基地迎来了第一批居民。不是救下来的——是他们自己找过来的。一个年轻女人带着她七岁的儿子，走了六十公里——因为听说了这里有水源。苏央让他们住进了他用废弃建材搭的第二间木屋。女人第二天就开始帮忙做饭。儿子负责喂大黑。大黑现在不吃苏央的口粮了——它胖了。

【快照4——第十个月】
废弃军车。老周修灯泡修出了名声，有人在路上给他指了一条消息——十七号公路的加油站后面有一辆翻倒的运输车。苏央带着两个人开着手摇发电车去了。车里没有食物。但有东西比食物更值钱——七把完好的枪、一箱弹药、还有一台可以用的短波电台。回来的路上他在电台里听到一个信号——有人在播老歌。

【快照5——第十二个月】
第一个新生儿。不是苏央的——是那个年轻女人在基地里生了第二个孩子。那天晚上所有人围着篝火，老周拿出他珍藏了三个月的半瓶白酒，每人倒了一口。苏央没喝——他把那口酒倒在地上。不是祭奠。是敬木屋墙上那些还没划完的字。

【外部验证】
第十五个月。短波电台里传来警报——有一股三十多人的劫掠队伍在朝这个方向移动。他们专找小型据点，抢完烧光。

苏央没有撤退。他在北面山坡上架了狙击位——那七把枪都上了膛。老周把太阳能板转向崖壁，让木屋的灯全部熄掉，基地在夜色里消失了轮廓。那个年轻女人把所有人带进加固过的地窖——那是上个月刚挖好的。

劫掠者摸到距离木屋三百米的时候，第一声枪响了。不是苏央开的——是他分给老张的那把。老张以前是民兵，枪法还在。劫掠者丢下四个人跑了。

第二天早上苏央站在崖壁上往下看。木屋、菜田、太阳能板——十七个人的营地小小的、紧紧的，像一只蜷着睡觉的猫。

大黑睡在营地正中间，肚子朝上。

收音机里那首三十年前的老歌还是那句没唱完的歌词：“明天会更好。”

苏央从来没听过这首歌。他站在崖壁上，轻轻跟着哼了最后一段模糊的调子。
```

### 爽感来源

| 传统暴涨爽点 | 经营建设获得感 |
|------------|-------------|
| 一次爆发的快感→爽完就没了 | 可持续的满足感→每次看到粮仓都爽 |
| 爽感来自"我比别人强" | 爽感来自"我有东西可守" |
| 数字越大越爽（百万灵石） | 数字的"变化过程"越具体越爽（3颗→17颗→满仓） |
