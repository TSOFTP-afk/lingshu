# 对话角色辨识度生成术

## 技能ID
`SKILL-006`

## 技能名称
为同一场景中的多个角色生成风格迥异的对话，确保去掉人名标签后读者仍能分辨说话者

## 触发场景
- 写作中出现2人以上对话场景
- 读者反馈"所有角色说话一个调"
- 需要为已有角色建立"语言档案"

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 角色列表 | array | 是 | 每个角色包含：姓名、性格关键词、身份、说话特征 |
| 对话场景 | string | 是 | 对什么事情展开讨论/冲突 |
| 对话功能 | string | 是 | 传递信息/制造冲突/展示关系/试探/隐瞒 |

## 执行步骤

### 步骤1：为每个角色建立"说话参数"
**操作**：根据角色的性格关键词，从下表匹配说话特征。

| 性格类型 | 句长偏好 | 开头习惯 | 高频用词 | 节奏感 |
|----------|----------|----------|----------|--------|
| 强势型 | 5-8字短句 | 命令式/"你"开头 | 少用"可能""也许" | 干脆利落，常打断别人 |
| 温柔型 | 15-25字长句 | 试探式/"我"开头 | "可能""或许""要不" | 说话有停顿，留余地 |
| 聪明型 | 10-15字中句 | 先陈述再反问 | 专业术语/精准动词 | 语速平稳，偶尔停顿 |
| 暴躁型 | 5-8字短句 | 反问/"你"开头 | 脏话(适度)/重复词 | 语速极快，连续输出 |
| 腹黑型 | 8-12字 | 先笑/先沉默再说 | 反讽词/双重否定 | 话说一半，留白 |
| 自卑型 | 10-15字 | "那个……""我……" | "不好意思""可能是我" | 断断续续，自我修正 |

### 步骤2：生成对话，注入角色差异
**操作**：围绕对话场景和功能，让每个角色按自己的说话参数发言。至少3个回合。

### 步骤3：注入潜台词（选做但强烈推荐）
**操作**：至少一个角色的台词需要包含"表面说A/实际指B"的潜台词。
**模板**："[表面上的话]。" 但 [真实意图的表现]。
**示例**："你这条裙子真好看。"但她轻轻把手里那条裙子放回了货架——那是同款。= "这条裙子只有我能穿。"

### 步骤4：去标签自检
**操作**：去掉所有的"XXX说""XXX道"标签，只看引号里的内容。
**核心检验**：能不能分辨出是谁在说话？能→合格；不能→步骤1的参数需要调整。

## 输出格式
输出完整对话段落，每句台词后标注说话者（用于验证），最后附上去掉标签的纯对白版本。

## 质量检验
- [ ] 去掉名字，能否准确指出每句话的说话者？
- [ ] 每个角色的句长偏好是否与步骤1设定的参数一致？
- [ ] 是否有至少一句潜台词？
- [ ] 是否有纯对话连续超过5段？（超过则需插入动作）

## 完整示例

**输入**：
```
角色列表：
1. 沈之晏（强势型，男，32岁，将军，习惯命令/短句/不解释）
2. 顾小满（温柔型，女，26岁，军医，习惯试探/长句/总在结尾留疑问）
3. 赵铁柱（暴躁型，男，28岁，副将，习惯反问/脏话/连续输出)

对话场景：粮草被烧，三人商量是否撤退
对话功能：制造冲突+展示关系
```

**执行过程**：
```
步骤1-建立说话参数：
沈之晏=强势型："不撤。"（3字）
顾小满=温柔型："可是如果再等下去，伤兵的药只够三天了……不是吗？"（23字+"不是吗"试探式结尾）
赵铁柱=暴躁型："那他妈也不能撤！你知不知道对面是谁？是蒙拓那个狗日的！他要是追上来，咱们全军都得撂在这儿！"（反问+脏话+连续输出）

步骤2-生成对话（3回合）：
回合1(沈→顾)："不撤。"(3字命令)
回合1(顾→沈)："我不是在质疑你的判断，只是如果再等下去，伤兵的药只够三天了……不是吗？"(试探式)
回合1(赵→顾)："顾小满你就是太软！打仗死人是常事，你当军医的还不明白？"(反问+直白)

回合2(顾→赵)："我明白。正是因为我明白，才不想多死一个人。"(温柔但坚定)
回合2(沈→两人)：沉默。然后站起来，披上盔甲。"赵铁柱。明天天亮前，把对面粮草也烧了。"(命令=不解释)
回合2(赵→沈)："就等你这句话！"(暴躁变兴奋)

步骤3-注入潜台词：
顾小满说"不想多死一个人"——表面在说伤兵。实际在说沈之晏当年也是这样被"死人是常事"放弃过的人。

步骤4-去标签自检：
"不撤。" → 强势
"伤兵的药只够三天了……不是吗？" → 温柔试探
"那他妈也不能撤！" → 暴躁
→ 能分清 ✓
```

**输出**：
```
"不撤。"沈之晏放下茶杯，两个字干脆得像两块铁。

顾小满抬起头。"我不是在质疑你的判断，将军。只是如果再等下去，伤兵的药只够三天了……不是吗？"

"顾小满你就是太软！"赵铁柱一巴掌拍在桌上，杯盖跳了一下，"打仗死人是常事——你当军医的还不明白？"

"我明白。"顾小满的声音仍然轻，但手指按在药箱锁扣上，一直没有松开。"正是因为我明白，才不想多死一个人。"

沈之晏沉默了片刻，站起来，披上盔甲。

"赵铁柱。"

"在！"

"明天天亮前——把对面粮草也烧了。"

赵铁柱咧嘴一笑："就他娘的等你这句话！"
```
