# 打脸爽点三段式

## 技能ID
`SKILL-003`

## 技能名称
按"压抑→反转→震惊反馈"三段递进结构，自动生成一场完整的打脸爽点场景

## 触发场景
- 剧情需要主角展示实力/身份/智商碾压
- 前期已积累读者对反派的恨意，需要释放
- 主角获得新能力/新身份后首次亮相

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 主角隐藏优势 | string | 是 | 主角实际上拥有什么（实力/身份/知识/证据） |
| 反派表现 | string | 是 | 反派此刻在做什么（嘲讽/打压/威胁） |
| 场景背景 | string | 是 | 发生地点和在场观众类型 |
| 反馈层次数 | int | 否 | 默认3层：反派震惊→围观者哗然→权威人物认可 |

## 执行步骤

### 步骤1：压抑——拉仇恨（占30%篇幅）
**操作**：写反派对主角的轻视/嘲讽/羞辱，让读者情绪积累到"忍不了"的程度。
**要点**：
- 反派的话必须具体，不能是模糊的"你不行"
- 至少2个不同层面的轻视（身份层面+能力层面+关系层面，任选其二）
- 用围观群众的附和行为放大羞辱感
**反例**："他看不起主角"——一句话带过，读者没感觉。

### 步骤2：反转——主角出手（占40%篇幅）
**操作**：主角用行动/证据/一句话粉碎反派的全部轻视。
**要点**：
- 反转必须与压抑阶段每个轻视点一一对应（你嘲笑我穷→我亮出亿万合同；你嘲笑我弱→我一招制敌）
- 反转方式决定了爽感类型：武力碾压=热血爽，智商碾压=沉静爽，身份揭晓=爆炸爽
- 主角出手的姿势必须"举重若轻"——越轻松越爽，越费力的"险胜"越削弱爽感
**反例**：主角和反派打了三百回合才赢——这不叫打脸，这叫正常竞争。

### 步骤3：震惊反馈——集体反应（占30%篇幅）
**操作**：按从近到远的层次依次描写"刚才轻视主角的人"的震惊反应。
**要点**：
- 第一层：反派的直接反应（语塞/后退/不可置信）
- 第二层：围观群众的态度逆转（窃窃私语→倒戈支持主角）
- 第三层（可选）：一个权威人物的认可（"这孩子，我一直在暗中观察他"）
- 每一层的描写控制在50字以内——反应越多越拖沓
**反例**：只有一句"全场震惊"——读者感受不到爽感。

## 输出格式
输出三段结构完整的打脸场景，总字数400-600字。

## 质量检验
- [ ] 压抑阶段能否让读者产生真实的愤怒？（读一遍，你拳头硬了吗）
- [ ] 反转是否回应了压抑阶段的每一个具体轻视？
- [ ] 主角出手是否"举重若轻"——越轻松越爽？
- [ ] 震惊反馈是否至少有2层？
- [ ] 有没有出现"全场震惊""所有人都目瞪口呆"这类万能模糊词？

## 完整示例

**输入**：
```
主角隐藏优势：萧寒其实是本次宗门大比的隐藏考官，修为元婴期
反派表现：大弟子赵阔公开嘲讽萧寒"废物师弟不配上擂台"
场景背景：宗门大比，全宗弟子和长老都在观礼台
```

**执行过程**：
```
步骤1-压抑：
赵阔当众羞辱——
身份层面："萧师弟，你还是下去吧。师兄怕收不住手把你打死，掌门那里不好交代。"
能力层面：台下一片哄笑。"赵师兄上个月刚突破金丹，萧寒还在筑基打转吧？"
关系层面：赵阔看向观礼台上的小师妹："师妹你放心，我三招之内解决。"

步骤2-反转：
萧寒不动。等赵阔一剑刺来——他抬起两根手指，夹住了剑尖。
"第一招。"萧寒说。声音不大，但全宗都听见了。
他松开手指，赵阔连退三步。
"还有两招。请。"
赵阔的脸从红变白再变青——他终于看出来那个起手式了。
那不是筑基期的起手式。

步骤3-震惊反馈：
第一层-反派："你——你不是筑基？"赵阔握剑的手在抖。
第二层-围观："元婴……是元婴期的威压！"台下炸了锅。"他什么时候……他不是废物吗？"
第三层-权威：观礼台最上首，掌门缓缓放下了茶杯。"各位——介绍一下。萧寒不是参赛弟子。他是你们本次大比的考官。"
```

**输出**：
```
赵阔站在擂台中央，剑尖对着台下，笑得张狂："萧师弟，师兄劝你还是别上来了。我怕自己收不住手，到时候在掌门面前不好交代。"

台下师弟们一阵哄笑。"赵师兄上月刚破金丹，萧寒还在筑基门槛打转吧？""让萧寒上？三招之内他得趴下。"

赵阔转头看向观礼台的小师妹，语调软了些："师妹放心，我点到为止。"

萧寒走上了擂台。没有拿剑。

赵阔一剑刺来。萧寒抬起两根手指——夹住了剑尖。

"第一招。"他说。音量不大，但整个演武场都听见了。

他松开手指。赵阔踉跄后退三步，脸上的笑意凝固成一块僵硬的壳——他终于认出来了。

那个起手式。

"你——"赵阔握剑的手在微微发抖，"你不是筑基？"

台下炸开了锅。"元婴？那是元婴期的威压！""他不是废物吗！"

观礼台最上首，掌门放下茶杯，对身旁的长老们点了点头。

"诸位——介绍一下。萧寒不是参赛弟子。他是本次大比的考官。"
```
