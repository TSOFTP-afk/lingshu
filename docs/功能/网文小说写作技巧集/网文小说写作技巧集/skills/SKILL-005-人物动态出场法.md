# 人物动态出场法

## 技能ID
`SKILL-005`

## 技能名称
用"未见其人先闻其声"的方式首次引入角色，10秒内在读者脑中建立角色记忆点

## 触发场景
- 新角色首次登场
- 重要配角/反派需要一个令人印象深刻的出场
- 旧角色在新场景中重新亮相

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 角色姓名 | string | 是 | — |
| 角色身份 | string | 是 | 表面身份+隐藏身份（如有） |
| 核心性格 | string | 是 | 用一个词概括，如"跋扈""阴郁""天真""老练" |
| 出场场景 | string | 是 | 在什么环境/情境下出现 |
| 记忆点 | string | 是 | 该角色最独特的一个特征（口癖/习惯/物件/反差） |

## 执行步骤

### 步骤1：声音/动作先于外貌出现
**操作**：先写角色的声音（一句话/一个笑声/一个动作的声响），再写人。
**要点**：声音内容必须立刻展示性格——温婉的人不会未见其人先闻其声；跋扈的人会。
**反例**："这时候走进来一个人，他叫XXX，长得很高，穿着一件蓝色长衫……"——静态描述，读者读完没有任何印象。

### 步骤2：用动态外貌替代静态描写
**操作**：不写"她有长头发、大眼睛"，而写"她甩了一下马尾辫，发梢差点扫到他脸上"——让外貌特征通过动作"发生"。
**要点**：只写1-2个最突出的外貌特征，剩下的留给读者脑补。
**反例**：从头到脚按顺序描写（发型→眼睛→鼻子→嘴巴→衣服→鞋子）——像填表格。

### 步骤3：将记忆点植入出场的第一个行为中
**操作**：角色的"记忆点"（口癖/习惯/物件）必须在出场30字内出现，成为这个角色的"姓名标签"。
**要点**：记忆点必须是独特的——"长得帅"不是记忆点，"永远叼着一根没点燃的烟"才是。
**反例**：第50章才想起来给角色加口头禅——读者早就忘了他是谁。

### 步骤4：用一个行为暗示"更深层的东西"
**操作**：在该角色的外貌/动作/台词里埋一条线索，暗示他"不只是表面看起来那样"。
**要点**：线索要隐蔽——第一次读不会特别注意，知道真相后回头看会觉得"原来那时候就埋了伏笔"。
**反例**：直接写"这个人不简单"——告诉读者没意思，要让读者自己发现。

## 输出格式
输出一个150-200字的角色出场段落，包含完整的四步骤内容。

## 质量检验
- [ ] 读者10秒后能否准确描述这个角色最突出的1个特征？
- [ ] 外貌是否通过动作展现而非静态罗列？
- [ ] 记忆点是否在出场30字内出现？
- [ ] 是否有至少1个暗示深层身份的细节？

## 完整示例

**输入**：
```
姓名：秦不渡
身份：表面是茶楼老板，实际是退隐的前朝第一刺客
核心性格：慵懒散漫
出场场景：主角上门寻仇，推开茶楼的门
记忆点：永远叼着一根没点燃的旱烟杆，说话拖长音
```

**执行过程**：
```
步骤1-声音先于外貌：
"急什么——"一个懒洋洋的声音从柜台后面拖出来。
（拉长的尾音=慵懒性格，立刻建立）

步骤2-动态外貌：
"倚在柜台后面的男人三十出头，下巴上一层胡茬。听到动静连眼皮都没抬，只是指尖捻了一片茶叶送进嘴里嚼了嚼。"
（"眼皮都没抬""嚼茶叶"=慵懒）

步骤3-记忆点植入：
"嘴里叼着的那根旱烟杆从头到尾没点着过。"
（出场即出现，且"不点烟的烟杆"=有故事）

步骤4-埋深层线索：
"用抹布擦柜台的手忽然停了一下。只是停了一瞬。那双手——骨节分明，指尖有一层寻常茶楼老板不会有的薄茧。"
（"薄茧"=拿刀的手，暗示前刺客身份——第一次读可能忽略，知道真相后回头看是伏笔）
```

**输出**：
```
"急什么——"

一个懒洋洋的声音从柜台后面拖出来，像这间茶楼一样，没有任何迎客的意思。

秦不渡倚在柜台后面，三十出头，下巴上一层胡茬。听到推门声连眼皮都没抬——只是指尖捻了一片茶叶送进嘴里，慢慢地嚼。嘴里叼着的那根旱烟杆从头到尾没点着过。

他拿起抹布擦柜台。擦了两下，手忽然停了一下。

只是一瞬。

那双手——骨节分明，宽大有力。指尖有一层薄茧。不是常年抓算盘和茶壶的手会长出来的那种。

主角把剑拍在柜台上。"秦不渡。我来寻仇。"

茶楼老板终于抬起了眼皮。

"哦。"他说，尾音拖得老长。"今天不营业。"
```
