# 黄金开篇300字

## 技能ID
`SKILL-001`

## 技能名称
在300字内完成"主角出场→困境展示→章末钩子"三段式开篇

## 触发场景
- 新书第一章写作
- 读者反馈"开头太慢/看不下去"需要重写开篇
- 需要为已有故事设计一个更有冲击力的开头

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 主角姓名+身份 | string | 是 | 如"萧炎，15岁，昔日天才如今斗之力三段" |
| 当前困境 | string | 是 | 主角此刻面临的具象化困境（非抽象描述） |
| 情感基调 | string | 否 | 愤怒/绝望/隐忍/自嘲，默认"隐忍不甘" |
| 隐藏底牌 | string | 否 | 主角有什么可以翻盘的资本，用于埋下期待钩子 |

## 执行步骤

### 步骤1：第一句话——抛出身份标签
**操作**：开篇第一句直接给出两个信息：(1)主角名字 (2)一个让读者立刻理解他处境的标签。
**要点**：标签必须是可量化的、有对比度的——"斗之力三段"(最低等级)、"全宗门唯一没筑基的弟子"、"嫁入侯府三年没见过夫君"。
**反例**："京都的秋天来得格外早……"（无人无事无冲突，环境开头=读者关页面）

### 步骤2：50-100字——用动作展示情绪
**操作**：不写"他很难过/愤怒/不甘"，而是写一个具体的身体动作或细节。
**要点**：动作必须有"疼痛感"——指甲掐进掌心/拳头攥得骨节发白/喉结滚了一下但一个字没说出来。
**反例**："他感到非常痛苦和愤怒"——这是报告，不是小说。

### 步骤3：100-200字——展示困境的具象画面
**操作**：用一句对白或一个场景瞬间呈现主角此刻面对的具体困境。
**要点**：困境必须是一个"画面"，不是一段"解释"——退婚书上的字/被踩碎的测试石/空无一人的婚房。
**反例**：用大段旁白解释"他曾经是天才，后来……"——读者不需要知道全部前因，只需要看到此刻的"惨"。

### 步骤4：200-300字——埋下逆袭期待
**操作**：在结尾处给出一个微小但确定的信号，让读者相信主角能翻盘。
**要点**：信号可以是一个物体（戒指里的灵魂）、一句话（"三年之约"）、一个发现的预兆（抽屉最深处那封他从未打开的信）。
**反例**：直接写"他不知道，很快他就会变强"——过于直白，失去悬念。

## 输出格式
直接输出300字以内的开篇段落，包含完整的四步骤内容。

## 质量检验
- [ ] 300字内主角是否出场且点名？——是
- [ ] 第一个冲突/困境是否在300字内出现？——是
- [ ] 情绪是否通过动作展示而非直接告诉？——是
- [ ] 最后的句子是否让人想翻下一页？——是
- [ ] 有没有超过50字的长句？——不超过3句

## 完整示例

**输入**：
```
主角：苏锦棠，17岁，庶女
困境：嫡姐穿着她的嫁衣嫁给了她爱的人
情感基调：愤怒隐忍
隐藏底牌：她手里有嫡母通奸的证据
```

**执行过程**：
```
步骤1-身份标签："庶女苏锦棠跪在祠堂外——这已经是第三个时辰了。
她的膝盖硌在冰冷的石板上，但她感觉不到疼。"

步骤2-动作展示情绪："她死死盯着前方。不是看祠堂里的牌位。
是看地上那道拖了九尺长的嫁衣裙摆——正红的绸缎从她眼前一寸寸碾过去。"

步骤3-困境画面："花轿的帘子掀起一角。她看见了那张脸。是她爱的人。
——坐在里面的应该是她。那件嫁衣，是她熬了三十七个日夜亲手绣的。
但花轿里坐的是嫡姐。"

步骤4-逆袭期待："苏锦棠低下头。袖口里，那封她本打算烧掉的信还在。
信封上写着——'户部侍郎苏大人亲启。内附令夫人与马夫通奸物证。'
她不烧了。"
```

**输出**：
```
苏锦棠跪在祠堂外的石阶上。第三个时辰了。膝盖硌在冰冷的石板上，但她感觉不到疼。

她死死盯着前方——不是看祠堂里的牌位。是看地上那道拖了九尺长的嫁衣裙摆。正红的绸缎从她眼前一寸寸碾过去，每一寸都像火在烧她的眼睛。

花轿帘子掀起一角。她看见了那张脸。是她最熟悉的那个人。

那件嫁衣是她熬了三十七个日夜，亲手绣的。但花轿里坐的不是她。

苏锦棠低下头。袖口里，那封她本打算烧掉的信还硬硬地硌着手腕。信封上八个字——"户部侍郎苏大人亲启"。她轻轻抚平被揉皱的纸角。

不烧了。
```
