# 伏笔回收快照法

## 技能ID
`SKILL-023`

## 技能名称
在关键反转点，用"快照回放"的方式让读者回头看前面N章——每一处曾经被忽略的细节此刻全部串成线

## 触发场景
- 长线伏笔到了回收时刻
- 身份/真相/反转揭晓时需要"证据回放"
- 读者对前文某些"奇怪但被忽略"的细节重新产生兴趣

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 揭晓的真相 | string | 是 | 此刻揭示的完整真相 |
| 前文伏笔位置 | string | 是 | 伏笔出现在哪些章节——"第7章他说了一句话""第12章有一个场景" |
| 伏笔原本的"伪装" | string | 是 | 当时读者为什么会忽略这些伏笔——伪装成什么了 |
| 主角/读者的此刻反应 | string | 是 | 揭晓时的第一反应 |

## 执行步骤

### 步骤1：揭晓——真相曝光的瞬间（占20%）
**操作**：用最短的句子给出真相。不给解释——只给事实。
**要点**：短句。极短。像一拳打在读者腹部。然后停顿。
**反例**：真相揭晓后立刻开始解释——读者的震撼还没消化就被塞了信息。

### 步骤2：第一处伏笔快照（占25%）
**操作**：角色的记忆闪现——"他忽然想起那天……"——回到前文章节的某个看似无关的片段。这次用"现在知道了真相"的视角重新描述那个片段。
**要点**：必须包含两个元素：(1)当时读是什么感觉 (2)现在回头看是什么感觉。只写后者，读者会自己脑补前者。
**反例**：只说"他以前说过一句话"——不给具体画面，读者没有"回头重看"的冲击。

### 步骤3：第二处伏笔快照（占25%）
**操作**：第二个被重新解读的细节。比第一个更深——第一个是"行为"，第二个是"物件"或"环境"。
**要点**：两处伏笔必须是不同类型的——一个是对话、一个是环境、一个是物品、一个是缺席——类型越多样，读者越觉得"作者布了多大的局"。
**反例**：两处伏笔都是"某人说过某句话"——单一类型显得单薄。

### 步骤4：第三处——最隐蔽的那一个（占30%）
**操作**：前两处伏笔之后读者已经开始"回头看"，第三处要给他们最隐蔽的那一个——没有出现在任何角色的对话或行为中，而是藏在环境描写、天气、或者一个"没有被写出来的缺席"里。
**要点**：第三处伏笔必须让读者产生"这都能是伏笔？！"的震撼——而且越想越对。
**反例**：第三处也是"某人说过一句话"——层次感没了。

## 输出格式
输出四段完整场景，标注每一处伏笔的类型和"当时vs现在"的双重解读。

## 完整示例

**输入**：
```
揭晓的真相：茶楼老板秦不渡不是退隐的刺客——他是当年奉命灭韩家满门的朝廷密探。但他放走了韩家唯一的幸存者：主角本人。
伏笔位置：第3章-他给主角递茶时手抖了一下；第7章-茶楼后院总有一盏灯亮到天亮；第14章-他说了一句"我这辈子最怕下雪天"
伏笔伪装：手抖=老了；灯亮着=失眠；怕雪天=随口一提
主角的此刻反应：忽然明白为什么二十年来秦不渡总是在下雪天站在窗口
```

**输出**：
```
【揭晓】
秦不渡是朝廷的人。不是退隐刺客——是奉命灭韩家满门的密探。二十年前那场屠杀不是寻仇。是灭口。

韩家灭门唯一幸存的那个婴孩——此刻就站在他面前。手里攥着一页吏部名册。

苏锦棠忽然觉得嗓子眼有什么东西堵住了——不是恨。

【快照1——行为类】
他想起秦不渡第一次给他泡茶。第三年冬天——那年雪大，苏锦棠刚上山，冻得手指发僵。秦不渡从柜台后面绕出来，把一杯热茶塞进他手里。茶杯递过来的时候——秦不渡的手抖了一下。茶水晃出来一滴，烫在苏锦棠的虎口上。

他当时以为是老人手抖。现在回头看——不是手抖。是他在递茶的瞬间，低头看见了苏锦棠虎口那颗痣。韩家满门，男性子嗣出生时右手虎口都有一颗痣。族谱里写得清清楚楚。那份族谱，是他二十年前执行灭门任务之前，在吏部档案室背下来的。

他接过茶的时候看见的第一样东西，是那个婴孩二十年后的脸。

【快照2——环境类】
然后是那盏灯。茶楼后院总有一盏灯亮到天亮。苏锦棠问过——秦不渡说"老了睡不着"。他信了。

现在他想起那盏灯的位置——正对着他的卧房。是巷子里唯一能看清他那扇窗户的角度。二十年。不是睡不着。是睡着之前需要确认那扇窗户里面还有人。

【快照3——最隐蔽的缺席】
最后一个——他从来没有说过的那句话。苏锦棠在山上住了六年，秦不渡教他剑法、教他泡茶、教他辨认江湖上每一股势力的来路和去路。教了他一切，唯独没有教他为什么——为什么收留他。每次苏锦棠问"你为什么要帮我"，秦不渡的回答永远是一样的。耸耸肩。叼着那根旱烟杆。不解释。

这一刻苏锦棠忽然懂了。不是不想解释。是在他准备好回答之前，他必须先回答另一个问题——"我是杀你全家的人"。他把那个问题藏了二十年，每一次苏锦棠问"为什么帮我"，他给出的那个耸肩都是在说：还不是时候。

"现在时候了。"秦不渡从柜台后面走出来。他走得很慢——不像是走向一个仇人。"你手里那张名册上写得很清楚。我在灭门名单上圈了自己的名字——不是退隐。是划掉。朝廷密探划掉自己的名字只有一个意思——任务失败。我失败了。"他停下脚步。离苏锦棠还有三步。"我的任务是杀掉韩家所有男性子嗣。你右手虎口那颗痣——二十年前我在一个婴儿的手上见过一模一样的。"

"你没杀我。"

"我没有。"

"为什么。"

秦不渡从嘴角取下那根旱烟杆。从来没有人见过他放下这根烟杆。二十年来第一次。

"因为你哭了一声。那时候你才一个多月——我不知道一个多月的孩子会不会做梦。但你哭了一声之后，把手从襁褓里伸出来，攥住了我的拇指。"

他低头看着自己右手大拇指——那根手指被他看了二十年。"然后我就不想杀人了。这个理由够不够。"

雪不知道什么时候开始下的。秦不渡转过身，走到窗口站住。这个姿势苏锦棠见过无数次——下雨、起风、大雾、阴天——每次天气变化秦不渡都会站在那个窗口。他一直在说"我怕下雪"。怕下雪不是因为冷。是因为二十年前韩家灭门那晚，也是一场大雪。

苏锦棠看着他的背影，忽然想起茶楼后院那盏亮到天亮的灯。照着那扇窗。照着窗边的人。二十年。一盏灯，一个人，一个不该活着的婴儿。一场下不完的雪。
```

**【伏笔类型标注】**
- 快照1：行为伏笔——递茶的手抖→认出虎口痣
- 快照2：环境伏笔——亮到天亮的灯→守卫那扇窗户
- 快照3：缺席型伏笔——从不回答"为什么帮我"→回答之前必须先回答另一个问题
