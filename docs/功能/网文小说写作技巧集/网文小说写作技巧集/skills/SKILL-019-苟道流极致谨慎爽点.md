# 苟道流极致谨慎爽点设计

## 技能ID
`SKILL-019`

## 技能名称
设计"主角明明很强但极度谨慎→做好万全准备再出手→出手即碾压→周围人震惊于'他什么时候准备了这么多'"的安全感爽点

## 触发场景
- 苟道流/稳健流修仙
- 读者厌倦了"主角莽撞冲上去靠光环逆转"的套路
- 需要一种"万无一失"的安全感满足

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 对手实力 | string | 是 | 敌人有多强——越强越衬托主角的谨慎是正确的 |
| 主角真实实力 | string | 是 | 主角可不费吹灰之力碾压（但读者和配角都不知道） |
| 主角的过度准备 | string | 是 | 主角准备了哪些"不必要的"防备——越多越荒诞越爽 |
| 旁观者的不解 | string | 是 | 周围人怎么看主角的谨慎——觉得他"胆小""神经质" |
| 碾压时刻 | string | 是 | 出手瞬间——越轻松越和之前的谨慎形成反差 |

## 执行步骤

### 步骤1：主角的"过度准备"清单（占30%）
**操作**：列出主角为应对一个威胁所做的所有准备——至少5条。"有这个必要吗"——读者越觉得没必要，后来的"幸好准备了"越震撼。
**要点**：准备必须是具体的、可展示的——"囤了一百颗丹药"不如"在后山挖了七个逃生地道，每个地道口埋了不同的传送符"。
**反例**：准备了两三条——不够夸张，反差不够强。

### 步骤2：旁观者的不解与轻视（占20%）
**操作**：写配角/同门对主角"过度谨慎"的嘲笑或不解。
**要点**：旁观者的理由是合理的——"一个筑基期打炼气期，准备这么多干什么"。读者会代入旁观者觉得主角真的过度紧张了。
**反例**：旁观者蠢到"完全不在意敌情"——他们的不理解应该是有依据的。

### 步骤3：一瞬碾压（占25%）
**操作**：对手出现，主角的某一条"过度准备"发挥了作用。碾压的过程极快——越短越能衬托"准备了这么久就为这一瞬"的讽刺美感。
**要点**：碾压时主角表情平淡——不是"看我多厉害"，是"幸好准备了"。
**反例**：碾压过程太长——与"苟道"的克制美学矛盾。

### 步骤4：旁观者"后怕式震惊"（占25%）
**操作**：写旁观者从"他太谨慎了"到"如果不是他谨慎，今天全得死"的态度逆转。
**要点**：逆转的触发点必须是主角某条"看起来多余"的准备——在关键时刻阻止了一场灾难。
**反例**：旁观者只震惊于主角的实力——忽略了"如果不是那些准备"这个关键。

## 完整示例

**输入**：
```
对手：金丹大圆满的魔修闯入宗门
主角真实实力：元婴期（早已可以碾压金丹）
过度准备清单：①在后山布下三重困杀阵 ②给每个同门塞了护身符 ③挖了五条逃生地道 ④在魔修必经之路上埋了三十颗雷火符 ⑤去藏经阁把金丹期所有攻击法术的破解方法抄了一遍 ⑥把掌门护山大阵的权限偷偷转到自己名下
旁观者：同门觉得主角"废物师弟天天瞎忙"
碾压时刻：魔修破开护山大阵冲进来——然后踩中了第五颗雷火符，接着发现所有攻击都被克死了，遁地逃跑的时候发现地下也被封死了。全过程主角蹲在藏经阁三楼窗边看着，手里的茶杯都没放下。
```

**输出**：
```
【过度准备清单】
苏默在宗门大比之后的第二天开始挖地道。同门都在庆功宴上喝灵酒——他一个人扛着铁锹在后山竹林里，从卯时挖到酉时。第一条。第二条。第三条。一共挖了五条，每条出口藏在不同的山峰，地道壁上贴了十七种不同的短距传送符——万一哪条被封了，跳进旁边那条就行。

挖完地道之后他开始布阵。三重叠杀——第一层触发警报，第二层减速，第三层绞杀。阵眼藏在一棵歪脖子老槐树的树洞里。做完这一切正好过去了十五天。同期入门的师弟问他这段时间去哪了。他说"肚子疼"。师弟们翻白眼——筑基期天天装病，丢不丢人。

【旁观者的不解】
"苏默又去藏经阁了。"

"这次抄什么？金丹期所有攻击法术的破解方法？他筑基期抄这个干嘛，金丹期的功法他看得懂吗？"

"上次说后山有妖气——结果是一只野猫。"

"上上次说宗门护山大阵有漏洞——掌门亲自查验，屁事没有。"

苏默听到这些议论的时候正在往师兄们的枕头底下塞护身符。纯手工的。每张符里嵌了一丝他的元婴真元——够了。金丹大圆满的魔修破不了这道防御。

【一瞬碾压】

魔修破开护山大阵的那个深夜里，山道上炸开的雷火符照亮了半座后山。第一颗。第二颗。第三颗。三十颗雷火符呈品字形排列——那个魔修一脚踩中了第五颗。他的护体魔罡应声碎裂。

他应变极快——不退反进，遁入地下。然后在地下三尺撞上了一堵墙。不是土。是苏默用石系法术浇了三个月的地基——这整座后山的底下十五丈全是铁壁。

"谁——"

他钻出地面，准备用血遁逃跑的时候，一道剑气从后山竹林飞过来。不是刺他——是切断了山道旁的歪脖子老槐树。树轰然倒下。阵眼碎裂。三重杀阵同时启动。

整个过程不到一炷香。

苏默全程蹲在藏经阁三楼的窗户边上看着。手里端着一杯放凉了的茶。茶杯里映着后山上不断爆开的雷火符——像一场无声的烟花。

【旁观者"后怕式震惊"】

第二天早上，掌门站在后山被炸出的大坑前沉默了许久。

"这几条地道——是谁挖的？"

"藏经阁那本《金丹法术破法集注》——上面批注的笔迹和魔修身上残留的克法符纹一模一样。"

"昨晚所有人都安然无恙——因为每个人的枕头底下都有一张护身符。纯手工的。符胆里注的不是筑基期的真元。"

掌门转过身。"把苏默叫来。"

那天早上，全宗门都在找苏默。他不在洞府，不在后山，不在藏经阁。最后是一个师弟在竹林深处找到他的——他正蹲在地上，把最后一截被炸断的地道壁重新补好。

"苏默——掌门找你。"

苏默拍了拍手上的土，站起来的时候，眼神还是那副"幸好准备了"的平淡。

"护山大阵的权限是不是在你这？掌门问。"
