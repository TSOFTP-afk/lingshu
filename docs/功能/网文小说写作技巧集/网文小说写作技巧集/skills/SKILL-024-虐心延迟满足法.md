# 虐心延迟满足法

## 技能ID
`SKILL-024`

## 技能名称
设计"信息差型虐点"——读者和部分角色已知悲剧结局，但不知道"怎么走到那一步"——让读者在明知结局的情况下被"过程"持续折磨

## 触发场景
- 虐文/悲剧向剧情
- 读者已经通过前文/预告/重生设定知道了某个角色的死亡
- 需要用"已知结局"增强而非削弱情感冲击

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 已知的悲剧结局 | string | 是 | 读者或主角已经知道的结局——谁死了/分开了/失败了 |
| 当前时间线 | string | 是 | 距离结局还有多远——"结局前一个月""倒数第三天" |
| 当前的"好" | string | 是 | 此刻角色正在经历的幸福/平静/希望——越甜后来的刀越疼 |
| 通往结局的关键事件 | string | 是 | 导致结局的那个转折事件是什么 |

## 执行步骤

### 步骤1：给读者一个"幸福的锚点"（占30%）
**操作**：在悲剧发生之前，写一个极其日常的幸福瞬间。不是大场面——是两个人一起做饭、在雨里跑、说了一句傻话然后一起笑了。
**要点**：这个幸福瞬间必须包含一个"以后会消失的细节"——他的笑声、她煮面的方式、阳台上那盆快枯死的花被他救活了——等到悲剧发生后，这个细节会成为读者胸口最疼的那根刺。
**反例**：幸福是"他们在一起很开心"——太抽象，没有具体的"锚点"。

### 步骤2：埋下"不祥的预兆"但让它看起来像日常（占20%）
**操作**：在这一段幸福描写中插入一个微小的异常——他说了一句"如果以后我不在了"然后立刻笑着说是开玩笑；她做了一个他看不懂的表情然后立刻转过头去。
**要点**：预兆必须伪装成日常。第一次读觉得"没什么"，结局后回头看才知道"那时候他/她已经知道了"。
**反例**：预兆太明显——"我有一种不好的预感"——这不是伏笔，是剧透。

### 步骤3：通往结局的"最后一件小事"（占30%）
**操作**：写悲剧发生前两人之间最后一次正常的互动——可能是吵架后没有和好、可能是他出门前忘了说"早点回来"、可能是她给他发了一条消息他正在忙没有立刻回。
**要点**：这件小事越普通越好。普通到角色自己都没意识到这是"最后一次"。因为读者知道这是最后一次——这种信息差就是虐点的核心。
**反例**："最后一面"被写得太煽情——角色如果知道自己要死了，那叫悲壮，不叫遗憾。真正的虐是"他不知道自己今天是最后一次给她发消息，所以只发了'冰箱里有饭'五个字"。

### 步骤4：结局时刻——用"缺席"写"存在"（占20%）
**操作**：不写角色怎么死的——写角色死后，前面每一步埋下的那些"锚点"如何变成刀子。他再也不会做那件事/那个位置永远空了/她下意识多拿了一双筷子然后又默默放回去。
**要点**：用细节而非情绪——"那个阳台上谁也不会再去浇的花"比"她每天以泪洗面"虐一百倍。
**反例**：直接写哭丧/崩溃——太直白，读者反而有距离感。

## 完整示例

**输入**：
```
已知悲剧结局：男主会在一次任务中牺牲（读者和女主都通过某种方式提前知道了）
当前时间线：任务前一周——他还活着，还在和女主一起生活
当前的幸福：两人刚搬了新家，他笨手笨脚地帮她装书架，装反了三次
通往结局的关键事件：再过五天他就要出发去那个任务了——一个他不可能活着回来的任务。女主知道，但他不知道她知道。
```

**输出**：
```
【幸福的锚点】
"反了。"她说。他蹲在地上，手里拿着螺丝刀，仰头看她。书架层板是倒的——这已经是他装的第三次了。第一次腿装反了，第二次螺丝拧滑了牙，第三次——"你看，这次方向是对的吧。"他把层板转过来，短边朝前。确实没错。但是书架本来是靠墙放的，短边朝前意味着所有的书脊都将面向墙壁。

她看了他三秒，然后笑了——不是因为他傻，是因为书架装反了可以再拆，螺丝滑牙了可以换新的。他说"这个书架我一晚上就能搞定"的时候她没拆穿他已经搞了三个晚上了。她只是蹲下来，从他手里接过螺丝刀，说"你扶着，我来拧"。他扶着层板，她的手覆在他的手背上——不是故意的，是因为螺丝孔被拧花了，需要两个人一起用力。书架装好的时候凌晨一点。他把她的书一本一本放上去——不是按颜色排的，是按他以为她想看的顺序。诗集在最上面那层，因为她睡前会读两页。她在旁边看着，偷偷把诗集挪到了第二层。第一层放了他最喜欢翻的那本破旧的《兵器图解》——他从来不说那本书是他的，但每次翻完都不会放回原位。

书架上的书脊有一半朝着墙壁。他没发现。她也没纠正。因为留着这个错误，他明天晚上就又会蹲在这里，拿着螺丝刀，对着书架发愁。他发愁的时候会咬下嘴唇。她很喜欢那个表情。

【伪装的预兆】
那天晚上快两点的时候他忽然从床上坐起来。"我想起来一件事——"她还没睡，看着他在黑暗里摸索着穿拖鞋，"那层板的方向还是不对。"

"明天再弄。"她拉住他的手腕。他的手腕比一个月前细了一圈——这个月他瘦了很多。她没问为什么。她知道他在准备什么。他把她的手握在掌心里，拇指沿着她的虎口轻轻划了一圈。他说"下周应该能把书架搞定"。

她闭上眼睛。下周他不在家。她知道。他不知道她知道。

【最后一件小事】
他出发那天早上，她在他包里塞了一包饼干，一管护手霜——他执行任务从来不记得涂，手背冬天会裂。她检查了两遍包里的绷带和止血药。够了。她知道这些救不了他。但她还是塞了。

他在门口换鞋的时候，她站在厨房里——没出去送。锅里有煎蛋，铲子还在她手里。他喊了一声："煎蛋别放姜！"她对着灶台上那碟已经切好的姜丝，愣了一下。锅铲放下的声音有点大。

她听见门关上的声音。脚步声在走廊里远了。然后电梯响了一声。电梯门关上的一瞬间她忽然弯腰从垃圾桶里把姜丝捡了回来——他从来不吃姜。但他今天出门的时候说的是"别放姜"。他在提醒她——他不在的时候，饭里不要放姜。因为他不在。

冰箱上她昨天用冰箱贴压着的那张纸条还在："烤箱里有鸡翅。他回来的时候应该刚好。"她昨天写的。写的时候忘了——他不会回来了。

【缺席】
第七天的晚上。那个装反的书架还是老样子——短边朝前，书脊对着墙。她没有去纠正。烤箱里的鸡翅是她吃的。她坐在厨房地上吃的，背靠着冰箱——冰箱贴压着的那张纸条翻过来写了新的一行："第七天。书架等你回来拆。鸡翅我吃了。不好吃。——还是等你回来烤。"

她放下笔，把纸条重新压在冰箱贴上。

烤箱里还有半盘。凉了。但她没有倒掉。因为他回来的话——她停了。她不会再写"他回来的话"了。她把烤箱的温度调低到保温。关上灯。

阳台上那盆枯了一半的花——他上周说要换盆，一直没来得及。她明天去买新盆。不是替他换。是自己换。因为她得学会。
```

**【虐点类型标注】**
- 锚点：装反三次的书架（短边朝前=错误被保留=期待他回来修）
- 伪装预兆："下周应该能把书架搞定"→他不会回来
- 最后的小事："煎蛋别放姜"→提醒她在没有他的日子里该怎么生活
- 缺席表达：烤箱里的半盘鸡翅保温着，阳台上等换盆的花
