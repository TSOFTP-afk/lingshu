# 群像戏编排法

## 技能ID
`SKILL-022`

## 技能名称
在同一场景中让3-6个角色同时在场且各有功能、各有台词、不混乱——每个角色推进剧情或展示性格，没有"背景板"

## 触发场景
- 宗门议事/家庭聚餐/团队作战/多人对峙
- 需要展现多方势力博弈
- 多人场景中某些角色容易"消失"

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 在场角色列表 | array | 是 | 每个角色含姓名、一句话性格、本章功能 |
| 场景目的 | string | 是 | 这场群像戏要达成的剧情推进目标 |
| 谁是本场焦点 | string | 是 | 这场戏的核心视角角色（不一定是主角） |

## 执行步骤

### 步骤1：功能分配——每个角色必须有且仅有一个"不可替代的功能"
**操作**：列出每个在场角色在本场戏中的功能。功能不能重复——提供信息/制造障碍/提供帮助/激化矛盾/提供对比/埋下伏笔。
**要点**：如果两个角色的功能相同——删一个或合并。有角色没有功能——删掉，他不该出现在这场戏里。
**反例**：写了五个人坐在一起开会，只有两个人在说话——剩下三个只是"在场"。

### 步骤2：视角控制——全场只跟一个角色的视线走
**操作**：所有描写——谁在说话、谁什么表情、桌上的杯子被谁碰了一下——都通过"本场焦点角色"的眼睛和耳朵传达。不切换到上帝视角。
**要点**：焦点角色不一定是主角——可以是旁观者，他的"不知情"本身就是戏剧张力。
**反例**：一段话里写了A的心理、B的想法、C的内心独白——视角杂了。

### 步骤3：用"非语言的权力信号"代替解释
**操作**：不写"他是这个房间里地位最高的人"，而是写——他坐下的时候别人都站着的；他端起茶杯，谈话声自动小了一半；他看了一眼门口，守在外面的弟子立刻把门关上了。
**要点**：群像戏最怕解释太多——"张三和李四关系不好"不如"张三坐下的时候把椅子朝远离李四的方向挪了半寸"。
**反例**：旁白解释每个人的背景和立场——读者在读说明书。

### 步骤4：给沉默的角色一句"炸场"台词
**操作**：全场话最少的那个人，在某一个时刻说一句话——这句话改变整个会议的走向。
**要点**：沉默者的台词必须简短——10字以内，但每个人都必须对他这句话产生反应。
**反例**：沉默者从头到尾真的什么也没说——他白来了。

## 输出格式
输出完整的群像场景（500-700字），末尾标注每个角色的功能。

## 完整示例

**输入**：
```
在场角色：
- 掌门（权威，负责最后拍板）
- 二长老（老派保守，功能：提供反对意见）
- 三长老（激进，功能：推动冒险方案）
- 苏默（本场焦点，沉默者，一直靠在门边没说话，最后一句炸场）
- 柳青云（竞争对手，功能：激化矛盾，嘲讽苏默）

场景目的：决定是否派弟子去探查魔族异动——一个九死一生的任务
本场焦点：苏默
```

**输出**：
```
掌门坐在主位——他坐下的时候，二长老和三长老才落座。苏默没有坐。他靠在门边的柱子上，手里端着一杯放凉了的茶。他不打算喝，也不打算说话。他来这里只是因为掌门点名了——"苏默也来。"柳青云坐在二长老下首，目光从苏默进殿的那一刻就没离开过他，像在看一个不该出现在大殿里的清洁工。

"魔窟入口在东南方七十里。"三长老铺开舆图，手指点在图上标注的位置，"探子是活着回来的——进洞不到一刻钟就退出来了。里面的魔气浓度至少需要金丹后期才能抵抗。"

掌门放下茶杯。"需要去一个人。进洞确认魔气来源，如果是天然矿脉，直接封洞。如果是——那位——从沉睡里苏醒了，我们得早做准备。十天之内必须出发。"

"金丹后期，"二长老翻开宗门名册，手指停在某一页。"符合条件的有三个——柳青云，金丹大圆满。王则，金丹后期。还有——"他停顿了一下，没有继续往下念。坐在他下手的三长老轻轻咳了一声。

"我没念完，"二长老合上名册，"但各位应该知道第三个人是谁。他在筑基期登记的表上。"

柳青云站了起来。他的目光扫过殿中每一个人的脸，最后定在门边那个——"诸位长老。我愿意去。"他顿了顿，"但我不明白，为什么苏默每次都来议事大殿。他是筑基期——筑基期连旁听的资格都没有。他坐在这里，每次一个字都不说，然后每次宗门出事的时候他就忽然不在了。"

掌门看向门边。苏默端着那杯茶，姿势和进门时一模一样。"苏默，"掌门的声音很轻，"你有什么看法。"

苏默把茶放在窗台上。这是他今晚第一个动作。他转过身，看着舆图上那个被三长老圈出来的位置。

"那个洞，"他说，"我去年挖地道的时候经过过。底下不是矿脉。是坟场。"

"你怎么知道是坟——"

"因为挖到第三层的时候铁锹磕上了一块碑。碑上刻的字和三百年前封印那位魔主用的碑文一模一样。我没继续挖。我在碑周围补了三层封阵。"

大殿里安静了。安静了很久。然后二长老从袖子里拿出第二本名册——封面上写着"元婴期登记表"。

苏默已经走到门口了。他回头看了一眼柳青云，说了一句在座所有人都没听懂的话："你刚才说——金丹大圆满需要多少天？"

"十天。"柳青云的声音有点哑。

"我去年挖了五条地道。每条通到后山不同山峰。还是同样的路数——先去把地道加固一遍。"他推开门，夜风灌进来，把他没说完的后半句话吹散了。但掌门听清了。

掌门听见的那两个字是：够了。
```

**【角色功能标注】**
- 掌门：最后拍板+抛出任务+窥探苏默底牌
- 二长老：保守派反对冒险+无意中暴露名册有两本（伏笔）
- 三长老：推动激进方案+提供任务参数
- 柳青云：竞争+嘲讽苏默→被现实打脸（激化矛盾功能）
- 苏默（焦点）：沉默→一句炸场改变会议走向→展示实力
