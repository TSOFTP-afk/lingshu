# 情感展示法：用行动替代说明

## 技能ID
`SKILL-004`

## 技能名称
将"他很难过/愤怒/害怕"等情绪说明词转化为可感知的动作、生理反应和环境映射

## 触发场景
- 文本中出现"他感到XX""他非常XX"等情绪说明词时需要改写
- 需要让读者"感受到"而非"被告知"角色情绪
- 关键情感节点需要增强感染力

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 原句 | string | 是 | 包含情绪说明词的句子 |
| 目标情绪 | string | 是 | 悲伤/愤怒/恐惧/喜悦/紧张/羞耻/嫉妒/绝望 |
| 角色性格 | string | 是 | 强势型/温柔型/隐忍型/暴躁型——决定行为方式 |
| 展示深度 | int | 否 | 1=仅动作 2=动作+生理 3=动作+生理+环境，默认3 |

## 执行步骤

### 步骤1：选择"情绪→行为"映射
**操作**：根据目标情绪和角色性格，从下方映射表中选择表现方式。

| 情绪 | 强势型角色 | 温柔型角色 | 隐忍型角色 |
|------|-----------|-----------|-----------|
| **悲伤** | 摔东西→沉默不语 | 默默流泪→强撑笑容 | 喉结滚动→转身离开→关门的声音特别轻 |
| **愤怒** | 拍桌/摔杯/踹门 | 声音发抖但语气克制 | 微笑着把杯子放下→杯底磕出裂纹 |
| **恐惧** | 本能后退一步→随即强迫自己站定 | 指尖掐进掌心→呼吸变浅 | 盯着一处不动→瞳孔微微放大 |
| **喜悦** | 仰头大笑/猛灌一口酒 | 笑出声→眼眶红了 | 低下头→嘴角压不住地上扬 |
| **紧张** | 来回踱步/频繁看表 | 反复整理衣角/舔嘴唇 | 手指有节奏地敲桌面→节奏越来越快 |

**反例**：所有角色情绪都用同一个行为模式表达——强势的人不会默默流泪，隐忍的人不会当众摔东西。

### 步骤2：叠加生理反应
**操作**：在行为描述之后，补充1个角色的身体内部感受。
**要点**：生理反应必须是"内部感知"——不是"他脸色发白"（外部），而是"他觉得喉咙像被人掐住了"（内部）。
**反例**：堆砌3个以上生理反应——过度生理化会变成医学术语堆砌。

### 步骤3：用环境映射放大（选做）
**操作**：用一个环境细节反射角色情绪——不是直接描述环境，而是"角色眼中的环境变了"。
**要点**：同一环境在不同情绪下看起来完全不同——愤怒时雨声像"擂鼓"，悲伤时雨声像"有人一直在哭"。
**反例**："天气阴沉，他的心情也很低落"——环境描写和情绪描写各说各的。

## 输出格式
直接输出一个完整的改写段落，不包含原来的情绪说明词，但通过动作+生理+环境三重展示让读者准确感知目标情绪。

## 质量检验
- [ ] 输出中是否完全没有"他感到""他很""他非常"等直接情绪说明词？
- [ ] 读者读完能否准确说出角色此刻的情绪？（找一个人读一遍测试）
- [ ] 选择的动作是否与该角色的性格一致？
- [ ] 是否有至少1个身体内部感受？

## 完整示例

**输入**：
```
原句：萧寒非常愤怒，因为他发现自己信任了十年的师父一直在骗他。
目标情绪：愤怒
角色性格：隐忍型（不会大喊大叫，但会让周围人感到压迫感）
展示深度：3
```

**执行过程**：
```
步骤1-情绪→行为映射：隐忍型愤怒=微笑着放下东西→物品出现细微损坏
选择：萧寒放下茶杯→杯底磕出一声响→茶盏座面上多了一道裂纹

步骤2-叠加生理反应：
内部感受="他觉得胸口被什么东西堵着，嗓子眼发紧"——只写一个

步骤3-环境映射放大：
师父还在说话——但萧寒已经听不见内容了。只听见声音变成嗡嗡的底噪。
→ 情绪改变了角色对环境的感知
```

**输出**：
```
师父还在说。说着十年前那个雨夜，说着韩家满门是怎么被逼死的，说着他是如何"出于无奈"。语气平静得像在念一份公文。

萧寒把茶杯放了下来。

杯底磕在紫檀木桌面上，声音不大。但一直说个不停的师父忽然住了口——他看了一眼那只茶杯，看了一眼茶盏座上多出的那道裂纹。

萧寒站起来，拱了拱手。

"师父教诲，弟子记住了。"
语气恭敬。一个字都没错。

他没看师父的眼睛，转身走出门。走到院子里，那场十年前就应该开始下的雨终于落了下来。

他站在雨里，觉得嗓子眼像被什么东西堵住了——不是想哭。是有什么东西要从胸腔里挤出来。
```
