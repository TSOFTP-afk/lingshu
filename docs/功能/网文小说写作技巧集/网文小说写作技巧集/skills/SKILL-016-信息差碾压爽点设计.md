# 信息差碾压爽点设计

## 技能ID
`SKILL-016`

## 技能名称
设计"主角掌握别人不知道的关键信息→利用信息差在不暴露自身的情况下达成目标"的智力碾压爽点

## 触发场景
- 重生/穿越/预知类剧情
- 主角需要在不暴露自身底牌的情况下扭转局势
- 商战/权谋/考试/比赛等竞争性场景

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 主角掌握的信息 | string | 是 | 主角知道而其他人不知道的内容（重生的未来记忆/穿越的现代知识/职业经验） |
| 对手的盲区 | string | 是 | 对手因为缺少这条信息正在做什么错误决策 |
| 信息释放方式 | string | 是 | 主角如何让信息产生作用——直接利用/暗示他人/提前布局 |
| 效果展现 | string | 是 | 信息差生效后的结果 |

## 执行步骤

### 步骤1：先写对手的"自信"决策（占20%）
**操作**：写对手/周围人根据"不完整信息"做了一个看似非常合理、非常自信的决策。
**要点**：对手不能蠢——对手越聪明、推理越严密，信息差的爽感越强。蠢对手被碾压=胜之不武。
**反例**："反派完全没脑子"——读者不会为主角碾压一个傻子而高兴。

### 步骤2：展示主角的"异常"行为（占25%）
**操作**：主角在对手自信决策时做出了一个微小的"异常"选择——在旁人看来不可理喻，但主角平静如水。
**要点**：主角的不合群要写得轻描淡写——"他只是往左挪了一步"。读者会在看到结果后回头惊叹"他那时候就知道会这样"。
**反例**：主角忍不住得意洋洋地解释——破坏了"高手不说话"的氛围。

### 步骤3：信息差爆发——"意外"逆转（占30%）
**操作**：对手的"完美决策"因为某条他们不知道的信息而崩溃。从对手视角看是"意外"——从读者视角看是"必然"。
**要点**：逆转必须完美对应步骤1中对手的每一个"自信推理点"。
**反例**：逆转依赖另一个巧合——不是信息差的胜利，是运气好。

### 步骤4：主角的安静收场（占25%）
**操作**：主角在混乱中安静离场，或者只用一句话淡淡道出真相。不与对手争辩胜利——让事实说话。
**要点**：收场越安静，信息差胜利的余味越长——读者会细细品味主角从什么时候开始布局的。
**反例**：主角长篇大论解释自己多聪明——降低了高手的格调。

## 完整示例

**输入**：
```
主角掌握的信息：重生者，知道三天后考试会临时换考纲——从《理论物理》换到《量子计算导论》
对手的盲区：全班同学都在拼命刷《理论物理》的历年真题
信息释放方式：主角看似"偷懒不复习"，实际上三天前就开始刷量子计算
效果展现：全班挂科，只有主角一个人考了满分
```

**输出**：
```
【对手的自信决策】
自习室座无虚席。每个人桌上都堆着同一本书——《理论物理》，扉页上印着去年的考纲编号。这本书过去五年都没变过。班长考前两周就在群里发了公告："今年的题应该跟前两年差不多。重点复习热力学三大定律和薛定谔方程。我这有去年A卷，要的私。"

苏棠的同桌借到了A卷之后连夜刷了三遍。早自习的时候趴在桌上，从胳膊肘缝里露出一句话："这次稳了。"

苏棠说："嗯。"

她在看一本叫《量子计算导论》的书——封面上没有任何考试编号。

【主角的"异常"行为】

考前三天，班长在群里发了一段考场座次表。紧接着有人截图转发教研室群里的一句闲聊——配了一张截图，截图里教务老师发了五个字："今年教考分离。"

群里炸了："教考分离什么意思？""出题老师不是教课的老师？""那出什么题啊？"

苏棠没回群消息。她合上了《量子计算导论》，打开一本笔记本，在上面画了一张量子纠缠态的原理图。同桌探过头来的时候，她把笔记本翻到背面——背面画着一只猫。

"你在干什么？"

"画猫。"苏棠说。"薛定谔的猫。你应该也是。"

同桌笑了："考前画猫，你是真不怕挂科。"

【信息差爆发】

监考老师发下试卷的时候，教室里的空气变了。第一排的班长翻开卷子——然后整个人僵住了。

"老师——这题纲不对。"

"教考分离，今年起换新纲。"监考老师低头看了一眼手表，"《量子计算导论》，第三章到第六章。有问题考后申诉。现在——开始答题。"

自习室里翻了一整天的纸张声在这一秒全部停止了。取而代之的是一种沉重的寂静——有人在倒吸冷气，有人把额头磕在桌面上。同桌的手停在卷面上空，笔尖悬了半晌——她根本不是量子计算方向的。

苏棠翻到最后一题——量子纠缠态的数学描述。她在笔记本上画的那只猫，正好蹲在这一页的左上角。

她开始写。笔在纸面上走得很轻——但她听见周围全是空白页翻来翻去的声音和有人用橡皮擦用力擦掉什么的声音。

【安静的收场】

考完出来的时候，走廊上聚着一圈人。班长在大声说着什么——"教务处凭什么临时换纲——"

苏棠从他们身边走过去。同桌追上来，手里攥着那张大半空白的卷子。

"你考的怎么样？"同桌问。

"还行。"

"你不是在画猫吗——"

苏棠看了她一眼。没有解释她画的那只猫——在量子力学里叫做"叠加态"。生和死同时存在。考试大纲也是。

走到分岔路口的时候她说："我往这边。"
