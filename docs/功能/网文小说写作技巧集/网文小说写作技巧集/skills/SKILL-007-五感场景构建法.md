# 五感场景构建法

## 技能ID
`SKILL-007`

## 技能名称
为任意场景注入视觉/听觉/嗅觉/触觉/味觉五感细节，从"环境是背景板"升级为"环境是情绪容器"

## 触发场景
- 场景描写空洞，只有视觉描述
- 需要让读者产生"身临其境"的沉浸感
- 用场景氛围暗示角色心理状态

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 场景类型 | string | 是 | 室内/室外/自然环境/战场/城市/特殊空间 |
| 场景基调 | string | 是 | 压抑/温馨/恐怖/孤独/紧张/释然 |
| 角色情绪 | string | 是 | 角色此刻的心理状态，用于"感受映射" |
| 感官数量 | int | 否 | 默认3（视觉+听觉+嗅觉），最多5 |

## 执行步骤

### 步骤1：视觉——从大到小，从远到近
**操作**：选择一个视角焦点，按"远→中→近→特写"推进。
**要点**：不写"房间很破旧"——写"墙皮掉了一块，露出里面的土坯。缺角的木桌边上挂着一缕灰。"
**反例**："这是一个美丽的山谷，鲜花盛开，风景如画"——笼统形容词=无画面感。

### 步骤2：听觉——加入动态声音
**操作**：在静态画面中插入至少1个动态声音。
**要点**：声音必须有"时间感"——不是"有鸟叫声"，而是"每隔一阵子，远处的林子里会传来一声不知名的鸟叫。"
**反例**：只说"很安静"——安静可以通过"能听到很远很远的水滴声"来表现。

### 步骤3：嗅觉/触觉/味觉——选1-2种注入
**操作**：根据场景类型选择最有辨识度的感官。
- 室内→嗅觉（霉味/茶香/血腥味/旧书味）
- 室外→触觉（风的温度/湿度/阳光的热度）
- 食物/药材相关→味觉
**要点**：嗅觉是人类记忆最深层的感官——一个气味可以瞬间建立代入感。
**反例**：五个感官全部堆上——信息过载。

### 步骤4：情绪映射——让环境"染上"角色的情绪
**操作**：将1个环境细节扭曲为角色情绪的投射。
**模板**："如果角色是XX情绪，那这个环境细节看起来就像XX。"

| 情绪 | 同一环境看起来是什么样 |
|------|----------------------|
| 愤怒 | "雨声像千万根针扎在铁皮屋顶上" |
| 悲伤 | "雨声像有人在哭，哭了很久很久" |
| 释然 | "雨停了。空气里有股洗干净了的清爽" |
| 恐惧 | "雨声里好像混着什么别的——像是有人在雨里走" |

**反例**：环境描写和人物情绪各说各的，缺乏融合。

## 输出格式
输出一个60-100字的环境描写段落，包含至少3种感官细节和1处情绪映射。

## 质量检验
- [ ] 是否包含至少3种感官？
- [ ] 是否有1处视觉+1处听觉？
- [ ] 是否有1处环境映射了角色情绪？
- [ ] 是否完全没有"很美""很破""很安静"等笼统形容词？

## 完整示例

**输入**：
```
场景类型：室内——老旧书房
场景基调：压抑、秘密即将揭晓
角色情绪：紧张、不安
感官数量：3（视觉+听觉+嗅觉）
```

**执行过程**：
```
步骤1-视觉→远中近：
远：书房不大，顶到天花板的书架把四面墙都吞掉了。
中：书桌上摊着一本翻开的日记。
近(特写)：日记边角卷了起来，纸页泛黄。那页的最后一行写到一半就断了——笔尖在纸上戳了一个洞。
(特写"中断的笔迹"=暗示不寻常)

步骤2-听觉：
只有壁炉里的火在噼啪响。但每响一下，墙角那座老钟的钟摆就跟着晃一下，像在数什么。
(动态声音+"像在数什么"=不安感)

步骤3-嗅觉：
空气里有一股老书特有的味道——纸浆、灰尘、还有一丝若有若无的霉。不是那种令人不适的霉，是那种"很久没人来过"的霉。
(嗅觉建立"被遗忘的空间感")

步骤4-情绪映射：
壁炉的火光映在墙上。影子在动。主角盯着日记上那个戳破的洞——不知道为什么，总觉得那页纸的另一面写的不是字，是一个名字。
(环境扭曲→日记上的洞=心里的不安)
```

**输出**：
```
书房被四面顶到天花板的书架吞掉了。书桌上摊着一本翻开的日记，纸页泛黄，卷起的边角被什么重物压过——翻开的那一页，最后一行写到一半就断了。笔尖在纸上戳了一个洞。

壁炉里的火在噼啪响。每响一下，墙角那座老钟的钟摆就跟着晃一下，像在数什么。

空气里有老书、纸浆和灰尘的味道。还有一种霉——不是令人不适的那种。是"很久很久没人来过"的那种。

火光在墙上晃动。影子也跟着晃动。主角盯着日记上那个戳破的洞——总觉得这页纸的另一面写的不是字。

是一个名字。
```
