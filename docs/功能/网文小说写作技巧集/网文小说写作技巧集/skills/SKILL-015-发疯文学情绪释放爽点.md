# 发疯文学情绪释放爽点设计

## 技能ID
`SKILL-015`

## 技能名称
设计"主角在被压抑到极限后，用不合常规但极度痛快的'发疯'行为撕碎规则"的情绪宣泄型爽点

## 触发场景
- 主角长期被规则/关系/职场压榨，需要一个情绪出口
- 读者渴望看到"直接掀桌"而非"忍辱负重"
- 穿书/重生文中主角拒绝按原剧情走——开始"发疯"

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 压抑源 | string | 是 | 什么在压主角——系统规则/社会期待/家族枷锁/剧情设定 |
| 具体导火索 | string | 是 | 哪一件事触发了主角的"不装了"时刻 |
| 发疯行为 | string | 是 | 主角做了什么打破规则的事——必须有创意而非纯暴力 |
| 旁观者反应 | string | 是 | 周围人被主角的"发疯"震惊/不解→然后微妙地被感染 |
| 情绪落点 | string | 是 | 发疯之后是什么——轻松/自由/悲凉/新的开始 |

## 执行步骤

### 步骤1：极限压抑——让读者和主角一起窒息（占25%）
**操作**：写主角在这个规则系统中反复被压榨的具体瞬间——至少3个细节，让读者感受到"这个系统不是针对主角一个人，而是对所有像主角这样的普通人"。
**要点**：压抑必须是结构性的、系统性的——不是某个具体坏人干的坏事，而是一套"看起来很正常"的规则在无声地消耗主角。这种压抑比"被坏人欺负"更让当代读者共鸣。
**反例**：一个纯反派欺负主角——这还是在传统打脸框架里。

### 步骤2：导火索——"我受够了"的触发点（占15%）
**操作**：一个具体的事件成为最后一根稻草。这个事件本身可能很小——但因为它完美地复刻了主角以往所有被压抑的经验，所以引爆了。
**要点**：导火索越小、越日常，越有共鸣——"老板在全员群里@你让你周末加班，明明不是你的活"比"反派杀了你全家"更让2026年的读者拳头硬。
**反例**：导火索太极端——读者会觉得"如果是我不会因为这种事爆发"。

### 步骤3：发疯——撕碎规则（占40%）
**操作**：主角用一个不合常规的、有创意的、令人拍手称快的行为粉碎压抑系统。
**要点**：
- 发疯≠无差别暴力——发疯是有方向的、有逻辑的、服务于"拆解规则"的
- 必须让读者产生"我也想这样！"的代入感
- 发疯的方式越有想象力，爽感越强——"她把老板桌上那盆'公司是我家'的绿植抱起来，放在了自己的工位上。'我家，我拿的。'"
**反例**：发疯变成了纯粹的破坏——没有"拆解规则"的智力快感，只有宣泄，效果大打折扣。

### 步骤4：余波——发疯之后的世界（占20%）
**操作**：写发疯带来的连锁反应——震惊的旁观者中有一个人微妙地被感染了（"原来可以不这样的"）；规则系统出现了一条裂缝；主角站在废墟（或新起点）上。
**要点**：不要写"然后所有人都鼓掌叫好"——现实不是这样。现实是有人震惊、有人不安、有人在角落里偷偷笑了——这种复杂性才让发疯有重量。
**反例**：发疯后一切恢复原状——浪费了情绪积累。

## 输出格式
输出完整四段结构场景（500-700字），末尾标注"发疯的类型"和"拆解了什么规则"。

## 完整示例

**输入**：
```
压抑源：修仙宗门——主角穿成"药奴"，每天无偿给所有弟子炼药，宗门用"师徒恩情"道德绑架
导火索：宗门大比，主角发现自己的炼药成果被署名成了别人——而所有师兄弟都觉得"这很正常，你是药奴嘛"
发疯行为：主角把丹炉搬到宗门大殿门口，当着所有长老的面把所有丹药倒进河里——然后宣布"从今天起，我出一颗丹药，宗门付一颗灵石的价。不付？你们自己炼。"
旁观者反应：一开始震惊愤怒→安静下来后，几个同样被压榨的外门弟子眼神变了
情绪落点：主角走出了大殿。殿外的阳光有点刺眼。这是她第一次觉得——空气里没有硫磺和朱砂的味道。
```

**输出**：
```
【极限压抑】
苏锦棠穿成药奴第七十三天，学会了用脚趾在鞋底抠三个洞。不是脚痒——是丹炉房的地面常年六十度，鞋底不透气，脚心已经烤出一层厚茧。她一开始会疼得咧嘴。后来不疼了。不疼比疼可怕。

她每天炼三百颗培元丹。分配给内门弟子当零食吃——有些人一天嚼十几颗，嚼完说"今天的丹怎么有点苦"。

昨天她熬了一夜，赶在宗门大比前炼出一炉凝神丹。大比前三名各赏一颗。她蹲在丹炉边上的时候，听两个外门弟子路过聊天："听说这次凝神丹是柳师兄炼的。""柳师兄——咦，不是苏药奴一直在丹炉房吗？""苏药奴一个炼杂丹的，凝神丹哪有她的份。"

她没出声。把凝神丹交上去的时候，管事的连眼皮都没抬，在"经手人"那一栏写了——"内门弟子柳青云监制"。

【导火索】
大比第一天的早晨。苏锦棠端着三十碗醒神汤走进内门膳堂。柳青云坐在首席——她炼的凝神丹就搁在他手边，瓷瓶上贴了红纸，写着"柳青云赠"。他的师兄弟在起哄让他讲凝神丹的配方。他真的在讲。

"火候要控在文火三转——"

苏锦棠手里那碗醒神汤还在托盘上热着。她听见自己开口了。声音不大——大得够整桌人闭嘴。"你说文火三转。"她把托盘放下，"那凝神丹第四转需要猛火破壁三息——你是怎么做到既文火三转，又猛火破壁的？"

安静。

柳青云的脸从红变灰。"我——"

"你不知道。"苏锦棠替他笑了。"因为这炉丹是我炼的。"

膳堂里鸦雀无声。然后有人轻轻说了一句："她是不是炼药炼疯了。"

苏锦棠转身走出膳堂。她没有回丹炉房——她推开了宗门大殿的门。长老们正在议事。

【发疯】
"我是苏锦棠。编号外门七三四。"

十二位长老抬起头。主位上的大长老——就是三年前签了她药奴契的那个人——皱起了眉头。"大殿议事。外门弟子不得擅入——"

"我只说两件事。"

苏锦棠从袖子里掏出那个瓷瓶。柳青云的凝神丹。她把瓶口的红纸撕下来扔在地上，把丹倒在手心里。"这颗丹，是我炼的。从头到尾没有第二个人碰过。柳青云连丹炉长什么样都不知道。"

她顿了顿。

"第二件事。"她回头看了一眼殿外——广场上已经围了不少弟子。"你们谁要丹——谁就付灵石。凝神丹市价三十灵石一颗。我按二十收——毕竟你们也是老客户了。"

大殿里安静了足有五息。

"大胆——"

"我不是大胆。"苏锦棠的声音比刚才更轻了。"我是出了丹炉房才发现——原来太阳底下不需要硫磺和朱砂也能活着。你们觉得我疯了？我只是不炼了。"

她把那颗凝神丹放进嘴里，嚼了嚼，咽下去。"自己炼的丹，自己吃。味道还行。"

【余波】
苏锦棠走出大殿的时候，广场上的人自动分成了两半——一半面带怒意，一半不敢看她。她走出山门的时候，身后有脚步声。

一个外门弟子追了上来。手里攥着一个小布袋。

"那个……苏师姐。"他犹豫了一下，把布袋塞进她手里。"这是二十灵石。你能不能……给我炼一颗凝神丹？"

苏锦棠低头看着布袋。粗布。手缝的。

她忽然觉得药奴这七十三个用脚趾抠鞋底的日子——其实也挺好的。正是因为过了那些日子，她才知道二十颗灵石对一个外门弟子意味着什么。

"行，"她说，"你先回去。丹炼好了我送到你手里——不走宗门登记。"

少年跑回去了。苏锦棠站在山道上，春天的风从山脚灌上来，吹得她的袖子猎猎作响。空气中真的没有硫磺味了。

【发疯类型】日常累积型发疯——非单一事件触发，而是被系统性压榨后的"不想玩了"
【拆解的规则】"药奴身份"=无偿劳动+署名权被剥夺+默认接受——主角用退出契约拆解了这套隐性剥削
```
