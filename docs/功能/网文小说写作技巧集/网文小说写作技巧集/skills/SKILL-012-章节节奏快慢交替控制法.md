# 章节节奏快慢交替控制法

## 技能ID
`SKILL-012`

## 技能名称
在单章2500字内按"快→慢→快→慢→最快(钩子)"五种节奏编排段落，控制读者的阅读呼吸感

## 触发场景
- 写完一章感觉"节奏太平"需要调整
- 需要让读者在紧张和喘息之间交替
- 设计高潮段落的节奏曲线

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 本章核心事件 | string | 是 | 这一章要完成的主要情节 |
| 本章情绪基调 | string | 是 | 紧张/日常/悲伤/兴奋/悬疑 |
| 前一章结尾状态 | string | 是 | 上一章结束时的节奏（延续/转向） |

## 执行步骤

### 步骤1：划分五个节奏分区
**操作**：将2500字按以下比例分配。

| 区号 | 字数 | 节奏 | 功能 | 写法 |
|------|------|------|------|------|
| ①开头 | 前300字 | **快** | 承接上章钩子，抛出新矛盾 | 短句为主，5-10词 |
| ②展开 | 300-1000字 | **慢** | 展开场景、铺垫情绪、交代细节 | 中长句，15-25词 |
| ③升级 | 1000-1800字 | **快** | 冲突升级，事件推进 | 短句+动词密集 |
| ④蓄力 | 1800-2200字 | **慢** | 主角的反思/盟友的对话/暂时的喘息 | 长句为主，停顿和留白 |
| ⑤钩子 | 2200-2500字 | **最快** | 突发转折/悬念/威胁→章末钩子 | 极短句，节奏急剧加速 |

### 步骤2：控制每区的句子长度
**操作**：快节奏区 = 60%以上句子≤10词；慢节奏区 = 50%以上句子≥20词。
**检测方法**：写完每区后统计平均句长。

### 步骤3：在区与区之间设置"过渡句"
**操作**：每个节奏切换点之前，用一句过渡句缓冲——避免读者感受到"急刹车"或"猛踩油门"。
**模板**：
- 慢→快的过渡："[角色]还没来得及细想——[突发事件]"
- 快→慢的过渡："一切安静下来之后，[角色]才注意到[一个细节]。"

### 步骤4：在⑤钩子区加速到最快
**操作**：钩子区（最后300字）的句子越来越短——从10词→8词→5词→3词→戛然而止。
**要点**：最后一句话控制在10字以内，效果最强。
**反例**：钩子区还在用中长句——读者感受不到"紧迫到必须翻页"的冲动。

## 输出格式
输出2500字完整章节，在每区开头标注【区号+节奏】，在每区末尾标注过渡句。

## 质量检验
- [ ] 五个区的字数比例是否大致符合模板？
- [ ] 快区的短句占比是否≥60%？
- [ ] 钩子区的最后一句是否≤10字？
- [ ] 每两次节奏切换之间是否有过渡句？

## 完整示例

**输入**：
```
本章核心事件：主角发现师父书房暗格里的密信，得知自己身世可能与二十年前灭门案有关
本章情绪基调：紧张→悬疑
前一章结尾状态：慢（主角在师父书房整理）
```

**执行过程**：
```
【区①-开头-快(300字)】
承接上章"整理"场景→突然发现暗格→节奏加速。全用短句。
过渡句："他还没来得及细想——手指已经探了进去。"

【区②-展开-慢(300-1000字)】  
展开暗格里的物品(密信、旧照片、半块玉玦)。仔细描述物品细节。中长句为主。
过渡句："他看着那半块玉玦，忽然觉得喉咙里堵了什么。"

【区③-升级-快(1000-1800字)】
密信内容逐渐拼出真相——每一句话都让主角更接近"那个可怕的结论"。短句+动词密集。
过渡句："窗外传来脚步声。他回头看——没有人。但脚步声还在。"

【区④-蓄力-慢(1800-2200字)】
主角强迫自己冷静，回忆起师父这些年的种种反常行为。长句，大量内心独白式的反思。
过渡句："他重新看向那封信。还有最后一段没读。"

【区⑤-钩子-最快(2200-2500字)】
最后一段信的内容——不是文字，是一个地址。而那个地址的隔壁，就是他从小长大的家。
句子越来越短：10词→8词→5词→3词。
最后一句："师父的脚步声。在楼梯口。越来越近。"
```

**输出**：
```
【区① 开头·快】
苏锦棠拿起桌角的镇纸——指尖碰到一处微微凸起的纹理。不是木头本身的纹路。

暗格。

按下去，抽屉底部的一块木板无声弹起，露出一个巴掌大的夹层。他还没来得及细想——手指已经探了进去。

【区② 展开·慢】
夹层里是四样东西。

半块玉玦，断口处包了一层薄薄的金箔——这种工艺叫"金缮"，不是补，是承认残缺之后用黄金把碎裂的痕迹变成花纹。只有长安城的老匠人会做。

一封信。信纸的折痕已经薄得快要断裂了。墨是旧的——但文字不是师父的笔迹。那种略带倾斜的魏碑体，他只在另一个地方见过：挂在祠堂里的那幅"韩氏宗族族谱"。落款写着——韩仲卿。那是韩家灭门前最后一任族长的名字。

一张褪色的照片。上面是一个妇人抱着一个婴儿。妇人额角有一点胭脂色的胎记，像一瓣桃花落在眉梢。

他看着那半块玉玦，忽然觉得喉咙里堵了什么。

【区③ 升级·快】
信的内容不长。一共六行。

第一行写军饷被调包的时间。第二行写调包执行人的名字——师父的名字。第三行是一句批注："秦君所为，实出无奈。"

第四行他看不清了。手在抖。

苏锦棠强迫自己深吸一口气，继续往下读。第五行写着韩家灭门的真相——不是寻仇，不是意外。是灭口。朝廷少了一笔三百万两的军饷，需要一个替罪羊。韩仲卿发现了这件事，所以韩家必须消失。

第六行只有四个字："吾儿尚存。"

窗外传来脚步声。他回头看——没有人。但脚步声还在。

【区④ 蓄力·慢】
苏锦棠用左手按住右手的手腕，把信放回暗格。

很多年了，他一直在追问一个问题：为什么这么多江湖人追杀韩家满门，却唯独放过了方生一日的新生儿。师父说那是"命"。师娘说"老天开恩"。同门的师兄们从不提这个话题——每次他问起来，他们就转开眼睛。

现在他知道为什么他们转开眼睛。不是回避。是知道答案但不敢说。

他重新看向那封信。还有最后一段没读。

【区⑤ 钩子·最快】
信的最后一段不是文字。

是一个地址。长安城东，朱雀大街，第一百零七号。隔壁一百零八号——是苏锦棠长大的那座院子。他从小住到十五岁，直到被师父接上山。师父说，那是他亲生父母的故居。

师父。脚步声在楼梯口。

越来越近。
```
