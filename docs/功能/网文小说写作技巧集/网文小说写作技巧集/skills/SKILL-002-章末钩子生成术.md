# 章末钩子生成术

## 技能ID
`SKILL-002`

## 技能名称
根据前文内容自动匹配并生成5种不同类型的章末钩子

## 触发场景
- 写完一章正文后，需要生成章末钩子
- 章节结尾感觉平淡，需要增加追读驱动
- 读者数据显示"下一章点击率低"，需要强化钩子

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 本章核心事件 | string | 是 | 这一章发生了什么事（50字概括） |
| 主角当前状态 | string | 是 | 主角此刻的情绪/处境 |
| 下一章预告 | string | 否 | 如果已知下一章方向则提供 |
| 钩子偏好类型 | string | 否 | 指定类型，不指定则自动匹配最优 |

## 执行步骤

### 步骤1：分析前文，确定最佳钩子类型
**操作**：根据本章核心事件和主角状态，从5种钩子类型中自动匹配。
**匹配规则**：
- 本章是战斗/冲突 → 优先 **[威胁钩子]** 或 **[情绪钩子]**
- 本章是日常/过渡 → 优先 **[信息钩子]** 或 **[悬念钩子]**
- 本章是重大揭露 → 优先 **[反转钩子]** 或 **[信息钩子]**
- 本章是低谷/失败 → 优先 **[选择钩子]** 或 **[悬念钩子]**

### 步骤2：按匹配类型生成钩子
**操作**：使用对应模板生成钩子，每种钩子30-80字。

**类型1：悬念钩子（适用率82%）**
模板："[角色] [做了一个反常动作/发现了一个反常事物]，但 [不给解释]。"
要点：反常对象必须与本章内容有关联，不能凭空出现。
反例："突然门铃响了"——过于随机，和本章内容无关联。
正例（续SKILL-001苏锦棠场景）："她把信藏回袖中。站起身来的时候，忽然发现祠堂的香炉里插着三炷香——两短一长。这不是祭祖的规矩。有人在她跪着的时候来过。"

**类型2：威胁钩子（适用率67%）**
模板："[一个明确的危险/倒计时]正在逼近 [主角在乎的人或事]，而 [主角] [还不知道/无力阻止]。"
要点：威胁必须具体量化——"三个时辰"比"很快"有力；"脚步声从走廊尽头传来"比"危险即将降临"有力。
反例："一场更大的危机正在酝酿"——太模糊，读者无法产生紧迫感。

**类型3：情绪钩子（适用率54%）**
模板："[主角] [做了一个有情绪张力的短动作/说了一句有情绪张力的话]，然后 [章节戛然而止]。"
要点：定格在"情绪峰值"——不要写情绪消散后的余韵，要停在爆发的瞬间。
反例：写完爆发之后还写了"他慢慢平静下来"——钩子被稀释。

**类型4：信息钩子（适用率48%）**
模板："[主角] [发现了一个信息碎片]：[一句简短但颠覆认知的话/一个画面]。"
要点：信息必须是"炸弹级"——一章只放一个，多了不值钱。
反例："他发现了一个秘密"——不能这样模糊处理，必须给出具体内容。

**类型5：选择钩子（适用率28%）**
模板："[主角]面前 [两个不可兼得的选择]。 [A选项]。[B选项]。他必须在 [极短时间]内做出决定。"
要点：两个选项都必须有真实的代价——不能一个明显好于另一个，否则不算"两难"。

### 步骤3：输出钩子质量自检
- [ ] 钩子内容是否与本章剧情有直接因果关联？（不能是"突然"发生）
- [ ] 读者读完钩子会不会在心里问一个问题？（"是谁？""为什么？""然后呢？"——必须有一个）
- [ ] 钩子是否控制在80字以内？（超过=太啰嗦=冲击力被稀释）

## 输出格式
输出1-3个候选钩子，标注每个钩子的类型和预期产生的读者追问。

## 完整示例

**输入**：
```
本章核心事件：苏锦棠在婚宴上当众揭发嫡母与马夫通奸，嫡母被押走，婚宴大乱
主角当前状态：表面上冷静但内心疲惫，刚完成复仇的第一步
```

**执行过程**：
```
步骤1-匹配：本章是"重大揭露"，优先匹配【反转钩子】和【信息钩子】

步骤2-生成：
候选A【反转钩子】："苏锦棠看着嫡母被拖出喜堂。她终于赢了。她转过身——
父亲站在她身后，手里拿着一封信。信封上的笔迹，是她三年前在庵里学的那一手小楷。'棠儿，'父亲的声音很轻，'这封信——为什么会在马夫的枕头底下？'"

候选B【信息钩子】："喧闹散去。苏锦棠独自走进嫡母的卧房——她要拿走剩下的证据。打开妆奁的最底层，她没有找到信。她找到了一个婴儿的襁褓，上面绣着'苏锦棠'三个字。襁褓里夹着一张字条——'此女非苏家血脉，乃妾与林家孽子所生。'落款：十七年前的接生婆。"

步骤3-自检：
A ✓ 与本章直接关联(嫡母被押→父亲手握反证) ✓ 读者追问"为什么信会在马夫那里？" ✓ 60字
B ✓ 与本章直接关联(寻找证据→发现更大秘密) ✓ 读者追问"她是谁的女儿？" ✓ 75字
```

**输出**：
```
【反转钩子】推荐使用
苏锦棠看着嫡母被拖出喜堂。她终于赢了。
转过身——父亲站在她身后。手里拿着一封信。
信封上的笔迹是她自己的——三年前在庵里学的那一手小楷。
"棠儿。"父亲的声音很轻。"这封信——为什么会在马夫的枕头底下？"

→ 读者追问：信为什么会在马夫那里？苏锦棠怎么解释？
```

```
【信息钩子】备选
喧闹散去。苏锦棠独自推开嫡母卧房的门。
妆奁最底层没有信。只有一个婴儿襁褓——上面歪歪扭扭绣着三个字：苏、锦、棠。
襁褓里夹着一张泛黄的字条。
"此女非苏家血脉。乃妾与林家孽子所生。——接生婆王氏，庚辰年三月初七。"

→ 读者追问：苏锦棠是谁的女儿？这十七年她认错了谁？
```
