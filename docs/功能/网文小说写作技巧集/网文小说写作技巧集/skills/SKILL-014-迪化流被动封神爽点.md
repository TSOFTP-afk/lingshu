# 迪化流被动封神爽点设计

## 技能ID
`SKILL-014`

## 技能名称
设计"主角做了一件普通小事→配角脑补成深谋远虑→主角被动获益"的躺赢型爽点

## 触发场景
- 迪化流/脑补流/被迫封神类剧情
- 需要展示主角"运气逆天"而非"实力逆天"
- 想要一种轻松的、不需要主角拼命的爽感

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 主角的普通行为 | string | 是 | 主角真正做了什么——一件很普通的事 |
| 主角的真实动机 | string | 是 | 主角为什么这么做——越朴实越好 |
| 旁观者的身份 | string | 是 | 谁在脑补——下属/对手/长辈/路人 |
| 旁观者的脑补内容 | string | 是 | 旁观者如何将主角的普通行为解读为惊天布局 |
| 被动收益 | string | 是 | 主角因此获得了什么——声望/资源/地位 |

## 执行步骤

### 步骤1：主角做一件普通的事（占25%）
**操作**：描写主角的行为和真实心理。绝对诚实——主角真的只是随便做的。
**要点**：越朴实越好——"我想偷个懒""今天不想加班""随便选的"。读者的乐趣来自"知道真相"，然后在旁观者开始脑补时产生强烈的喜剧反差。
**反例**：主角其实心机很深故意装傻——这不叫迪化流，这叫扮猪吃虎（老套路）。

### 步骤2：旁观者发现这个行为（占20%）
**操作**：旁观者注意到主角的行为。先写旁观者"一开始觉得奇怪/不解"。
**要点**：旁观者不能是傻子——他必须在自己的认知框架内"合理"地推演。真正好笑的迪化流，旁观者的逻辑链条其实是对的——只是前提错了。

### 步骤3：旁观者脑补推演（占35%）
**操作**：旁观者从主角的普通行为开始，一步步推导出一个惊天阴谋/深谋远虑。
**要点**：
- 每一步推导都必须"如果前提是对的，那推论确实是合理的"
- 推导链条越长越好——从A到B到C到D，每步都合理，但A是错的
- 最后结论越离谱，反差的喜剧效果越强
**反例**：旁观者无脑崇拜——"大佬做什么都是对的"——没有推演过程，不搞笑。

### 步骤4：被动收益+主角浑然不觉（占20%）
**操作**：旁观者因为脑补而做出行动——主角在不知情的情况下获益。
**要点**：主角的反应必须是"啊？发生了什么事？"——这种"无知"和读者"全知"之间的信息差，是迪化流最核心的愉悦感来源。
**反例**：主角立刻利用误会——又回到了心机主角的老路子。

## 输出格式
输出完整四段结构场景（400-500字），标注主角的真实想法 vs 旁观者的脑补推演链。

## 完整示例

**输入**：
```
主角普通行为：用公司打印机打印了一份《劳动法》，因为隔壁工位的同事被无故辞退，他想悄悄塞给对方参考
主角真实动机：纯粹看不过去，随手帮忙
旁观者身份：公司HR总监
旁观者脑补内容：总监发现"这个看似平庸的员工居然在收集劳动法律条文"→脑补他可能在准备劳动仲裁→脑补他背后一定有律师团队→脑补他要搞垮公司→主动给他升职加薪
被动收益：主角被破格提拔，HR总监从此对他毕恭毕敬
```

**输出**：
```
【主角的普通行为】
陈默趁午休时间去打印机那儿扫了一眼——没人。他迅速从口袋里掏出U盘，插进接口。文件名叫"劳动法全文.pdf"。隔壁工位的老周上午被人事叫去谈话，回来的时候只抱了一个纸箱。老周干了八年。陈默觉得至少该让他知道自己有什么权利。

他把打印好的十几页纸对折，夹在一本《程序员入门》里。打算下班的时候塞给老周。就这么简单。

打印机在走廊尽头。HR总监的办公室在走廊另一头。中间隔了七米——那条走廊唯一的监控摄像头正对着打印区域。

【旁观者发现】
总监姓周，42岁，在HR这一行干了十五年，自认阅人无数。他每天午饭后习惯看一眼监控回放。今天，他看到一个平时从不靠近打印机的员工——数据中心运维组的陈默——在午休时间鬼鬼祟祟地打印了一叠文件，然后飞快地藏进一本书里。

"他打印了什么？"周总监本能地警觉了。一个运维——日常从不和打印机关联的角色——突然复印文件还刻意隐藏。在他的职业直觉里，这个行为只有三种解释：泄密、仲裁准备、或者更糟。

【脑补推演】
周总监调出了今天所有打印记录。陈默打印的文件名是"劳动法全文.pdf"。PDF右上角有下载来源水印——市人社局官网。

人社局。

周总监的手指停在鼠标上。

一个运维。趁午休。从人社局官网下载了劳动法全文。打印。隐藏。他昨晚备份了哪些服务器数据？他的运维权限可以访问公司所有内部邮件。

周总监的推演顺序是这样的：
1. 陈默在准备劳动仲裁——否则为什么要下载劳动法？
2. 一个运维准备劳动仲裁——他手上一定有证据，而且是数据证据
3. 他拿到了什么？加班记录？考勤篡改？公司内部不合规的邮件确认？
4. 如果他仲裁成功——公司将被罚至少六位数

周总监当晚没有回家。他在办公室写了一封内部邮件："建议将数据中心运维组陈默即日起晋升为部门副主管，薪资上调40%。并请各部门配合——任何涉及该员工的不合理要求，请第一时间向我反馈。"

【被动收益+浑然不觉】
第二天早上，陈默被通知加薪升职的时候，他正蹲在机房地上修一台宕机的交换机。经理拍着他的肩膀说"小陈啊前途无量"的时候，他脑子里想的是——昨晚塞给老周那本《程序员入门》，老周翻开没有。劳动法条款在68页。

他至今不知道那条走廊有一个监控摄像头。
```

### 核心爽感来源

| 传统打脸 | 迪化流被动封神 |
|----------|-------------|
| 主角主动证明自己 | 主角什么都不用证明，别人帮他证明 |
| 读者爽在"看到反派被碾压" | 读者爽在"我知道真相，而你们全猜错了" |
| 紧张对抗 | 轻松喜剧 |
| 需要主角变强 | 主角可以一直很普通 |
