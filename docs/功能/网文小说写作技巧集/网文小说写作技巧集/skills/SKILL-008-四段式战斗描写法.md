# 四段式战斗描写法

## 技能ID
`SKILL-008`

## 技能名称
按"试探→交锋→压制→终结"四个递进层次写一场打斗，从试探到终结的速度越来越快

## 触发场景
- 主角与敌人发生武力冲突
- 需要展现主角实力成长（同级别险胜→高一级碾压）
- 剧情需要一场战斗作为爽点释放

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 敌我实力差距 | string | 是 | 碾压/小优/均势/劣势/绝境 |
| 战斗类型 | string | 是 | 武力/法术/智斗/机甲/群战 |
| 战斗目的 | string | 是 | 展示实力/逆转命运/保护某人/立威 |
| 篇幅 | int | 否 | 超短(100字)/短(200字)/中(400字)/长(600字)，默认中 |

## 执行步骤

### 步骤1：试探——慢速，互相观察（占15%篇幅）
**操作**：双方都不出全力——反派低估主角，主角在掂量对手。
**要点**：主角的反应必须与"敌我实力差距"参数匹配——碾压关系下主角不动如山，劣势关系下主角警惕谨慎。
**反例**：碾压局主角还在慢慢试探——读者会不耐烦。

### 步骤2：交锋——你来我往（占25%篇幅）
**操作**：双方正式开打。描写1-2个回合的攻防交替。
**要点**：每回合包含"攻击动作→防御/闪避→反制"三个环节。动词必须精准——"刺/劈/砸/扫"比"打"强。
**反例**："两人打了几个回合"——一句话跳过，浪费了战斗描写的全部爽感。

### 步骤3：压制——主角占据上风（占20%篇幅）
**操作**：主角找到破绽，开始压制。
**要点**：主角的压制手段必须与"敌我实力差距"匹配——碾压关系下只需要一招简单的动作+漫不经心的态度；劣势关系下需要智取+利用环境。
**反例**：所有战斗都是"主角大吼一声冲上去"——用一百遍读者就看吐了。

### 步骤4：终结——一击定胜负，快速收尾（占15%篇幅）
**操作**：决定性一击→敌人倒下→尘埃落定。速度从"快"变成"极快"——让读者感受到碾压的爽感。
**要点**：终结技之前要有一个极短的停顿（"他深吸一口气"/"周围的空气凝固了一秒"）——这是读者的"屏息等待"时刻。
**反例**：终结技写得和前面交锋一样长——速度没有递进就没有爽感。

### 步骤5：余韵——战斗后的反馈（占25%篇幅）
**操作**：周围的反应——围观者震惊、盟友松了一口气、敌人恐惧逃窜。
**要点**：如果这是打脸场景，必须有第三方的震惊反馈（参见SKILL-003）。
**反例**：打完直接切下一章——读者的情绪没有"着陆"，高潮感被浪费。

## 输出格式
输出完整的四段式战斗描写，每段标注属于哪个阶段。

## 质量检验
- [ ] 四个阶段的篇幅比例是否大致符合模板？
- [ ] 速度是否从慢→中→快→极快递进？
- [ ] 终结技之前是否有一个极短的停顿？
- [ ] 是否有至少1个精准的动作动词（非"打/踢/撞/推"）？
- [ ] 是否有围观者的反应描写？

## 完整示例

**输入**：
```
敌我实力差距：碾压（主角金丹大圆满，对手筑基后期）
战斗类型：武力
战斗目的：立威
篇幅：中(400字)
```

**执行过程**：
```
步骤1-试探(15%，约60字)：
对手不知深浅，率先出手试探。主角不动。
→"赵阔一剑刺来，剑尖破开空气。"

步骤2-交锋(25%，约100字)：
一个回合内主角展现出碾压级的从容。
→萧炎侧身避开。"只有这种程度？"——一句话既是嘲讽也是展示。

步骤3-压制(20%，约80字)：
对手加大力量，但主角只用最简单的动作就压制了。
→第二拳更猛，但萧炎只是后退一步，卸掉了所有力道。

步骤4-终结(15%，约60字)：
极短的停顿→决定性一击→尘埃落定。
→抬起眼帘→肘击撞入腹部→对方砸向墙壁→碎石四溅。

步骤5-余韵(25%，约100字)：
围观者震惊→权威人物反应→主角离场。
→同伴欢呼→长老点头→主角头也不回地离开。
```

**输出**：
```
【试探】赵阔率先出剑。剑尖破开空气，直刺萧炎咽喉。萧炎没有拔剑——只是侧了侧身，剑刃擦着他的衣领划过去。

【交锋】"只有这种程度？"萧炎抬起眼帘。

赵阔的第二剑加了十成功力。剑风扫过，擂台上的旗帜被削断了绳子。萧炎倒退一步，鞋底在石板上擦出浅白的一痕——然后停住了。

【压制】他没有反击。只是抬起一只手。手掌平摊，接住了赵阔第三剑。剑气撞上他的掌心，像水撞上石头——四下溅开，消散在空气里。赵阔的瞳孔骤然收缩。

【终结】萧炎的五指收拢，握住了剑刃。一扯。赵阔整个人被带得向前踉跄——然后萧炎的肘击已经撞入了他的腹部。

赵阔飞了出去。砸在擂台边缘，碎石四溅。他手里的剑脱了手，插在五尺之外的旗杆上，嗡嗡地抖。

【余韵】整个演武场安静了一瞬。然后爆发出比刚才响十倍的喧哗——"金丹大圆满！他是金丹大圆满！"

"那不是参赛弟子。"掌门放下茶杯，缓缓站起来。"他是本次大比的考官。"
```
