# 信息冰山投放法

## 技能ID
`SKILL-011`

## 技能名称
按"冰山原则"分层投放关键信息——每一章只揭示真相的10%，用信息差驱动读者追更

## 触发场景
- 有重大真相/秘密需要在多章中逐步揭示
- 想让读者持续保持"差一点就猜到了"的追更状态
- 悬疑/推理/阴谋类剧情的信息控制

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 完整真相 | string | 是 | 最终的完整真相是什么 |
| 总章节数 | int | 是 | 计划用多少章揭示这个真相 |
| 当前章节 | int | 是 | 当前是第几章 |
| 前文已揭示信息 | string | 是 | 前文已经让读者知道了什么 |

## 执行步骤

### 步骤1：确定当前章节的信息投放量
**操作**：根据进度比例确定该给读者多少信息。

| 进度 | 该阶段给读者的信息 | 该阶段不给读者的信息 |
|------|-------------------|---------------------|
| 0-20% | 只有异常现象——"事情好像不太对" | 不解释为什么不对 |
| 20-40% | 一个具体线索——"这里有一个可疑的点" | 不解释这个点意味着什么 |
| 40-60% | 两条线索之间出现关联——"A和B可能有关" | 不揭示关联的完整含义 |
| 60-80% | 一个"伪真相"——看似合理解释一切 | 伪真相里藏着一个漏洞 |
| 80-100% | 完整真相揭晓 | — |

**反例**：第5章就把完整真相暗示得太明显——后面45章读者在等什么？

### 步骤2：设计本章的信息投放方式
**操作**：从以下3种方式中选择1种来投放信息。

| 方式 | 操作 | 适合场景 |
|------|------|----------|
| **偶然发现型** | 主角在找别的东西时意外发现了这条信息 | 需要让信息出现得"自然" |
| **对话透露型** | 通过另一个角色的对话不经意间透露 | 需要暗示"某个角色知情但不说" |
| **反消除型** | 主角排除了一种解释——而剩下的那个就是真相 | 需要制造"差一点就猜到了"的感觉 |

### 步骤3：在本章末尾附加一个"伪钩子"
**操作**：在本章揭示信息后，章末加一个能支撑追读但不会剧透下一步的问题。
**模板**："[角色]知道了[本章信息]。但他不知道的是——[一个本章信息引出的新问题]。"
**反例**：章末直接暗示完整真相——跨过了中间的所有阶段。

## 输出格式
输出本章的信息投放段落（50-100字），以及章末伪钩子。

## 质量检验
- [ ] 本章信息是否严格控制在总真相的≤10%？
- [ ] 信息是否自然融入剧情（不是旁白解释）？
- [ ] 章末是否有新问题引出的钩子？
- [ ] 是否避免了"跨阶段透露"？

## 完整示例

**输入**：
```
完整真相：秦不渡是朝廷安插在江湖上的密探，二十年前的"夜不收屠韩家满门"案件，是他受皇命执行的秘密行动——但他放走了韩家唯一的幸存者（主角本人）
总章节数：20章
当前章节：第8章（进度40%——应该给"两条线索有关联"级别的信息）
前文已揭示信息：
- 第3章：秦不渡手指上有薄茧
- 第5章：他走路没声音
- 第6章：主角发现秦不渡认识一种只有朝廷密探才会使用的手语
```

**执行过程**：
```
步骤1-信息投放量：40%进度→给出"两条线索之间的关联"
前文线索3(第6章)可以延伸——"他为什么会朝廷密探的手语？"

步骤2-选择投放方式：【偶然发现型】
主角在找别的东西时（翻秦不渡的账本），意外发现账本夹层里有一份旧档案。

步骤3-设计信息内容（≤10%真相）：
只给"秦不渡二十年前有朝廷身份"这一条——不给"他是奉命执行秘密任务"、不给"他放走了主角"。

伪钩子：主角知道了秦不渡曾是朝廷的人。但新的问题是——一个朝廷密探为什么隐姓埋名在桂花巷开了二十年茶楼？他是在躲谁？
```

**输出**：
```
【本章信息投放】
账本是空的。不对——不是空的。

苏锦棠翻到最后几页，发现纸张的厚度不对劲。他用指甲小心揭开页脚——封皮夹层里有一页折得整整齐齐的旧纸。不是账目。是半张吏部的铨选名册，年份写着庚辰年。在最末尾的一行蝇头小楷旁边，有人用朱笔圈了一个名字。

秦不渡。

下面是三个字："录，内卫。"

吏部名册上的"内卫"，是直属皇上的密探机构。二十年来从不在任何官方档案中留名。秦不渡不是刺客。他是朝廷的人。

【章末伪钩子】
苏锦棠把那张纸塞回夹层。一个内卫密探，二十年前为什么会被记录在"夜不收"的名单上？他隐姓埋名在桂花巷开了二十年茶楼——不是在躲仇家。是在躲谁？

门外传来脚步声。秦不渡回来了。手里的抹布还是那条抹布。但他走路的时候——苏锦棠忽然注意到——他永远用左脚先迈步。右脚的步伐比左脚短了半寸。

那是在膝盖受过重伤之后才会有的走路方式。
```
