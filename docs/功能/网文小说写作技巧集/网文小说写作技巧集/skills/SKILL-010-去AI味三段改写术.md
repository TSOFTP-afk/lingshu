# 去AI味三段改写术

## 技能ID
`SKILL-010`

## 技能名称
识别AI生成文本的模板化特征，按"句式打散→禁用词替换→人味注入"三阶段改写为人类风格文本

## 触发场景
- AI生成的初稿需要改写去模板化
- 文本被读者/编辑反馈"有AI味""太模板化"
- 需要将任何来源的文本注入更多人类特质

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 原文本 | string | 是 | 需要改写的文本段落 |
| 角色视角 | string | 是 | 从谁的视角叙述（影响语气） |
| 改写强度 | int | 否 | 1=轻度润色 2=中等改写 3=深度重写，默认2 |

## 执行步骤

### 步骤1：句式打散——打破句长均匀
**操作**：检测原文本的句子长度分布。将其中50%的"中句"（15-20词）拆成短句（5-8词），将20%合并或扩展为长句（30+词）。
**检测规则**：连续3句以上长度在15-20词之间=AI味警报。
**反例**：只做同义词替换不改句式结构——内核仍是AI味。

### 步骤2：禁用词替换——消除AI高频词
**操作**：扫描并替换以下AI高频词汇。

| AI高频词 | 替换方案（三选一） |
|----------|------------------|
| 值得注意的是 | 直接删除/改"有个细节" |
| 在当今……的环境中 | 用具体时间场景替代 |
| 发挥着重要作用 | 直接用动词描述具体影响 |
| 此外/而且/进而言之 | 删除（段间自然过渡不需要） |
| 总而言之 | 用具体结论自然收束 |
| 不仅……而且…… | 拆成两句，或用"甚至"替代 |
| 不是X，而是Y | 改为直接描述Y或拆成两句 |
| 首先是……其次是……最后是…… | 改为自然过渡，"先看……再看……" |
| 可以说/众所周知/毋庸置疑 | 全部删除 |

**反例**：每遇到一个词就替换为同一个近义词——下一段又被检测出来。

### 步骤3：人味注入——加上人类才写得出的内容
**操作**：从以下五种"人味元素"中选择至少2种注入文本：

| 人味元素 | 操作方法 | 示例 |
|----------|----------|------|
| **一个具体的数字** | 把模糊量词换成精确数字 | "很多年"→"第四十七封信寄出后的第二百一十三天" |
| **一个身体内部感受** | 插入角色的生理感知 | "他觉得喉咙发紧，像吞了一口滚烫的沙子" |
| **一个私人记忆碎片** | 让角色联想到过去的一件事 | "他忽然想起十六岁那年……" |
| **一个不规则的小动作** | 插入不符合场景逻辑但符合人物性格的动作 | "她下意识数了数天花板上的灯管——六根。有一根不亮。她三天前就注意到了。" |
| **一句有瑕疵的对白** | 故意写一句"不像台词的对白" | 不说"我恨你"，而说"算了。你走吧。我懒得恨了。" |

**反例**：注入过多"人味"导致文本混乱——2种元素足够，不需要全加。

## 输出格式
输出改写后的完整段落，并在末尾附上"改写日志"——标注每一处改动的类型和原因。

## 质量检验
- [ ] 原文本中连续"中句"是否已被打散？
- [ ] AI高频词是否已全部替换？
- [ ] 是否至少注入了2种人味元素？
- [ ] 读一遍——听起来像AI在念报告还是像一个人在讲故事？

## 完整示例

**输入**：
```
原文本：
他推开房门之后发现屋子里空无一人。窗户大开着，窗帘被风掀起。桌子上放着一封信，信的内容让他感到非常震惊。他不禁开始思考为什么事情会发展到这个地步，心中充满了疑惑和不安。最后他决定按照信上的要求去做。

角色视角：主角，30岁男性，冷静内敛
改写强度：2
```

**执行过程**：
```
步骤1-句式打散：
检测：原文本5句长度依次为14、11、15、18、12词——2句中句，需要拆分。
操作：
- "他推开房门之后发现屋子里空无一人"→拆成"他推开门。屋子里空无一人。"
- "桌子上放着一封信，信的内容让他感到非常震惊"→拆成"桌上放着一封信。他拆开，只扫了一行——手就停住了。"

步骤2-禁用词替换：
- "心中充满了疑惑和不安"→AI味（"充满了XX和XX"），替换为具体身体反应

步骤3-人味注入：
元素1(身体感受)："手就停住了"+"嗓子发紧"
元素2(私人记忆碎片)："这种笔迹他见过——三年前，在父亲的书房里，在律师寄来的遗产分割协议上。"
元素4(小动作)："他下意识用手指摩挲信封的边角，从左到右，再从右到左。"
```

**输出**：
```
【改写后】
他推开门。屋子里空无一人。

窗户大开着，窗帘鼓起来又瘪下去，像什么东西在呼吸。桌上放着一封信。

他拆开。只扫了一行——手就停住了。这种笔迹他见过。三年前，在父亲的书房里，在律师寄来的遗产分割协议上。一模一样的魏碑体。一模一样的落款。

他下意识用手指摩挲信封的边角，从左到右，再从右到左。嗓子眼有点发紧。他把信折好，放进口袋，站起来关了窗。然后按照信上写的那个地址出了门。

——
【改写日志】
1. "他推开房门之后发现屋子里空无一人"→拆成两句【句式打散】
2. "信的内容让他感到非常震惊"→改为"只扫了一行——手就停住了"【禁用词替换+"充满了XX"=AI味】
3. "心中充满了疑惑和不安"→改为"嗓子眼有点发紧"【人味注入-身体感受】
4. 新增"三年前父亲书房记忆"【人味注入-私人记忆碎片】
5. 新增"摩挲信封边角"【人味注入-小动作】
6. "不禁开始思考"→删除【AI高频词删除】
```
