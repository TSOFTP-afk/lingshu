# 反转设计三步法

## 技能ID
`SKILL-009`

## 技能名称
按"铺垫认知→强化误导→揭晓真相"三步生成一个完整的剧情反转

## 触发场景
- 需要身份/真相/结果的大反转
- 前期已埋伏笔，需要收网
- 读者已形成固定预期，需要打破

## 输入要求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 表面认知A | string | 是 | 读者和角色目前认为的"真相" |
| 真正真相B | string | 是 | 反转后揭晓的真实情况 |
| 已埋伏笔列表 | string | 是 | 前文已埋下的支持真相B的细节 |
| 反转强度 | string | 否 | 温和（读者略有怀疑）/中等（读者没猜到）/强烈（完全颠覆），默认中等 |

## 执行步骤

### 步骤1：铺垫——建立认知A（占25%篇幅）
**操作**：让角色（或读者）对"表面认知A"深信不疑。给出看似充分的理由。
**要点**：理由必须"看起来合理"——如果理由太弱，读者会提前怀疑。但每一条理由后面都要有微小的"裂缝"。
**反例**：铺垫阶段就暗示了真相B——反转失去了冲击力。

### 步骤2：强化误导——巩固认知A（占35%篇幅）
**操作**：通过事件发展，让读者进一步确认"A是对的"。
**要点**：至少用2种方式强化——人物的确认赞同、新证据的出现、逻辑上的"完美闭环"。但每个强化点都必须"回头看时能看出破绽"。
**反例**：误导太明显，读者在第200章就猜到真相了——反转的爽感减半。

### 步骤3：揭晓——真相B爆出（占40%篇幅）
**操作**：一个事件/发现/对白同时粉碎认知A并揭示真相B。
**要点**：
- 揭晓时先给"冲击瞬间"（角色的第一反应/一个震撼画面），再给"解释"（回头串联伏笔）
- "冲击瞬间"和"解释"的比例约为3:7——读者需要时间消化冲击，然后享受"原来那些细节都是伏笔"的恍然大悟
**反例**：揭晓=解释，没有冲击瞬间；或者冲击了之后不解释怎么从A走到B。

## 输出格式
输出三步完整的反转段落，标注每段的阶段和功能。

## 质量检验
- [ ] 反转是否让读者有"原来如此！"的拍大腿感？
- [ ] 揭晓前是否有至少3处支持B的伏笔？
- [ ] 揭晓时是否有"冲击瞬间"+ "伏笔串联解释"？
- [ ] 反转是否合理——回头看前文所有细节都对得上？

## 完整示例

**输入**：
```
表面认知A：茶楼老板秦不渡是个手无缚鸡之力的普通人
真正真相B：他是二十年前江湖上令人闻风丧胆的"夜不收"——前朝第一刺客
已埋伏笔列表：
1. 他"拿抹布擦柜台的手有薄茧"
2. 他"知道只有行内人才懂的暗语"
3. 他"永远叼着没点着的旱烟——因为点着的火光会暴露位置"
4. 他"走路没有声音"
5. 茶楼里"客人总是坐在背对门口的位置"
反转强度：中等
```

**执行过程**：
```
步骤1-铺垫认知A（约100字）：
写秦不渡的日常——懒散、怕事、遇到危险先躲。
"你找错人了。我就是个开茶楼的。"
当主角追问时，他缩了缩脖子，一副小市民的怯懦相。

步骤2-强化误导（约140字）：
两个强化点：
- 强化1：主角的同伴说"我问过街坊了，他在这条街上开了十年茶楼，从没惹过事"
- 强化2：秦不渡被逼急了，抖着手从柜台底下摸出一张泛黄的官府批文——上面盖着"良民"的印
→ 两条线索都指向"他就是个普通人"

步骤3-揭晓真相B（约160字）：
冲击瞬间：主角被仇家围攻。一支箭射来时——秦不渡接住了那支箭。用两根手指。
解释串联：
"你说你是开茶楼的。开茶楼的人手指上不会有那种茧——那是拿刀拿太久磨出来的。你走路没声音。你的客人永远背对门口坐——因为你在教他们怎么防刺杀。"
→ 回头串联1-5条伏笔
```

**输出**：
```
【铺垫——建立"他是普通人"】
"你找错人了。"秦不渡缩了缩脖子，那根旱烟杆在嘴角颤了颤。"我就是个开茶楼的。"

主角一把揪住他的领口。"二十年前，夜不收一夜之间屠了韩家满门。你敢说不是你？"

秦不渡被揪得脚尖离了地，脸上又浮出那副让主角讨厌透了的畏缩表情。"这位爷——二十年前我才十五岁。十五岁的毛孩子能屠人满门？您别开玩笑了。"他回头看了一眼满屋子的茶客，压低声音，"我这还要做生意呢……"

【强化——让读者也相信】
"行了。"同伴拉住了主角，在他耳边低声道，"我问过街坊了。他在桂花巷开了十年茶楼，连隔壁王寡妇养的那只凶猫都没打过。官府档案也调了——正经注册，有良民印。"

同伴把一张泛黄的官纸拍在桌上。上面盖着褪色的朱砂印，字迹模糊但还是能辨认出——"桂花巷三十七号 茶商秦不渡 庚辰年三月立籍"。

主角的手松了松。

【揭晓——粉碎】
一支弩箭破窗而入。不是射向主角——是射向墙角那个始终低着头喝茶的客人。

秦不渡接住了那支箭。

用两根手指。

主角甚至没看清他是什么时候站起来的——直到弩箭的尾羽还在秦不渡指间微微震颤，他才发现这个人站的姿势和刚才不一样了。不是懒洋洋倚着柜台，是侧身半蹲，重心下沉。一种写了二十年才写得进骨头里的姿势。

"你说你是开茶楼的。"主角的声音很轻。"开茶楼的人——手指上不会有茧。那种筋腱隆起的方式，也不是端茶壶能练出来的。"

秦不渡把弩箭放在桌上，慢慢直起腰。他取下嘴里那根旱烟杆——从头到尾没点着过。

"因为点着了的火光，在夜里会暴露位置。"

"你走路没声音。"

"你的客人永远背对门口坐——你在教他们怎么防刺杀。"

秦不渡沉默了很久。然后他笑了——不是刚才那种畏缩的笑。是另一种。

"二十年了。"他把旱烟杆重新叼回嘴里。"我以为你们不会再找过来了。"
```
