# 维护清单

本清单用于保持知识库可查、可用、可扩展。

---

## 一、项目口径

- `README.md` 是总入口，只放已经存在的文件链接。
- `skills/` 是可执行技能库，统计时只计算 `SKILL-*.md`，不计算 `_技能模板.md`。
- `01-` 至 `12-` 开头的目录是参考知识库，当前统计为 48 篇。
- 根目录辅助文档，如 `使用指南.md`、`索引-按任务检索.md`、`维护清单.md`，不计入参考知识库篇数。

---

## 二、新增参考知识文档检查

新增前：

- [ ] 确认分类目录是否已有对应主题，避免重复收录。
- [ ] 使用 `_模板文件.md` 的结构。
- [ ] 文件名遵守 `[类别缩写]-[编号]-[具体主题]-[来源].md`。

正文必须包含：

- [ ] 基本信息表。
- [ ] 核心技巧或核心观点。
- [ ] 详细说明。
- [ ] 适用场景。
- [ ] 经典案例或示例。
- [ ] 常见误区。
- [ ] 相关技巧。
- [ ] 练习建议。

新增后：

- [ ] 更新 README 对应分类表。
- [ ] 更新 README 统计信息。
- [ ] 如该文档适合任务检索，更新 `索引-按任务检索.md`。

---

## 三、新增技能文档检查

新增前：

- [ ] 使用 `skills/_技能模板.md`。
- [ ] 编号使用下一个可用 `SKILL-XXX`。
- [ ] 技能必须能独立执行，不只是一篇理论文章。

技能文档必须包含：

- [ ] 技能ID。
- [ ] 技能名称。
- [ ] 触发场景。
- [ ] 输入要求。
- [ ] 执行步骤。
- [ ] 输出格式。
- [ ] 质量检验。
- [ ] 完整示例。

新增后：

- [ ] 更新 README 的技能表与技能总数。
- [ ] 更新 `使用指南.md` 的常用组合配方。
- [ ] 更新 `索引-按任务检索.md` 的相关问题入口。

---

## 四、定期体检

每次较大更新后执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\validate-project.ps1
```

检查项：

- [ ] README 相对链接全部可打开。
- [ ] README 中技能总数与 `skills/SKILL-*.md` 数量一致。
- [ ] README 中参考知识库总数与 `01-` 至 `12-` 目录下 Markdown 数量一致。
- [ ] 没有把未完成文档提前写进 README。
- [ ] 根目录辅助文档没有被误计入参考知识库。

---

## 五、推荐维护节奏

- 小更新：新增或修改 1-2 篇文档时，只更新相关索引。
- 中更新：新增一个主题簇时，同步更新 README、任务索引、使用指南。
- 大更新：新增目录、改变统计口径、重排编号时，先更新本清单，再更新 README。
