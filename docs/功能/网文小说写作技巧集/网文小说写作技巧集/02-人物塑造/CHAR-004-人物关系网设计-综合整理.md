## 核心技巧

人物关系网决定了长篇小说的扩展空间。六层关系图谱：核心关系圈（直系亲属/挚友/伴侣）→ 次级社交网络（同事/邻居/社团成员）→ 冲突关系（利益对立/价值观碰撞/情感纠葛）→ 师徒传承关系 → 泛社会关系（快递员/店主等背景型角色）→ 已故/缺席人物（对角色影响深远的不在场者）。每一层关系都有明确的功能，功能相同的配角要删减合并。

## 详细说明

### 一、六层关系图谱

**第一层：核心关系圈**
围绕主角设计3-5个核心人物：直系亲属、挚友、伴侣。

- 功能：展现情感深度和依赖关系
- 要求：每个人必须有不同的"功能"——一个提供帮助、一个制造麻烦、一个需要被保护

**第二层：次级社交网络**
同事、邻居、社团成员等。

- 功能：反映主角的社会适应能力和影响力范围
- 要求：通过日常互动展现主角多面性格

**第三层：冲突关系**
三种冲突关系类型：

- 利益对立型：资源争夺、目标相悖
- 价值观碰撞型：理念、道德观的根本冲突
- 情感纠葛型：误会、背叛、嫉妒引发的复杂张力

**第四层：师徒传承关系**
导师/师父/前辈与学徒——这是网文中最能引发共鸣的关系之一。

**第五层：泛社会关系**
快递员、店主等背景型角色——

- 功能：强化真实感
- 要点：一个简短互动即可暗示主角习惯或性格

**第六层：已故/缺席人物**
对角色有深远影响但已不在场的人——已逝的父母、失踪的师父、离开的挚友。

- 功能：角色的行为动机来源
- 要求：不需要出场，但必须持续对角色产生影响力

### 二、关系数量管理

| 角色类型    | 建议数量   | 出现频率占比    |
| ------- | ------ | --------- |
| 主角+核心配角 | ≤5人    | 全书50%-65% |
| 次要角色    | 15-25人 | 25%-40%   |
| 过渡性角色   | 不限     | ≤10%      |

超过5个核心角色会让故事焦点分散。

### 三、关系设计的核心原则

**功能不重复**：如果两个配角的功能完全相同（都是"给主角送情报的人"），删掉一个或合二为一。

**关系要演变**：关系不是静态的。盟友变敌人、敌人变朋友、师徒反目——这些"关系转折"本身就是重要的戏剧冲突。

**借配角透视主角**：配角存在的最终意义是"照亮主角"。一个好的配角能让读者更理解主角。

## 适用场景

- **场景1**：开新书设计人物群像
- **场景2**：写到中期发现人物太多太乱——用六层图谱重新梳理
- **场景3**：设计关系转折事件（师徒反目、兄弟决裂等）

## 经典案例

**案例作品**：《庆余年》- 猫腻

范闲的关系网堪称六层图谱的完美范例：

- 核心圈：范建（养父）、五竹（守护者）、陈萍萍（导师）
- 冲突圈：庆帝（终极对手）、长公主（中间反派）
- 已故人物：叶轻眉（母亲，全书最大的"缺席者"影响力）

## 常见误区

1. **关系数量失控**：写了50章之后配角数量超过30个，读者记不住。
2. **功能完全相同的配角**：三个角色都是"给主角送宝物的"，全删了也没影响。
3. **关系一成不变**：全书写了100万字，人物关系没有任何变化——无聊。
