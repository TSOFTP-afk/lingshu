## 核心技巧

构建人物的三维模型，从社会层面让角色立体化，以独特的个性创造使人物”活起来“，不在局限于一个被创造出来的片面性角色。不同角色（主角、配角、反派）有不同的塑造侧重点：主角功能性大于完美性，配角记忆点大于完整性，反派破坏力大于邪恶值。

## 详细说明

### 一、不同角色的功能选定

**① 主角：功能性大于完美性**

主角人设一定不能太完美。不完美，才能引出更多故事线，而且一般人都不是完美的，不完美的主角可以提升读者的代入感，也更能让读者明白这是一个活生生的人。

- 性格过度自信 → 错过线索做出错误判断 → 引出剧情
- 过度谨慎到一个偏执的级别

但主角的功能性一定要显著——主角之所以成为主角，就是他有其他人做不到的地方（金手指、信息差运用能力等），同时最后的结果一定要是一个正面反馈，不能让主角一直制造麻烦而不解决，这是一个毒点。

**② 配角：记忆点大于完整性**

配角是工具人，用于给主角制造矛盾或解决矛盾。不需要全面描写，只需抓取最独特的记忆点。

- 反面案例：玉树临风的暗卫——看完就忘
- 正面案例：嗜甜如命的暗卫——一提就知道是谁
- 正面案例：结巴的毒医——独一无二的标签

总结：给配角创造一个便于读者记忆的特殊点，相当于给角色搭上了一个特殊的【标签】，以此来帮助读者快速回忆并寻找配对。

**③ 反派：破坏力大于邪恶值**

反派不需要邪恶值拉满，但必须有实际破坏力，给主角带来真实压力。

- 反面案例：心狠手辣但实力菜鸡的反派——毫无威胁，分析：他没有办法给主角带来一定的威胁，顶多就是制造一点小麻烦，不利于剧情推动。
- 正面案例：修为高超但被心魔控制的大能——虽然不一定邪恶，但破坏力惊人，是悬在主角头顶的利剑。

### 二、人物设定的基础模型

| 要素         | 方法                                 |
| ---------- | ---------------------------------- |
| **姓名**     | 贴合世界观的命名                           |
| **年龄**     | 涵盖成长过程（如12岁到30岁）                   |
| **身份**     | 突破常规——双面设定，表面身份+隐藏身份（便于"打脸"）       |
| **外貌**     | 用动态描写代替静态描写（如王熙凤出场："我来迟了，不曾迎接远客！"） |
| **性格**     | 优缺点并存，要有矛盾点                        |
| **金手指/特长** | 限制明确，有代价                           |

## 适用场景

- **场景1**：开新书构思人设时，按三维模型逐一填充
- **场景2**：写到中期发现人物扁平、行为不合理时，回头补全三维模型
- **场景3**：设计反派时，确保"破坏力"足够让读者感到紧张

## 经典案例

**案例作品**：《红楼梦》- 曹雪芹

王熙凤出场——"一语未了，只听后院中有人笑声，说：'我来迟了，不曾迎接远客！'"

**案例分析**：
未见其人先闻其声，动态出场方式立刻展现王熙凤在贾府的特殊地位和张扬性格。这是"用动态描写代替静态描写"的典范。

## 常见误区

1. **主角太完美**：没有缺点的主角没有成长空间，读者没有代入感。
2. **配角抢戏**：配角描写过多，读者分不清谁是主角。
3. **反派纯坏**：没理由地坏，缺乏动机和背景支撑。
