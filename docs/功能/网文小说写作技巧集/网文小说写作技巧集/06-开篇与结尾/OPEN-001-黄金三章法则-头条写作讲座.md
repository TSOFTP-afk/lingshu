# 黄金三章法则：开篇300字定生死

## 基本信息

| 字段       | 内容                |
| -------- | ----------------- |
| **编号**   | OPEN-001          |
| **技巧类型** | 开篇与结尾             |
| **来源**   | 头条-网文写作讲座 / 网文俱乐部 |
| **收录日期** | 2026-05-28        |
| **适用风格** | 通用                |
| **难度等级** | 入门                |

## 核心技巧

读者的耐心只有3章，编辑看投稿一般也只前三章。黄金三章法则要求：第一章抓眼球（开篇即写冲突），第二章深化设定（展开第一个冲突），第三章初露锋芒（给出明确故事方向）。三章内必须亮出核心卖点（金手指、功法体系、世界观特色）。

## 详细说明

### 第一章：抓眼球

**唯一目标**：抓住读者的眼球，让他舍不得划走。

**绝对不要写**：世界观、回忆、主角起床刷牙吃饭。

**正确写法**：开篇第一句就写冲突，让主角直接陷入绝境。

示例开头：

- "林晚睁开眼，发现自己正被人按在水里，耳边是继妹恶毒的声音：'姐姐，你就去死吧！'"
- "萧炎站在大厅中央，看着眼前那张写着'退婚'二字的纸，拳头攥得咯咯作响。"

**第一章结构要求**：

- 300字内必须出现主角
- 用1000字左右展开第一个冲突
- 章末留一个强力钩子

### 第二章：深化设定

- 展开第一个完整冲突
- 强化主角形象
- 让读者更了解主角的能力和性格

### 第三章：初露锋芒

- 给出明确的故事方向
- 让读者产生期待
- 亮出核心卖点（金手指、世界观特色）

**参考**：《诡秘之主》前3章通过"灰雾空间"和魔药设定，奠定克苏鲁+蒸汽朋克的独特风格。

### 开篇四种常见模式

**模式一：废柴逆袭**——主角是废柴→被欺凌→获得金手指→开始逆袭

**模式二：强者回归**——展现前世辉煌→意外重生→利用经验优势→重新崛起

**模式三：获得系统**——普通生活→获得系统→接受任务→走上强者之路

**模式四：穿越异界**——意外穿越→发现身份→适应环境→开始冒险

### 前3章的黄金法则速查

| 章节  | 核心任务 | 必须包含       |
| --- | ---- | ---------- |
| 第1章 | 抓眼球  | 冲突+主角+钩子   |
| 第2章 | 深化   | 展开冲突+强化形象  |
| 第3章 | 定方向  | 初露锋芒+亮核心卖点 |

## 适用场景

- **场景1**：新书开篇设计——对照此法则检查前三章
- **场景2**：改稿优化——前三章数据差，可能是开篇出了问题
- **场景3**：投稿前自检——编辑只会看前三章，确保每一章都有钩子

## 经典案例

**案例作品**：《斗破苍穹》- 天蚕土豆

第一章同时完成了：主角登场（萧炎）、冲突设置（三段斗之气，残酷现实）、钩子设置（纳兰嫣然退婚）。读者从第一段就被吸引，忍不住继续看下去。

## 常见误区

1. **前3000字写世界观**：读者还没对主角产生感情，不会关心你的世界有多宏大。
2. **主角迟迟不出现**：开篇写配角、写环境，主角第三章才出场——读者早跑了。
3. **第一章没有冲突**：主角吃了个饭、逛了个街、睡了个觉——读者不知道你想讲什么。
