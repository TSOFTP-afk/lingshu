# 使用指南

这是一套面向网文小说创作的知识库，分为两类内容：

- **参考知识库**：用于学习方法论、拆解题材、理解行业和平台。
- **可执行技能库**：用于让 AI 或作者按步骤直接产出片段、结构、钩子、改稿方案。

最有效的用法不是从头到尾通读，而是带着当前创作任务进入对应模块。

---

## 一、5分钟上手

1. 想开新书：先看 `01-情节构建`、`02-人物塑造`、`06-开篇与结尾`。
2. 正在写单章：优先用 `skills` 里的技能文档，尤其是 SKILL-001、SKILL-002、SKILL-004、SKILL-006、SKILL-012。
3. 觉得文章没爽点：看 `05-节奏控制`，再调用 SKILL-003、SKILL-013 至 SKILL-020。
4. 觉得文字有 AI 味：看 `10-风格流派/其他/MISC-003-去AI模板化全体系解决方案.md`，再调用 SKILL-010。
5. 准备发布或选平台：看 `12-商业与发布` 和 `10-风格流派/其他` 中的行业趋势文档。

## 二、从构思到发布的推荐流程

| 阶段 | 目标 | 推荐文档 | 产出物 |
|------|------|----------|--------|
| 1. 卖点定位 | 确定读者为什么点开 | PLOT-002、PLOT-005、MISC-005 | 一句话卖点、核心爽感 |
| 2. 主角设计 | 让主角有功能、有缺陷、有成长 | CHAR-001、CHAR-002、CHAR-003 | 主角人设卡 |
| 3. 世界与规则 | 建立故事可持续运转的底层逻辑 | WRLD-001、WRLD-002 | 世界观规则表 |
| 4. 全书骨架 | 避免写到中期散掉 | PLOT-001、HABT-003 | 三幕式大纲、十章单元 |
| 5. 开篇设计 | 前300字抓人，前三章留人 | OPEN-001、OPEN-002、SKILL-001 | 开篇段落、前三章钩子 |
| 6. 单章生产 | 每章有推进、有情绪、有钩子 | RYTH-001、RYTH-003、SKILL-002、SKILL-012 | 章节骨架和章末钩子 |
| 7. 中期维护 | 防止拖沓、忘伏笔、人设崩 | SUSP-002、HABT-002、HABT-004、SKILL-023 | 伏笔表、人物一致性检查 |
| 8. 改稿发布 | 去模板化，匹配平台与商业路径 | MISC-003、HABT-005、BIZ-001、BIZ-002 | 改稿清单、发布策略 |

## 三、AI调用技能的标准方式

使用 `skills` 目录里的文档时，建议按下面格式给 AI：

```text
请调用【SKILL-编号-技能名称】。

【输入】
主角/场景/困境/目标：……
已有正文或大纲：……
风格要求：……
限制条件：……

【输出要求】
严格按该技能的输出格式生成；
生成后按该技能的质量检验项自查；
如发现不合格，直接给出修订版。
```

如果需要组合技能，按“结构先行、文笔后置”的顺序：

```text
先用 SKILL-009 设计反转结构；
再用 SKILL-011 安排信息投放；
最后用 SKILL-004 和 SKILL-010 改写成有动作、有细节、低 AI 味的正文。
```

## 五、阅读建议

- 新手不要先读行业趋势，先把开篇、人物、节奏跑通。
- 老作者可以直接从问题索引进入，优先补短板。
- 写长篇时，每 10 章用 `HABT-004` 做一次自查，每 20 章用 `SUSP-002` 和 SKILL-023 检查伏笔。
- 用 AI 写作时，保留“人决定卖点、反转、情绪节点；AI辅助扩写和检查”的分工。
