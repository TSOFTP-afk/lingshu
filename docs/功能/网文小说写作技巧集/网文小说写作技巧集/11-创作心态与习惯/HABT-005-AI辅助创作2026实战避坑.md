## 核心观点

2026年，AI辅助写作已经不是"要不要用"的问题，而是"怎么用才不被平台处罚、不被读者嫌弃"的问题。番茄小说刚处置了855个滥用AI的账号，各平台AI检测精度已达80%-99%。核心原则始终是：**人写骨架，AI填血肉——所有AI输出必须经过至少30%的人工深度改写。**

## 一、2026年AI辅助创作的三大禁区

### 禁区1：从零生成章节并直接发布

**为什么禁**：
- 2026年2月番茄一次性处置855个账号（"AI水文"批量生成）
- 平台检测精度80%-99%——纯AI输出的识别率极高
- 直接复制AI输出=平台处罚+读者差评+限流

**正确做法**：
- AI产生初稿→人工改写≥30%（至少每段落都有注入人的细节）
- 核心剧情/反转/伏笔必须全部由人控制

### 禁区2：用AI代替大纲设计

**为什么禁**：
- AI生成的大纲最常见的问题是"看似合理但完全无记忆点"
- 所有AI大纲本质上是统计平均——意味着你的书会和无数本书"撞车"

**正确做法**：
- 人设计"一句话卖点"（PLOT-005参考）
- 人设计核心反转和关键情感节点
- AI只负责细化填充（把"主角参加宗门大比"扩展为具体流程）

### 禁区3：不经改写直接复制AI的环境描写和对白

**为什么禁**：
- 2026年读者对AI味的敏感度已达历史新高
- AI环境描写="阳光透过树叶洒下光斑"+"微风拂过带来清香"——千篇一律
- AI对白=所有角色说话一个调

**正确做法**：
- AI环境描写→替换至少3个具体感官细节（参见STYL-001）
- AI对白→为每个角色注入独特的说话习惯（参见DIAL-004）

## 三、2026实测高效的AI工作流

### 流程一：日更加速流（适合日均4000-6000字的作者）

```
[人] 写200字章节骨架
  → 核心事件 + 情绪变化 + 章末钩子方向

[AI] 扩展为2000字初稿（严格使用禁用词清单）
  → 要求3版不同叙事角度的输出

[人] 从3版中选取最佳片段组合 + 深度改写（15分钟）
  → 感官注入 + 句式重构 + AI高频词替换 + 人味细节植入

[AI] 自动检查错别字和违规词（2分钟）

[人] 朗读检查 + 钩子确认（3分钟）
```

**总耗时**：约25分钟/章

### 流程二：拆书学习流（适合研究爆款规律的作者）

```
[人] 选定一本爆款书

[AI] 拆解前30章的关键数据
  → 每章的爽点位置、钩子类型、情绪曲线
  → 人物出场频率、对话占比、场景数量

[人] 分析AI拆解结果
  → 找出该书的"节奏模板"
  → 提取可供自己借鉴的3个技巧

[AI] 生成该书的"节奏蓝图"供参考
```

### 流程三：伏笔管理流（适合百万字长篇作者）

```
[人] 建立伏笔追踪Excel

[AI] 每10章扫描一次
  → 提取本章新埋的伏笔
  → 检查前文伏笔的回收到位情况
  → 标记超20章未被提及的"遗忘伏笔"

[人] 决定遗忘伏笔的处理：立即回收 or 正式删除
```

## 四、Prompt工程：2026年的进阶写法

### 4.1 基础Prompt已死

2024年那种"写一段玄幻小说"的模糊Prompt已经完全过时。2026年的有效Prompt必须具备以下要素：

**必备五要素**：
1. **角色约束**：具体人物的性格、当前状态
2. **场景约束**：具体场景、氛围要求
3. **风格约束**：禁用词清单（必加！）
4. **结构约束**：句长变化、节奏要求
5. **感官约束**：必须包含的具体感官细节数量

### 4.2 2026年的标杆Prompt模板

```
你是一位网文写手。请为以下场景生成2000字正文，严格遵守以下规则：

【角色】
主角：萧寒，26岁，表面温和内敛，内心偏执记仇。
  核心性格：护短但记仇，对敌人绝不留情。
  当前状态：刚经历背叛，情绪在愤怒和冷静之间摇摆。
  绝对不能说："我不是以前的XXX了"

【场景】
旧宅书房，深夜。主角在整理遗物时发现一封被藏了十年的信。

【禁用词清单】
- 不得使用：值得注意的是、在当今、发挥着重要作用、此外、总而言之
- 不得使用"首先……其次……最后……"的过渡
- 不得使用"不是……而是……"的煽情句式
- 不得使用"从……到……"的虚假范围句式

【风格要求】
- 短句占比≥30%（5-8词）
- 长句占比≤20%（30词以上）
- 每500字至少包含1个具体的感官细节（色/声/味/触）
- 章末必须留一个让读者无法停止翻页的钩子

【特别要求】
- 信的揭晓不能是"突然出现"的——用环境的某个变化暗示
- 主角的情绪变化从"烦躁→困惑→震惊→冰冷"四个层次递进
- 最后三句话让读者脊背发凉
```

### 4.3 最容易被忽略的Prompt技巧

**1. "先写烂的再改好"**

Prompt：先给我一个粗糙的、不完美的初稿。不要在乎语法和过渡，用最快的速度把场景用最口语化的语言讲出来。

→ 这种"去精致化"反而能得到更接近人类思维流动的文本

**2. "喂一段你自己的文字"**

> Prompt开头：以下是我的写作风格示例：\[粘贴300-500字你自己的小说\]。请以上述风格生成以下场景……

→ 这个简单步骤能消除80%的AI味——AI有具体样本可以模仿，不会默认平均化

**3. "禁止AI知道答案"**

如果你的小说中有谜团：
> Prompt：在写这段的时候，你必须假设你不知道凶手是谁。不要给任何暗示。

→ 这能防止AI"作弊"——提前泄露信息

## 六、AI辅助写作的核心纪律

1. **永远不要在Prompt里说"写一章小说"**——每次都用具体的五要素Prompt
2. **所有AI输出必须朗读一遍**——耳朵比眼睛更早发现AI味
3. **核心反转和伏笔绝不能交给AI**——这是你作品独一无二的地方
4. **每章AI辅助比例不超过70%**——至少30%的内容是你"人写的"
5. **建立个人的AI高频词黑名单**——每次Prompt都带上
6. **不要用同一个Prompt模板连续写超过5章**——风格重复会被检测
