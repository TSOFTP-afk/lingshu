| 字段 | 内容 |
|------|------|

| **技巧类型** | 创作心态与习惯 |
| **来源** | 综合整理 |

| **适用风格** | 通用 |
| **难度等级** | 入门 |

## 核心技巧

写完一章不是结束——自查优化才是。这套检测表覆盖七个维度：节奏（爽点有无？钩子有无？）、文字（通顺与否？废话有无？）、逻辑（行为合理？前后矛盾？）、对白（能分得出谁在说话？）、场景（是否超过3个？）、情感（有没有让读者"感受到"而非"被告知"？）、进阶（本章删掉影响主线吗？）。每章写完花5分钟逐项自检，日积月累就是质的飞跃。

## 详细说明

### 一、节奏检测（最重要）

- [ ] 本章有爽点吗？没有的话——合并到下一章或加一个小爽点
- [ ] 章末有钩子吗？——无论大小，必须有
- [ ] 爽点来临前有至少1层铺垫吗？
- [ ] 本章节奏是否合理？——打斗场景是否太密？日常场景是否太拖？
- [ ] 读者看完本章会不会想"然后呢？"——如果不会，缺钩子

### 二、文字检测

- [ ] 一句话最长不超过50字（超过就拆）
- [ ] 有没有"他觉得""他看到""他感到"这种多余词汇？——能删就删
- [ ] 同一个意思有没有反复说？（删除重复句）
- [ ] 动词有没有雷同？（一页用了8个"说"？换掉5个）
- [ ] 有没有写成"他很XX"？（把"他很生气"改成"他猛地把杯子摔在地上"）

### 三、逻辑检测

- [ ] 角色的行为符合他的人设吗？（对照人设卡）
- [ ] 事件的前因后果能说通吗？（不能是"因为剧情需要"）
- [ ] 本章和前文有矛盾吗？（比如前文说主角没钱，本章突然坐豪车）
- [ ] 时间线合理吗？（不能"刚吃早饭→下一段就吃晚饭"，中间发生了什么？）

### 四、对白检测

- [ ] 去掉所有"XXX说"标签，光看引号里的内容——能分得出谁在说话吗？
- [ ] 每句对话都有目的吗？（如果某句删了完全不影响剧情——它就是废话）
- [ ] 对话有没有潜台词？（不是每句都必须有，但关键对话必须有）
- [ ] 连续纯对话超过5段了吗？（超过就插入动作/环境描写）

### 五、场景检测

- [ ] 本章场景不超过3个（超过则考虑合并）
- [ ] 每个场景切换有明确信号吗？（读者不会"咦刚才不是在A吗怎么跳到B了"）
- [ ] 环境描写服务于情绪/剧情了吗？（还是纯粹凑字数？）

### 六、情感检测

- [ ] 角色的情绪是"展示"出来的还是"告诉"出来的？
- [ ] 有没有写了"他很感动"这种犯规句式？
- [ ] 情感转折有没有铺垫？（不能上一段还在笑，下一段突然大哭）
- [ ] 压抑-释放的比例是否合理？（3:1到5:1）

### 七、进阶检测（写完10章后做）

- [ ] 如果删掉本章，对主线有影响吗？（完全没影响=可有可无=该删）
- [ ] 本章和前后两章的衔接流畅吗？
- [ ] 有没有为后续埋下伏笔？（不需要每章都有，但每3-5章至少埋一个）
- [ ] 主角在本章有没有可感知的收获？（实力/资源/信息/关系，至少一项）

## 适用场景

- **场景1**：每章写完后的5分钟快速自查
- **场景2**：改稿时逐项对比优化
- **场景3**：别人的作品拆解——逐项打勾看哪些做到了

## 练习建议

打印出这份清单贴在电脑旁边，每写完一章逐项打勾。坚持一个月，形成肌肉记忆后质量自然提升。
