## 核心技巧

玄幻修炼体系的设计需要三个核心要素：清晰的境界划分（含晋级条件、实力表现、寿命变化）、合理的能量体系（灵石、天地灵气等经济系统）、明确的社会制度（宗门、家族、散修等势力分布）。每个境界必须量化差异，让读者能直观理解战力层级。

## 详细说明

### 一、境界划分体系

**凡人阶段（炼体）**：
1. 淬体期（1-9层）→ 身体强化
2. 炼气期（1-9层）→ 灵力初现
3. 筑基期（初/中/后/大圆满）→ 根基牢固
4. 金丹期（初/中/后/大圆满）→ 凝结金丹，可飞行，寿命500年
5. 元婴期（初/中/后/大圆满）→ 元婴离体，第二条命

**修士阶段（悟道）**：
6. 化神期 → 神识蜕变
7. 炼虚期 → 掌控虚空之力
8. 合体期 → 肉身与天地合一
9. 大乘期 → 半步仙人
10. 渡劫期（一劫至九劫）→ 历经天劫

**仙人阶段（超脱）**：
11. 散仙 → 真仙 → 玄仙 → 金仙 → 太乙金仙 → 大罗金仙
12. 准圣 → 圣人 → 天道圣人 → 混元圣人

### 二、每个境界的设计要素

为每个境界明确以下内容：
- **晋级条件**：修为积累 + 感悟领悟 + 机缘造化 + 渡劫考验
- **实力表现**：能做什么、不能做什么
- **寿命变化**：筑基200年→金丹500年→元婴1000年→化神2000年→……
- **数量分布**：越往上人越少，形成金字塔结构
- **社会地位**：如金丹期即可开宗立派

### 三、能量体系

**灵石体系（经济基础）**：
- 下品灵石 = 1单位
- 中品灵石 = 100下品灵石
- 上品灵石 = 100中品灵石
- 极品灵石 = 100上品灵石
- 仙晶 = 100极品灵石

**修为积累量化**：让读者能直观感受差距。

### 四、势力分布

**正道势力**：仙门宗派（剑宗、丹阁等）、修真家族、正道联盟
**魔道势力**：魔宗、魔域
**妖族势力**：圣地（青丘、昆仑）、妖王势力（龙族、凤族）
**散修联盟**：佣兵公会、商会

### 五、关键设计原则

1. **越级挑战有上限**：一般不超过2个大境界
2. **初期/中期/后期/大圆满**：区分同一境界内的差异
3. **主角特权**：可以越级但要有限度，且原因必须合理（金手指、特殊功法）

## 适用场景

- **场景1**：开玄幻/仙侠新书，需要一套自洽的修炼体系
- **场景2**：写到中期战力崩塌，用此框架重新校准
- **场景3**：设计"换地图"节奏时，用境界体系锚定新世界的战力基线

## 经典案例

**案例作品**：《凡人修仙传》- 忘语

凡人流的境界划分极为清晰：炼气→筑基→结丹→元婴→化神→炼虚→合体→大乘→渡劫。每个境界都有明确的实力差距和突破资源需求，韩立每次突破都需经历漫长积累和机缘，让升级具有极强的真实性。

## 常见误区

1. **境界太多**：超过15级读者记不住，10-13级最合适。
2. **战力通货膨胀**：前期说筑基是高手，后期筑基多如狗。宁可换地图，也不要随意拔高原有地图的战力。
3. **突破太随便**：主角吃个丹药就突破，缺乏积累感和仪式感。
