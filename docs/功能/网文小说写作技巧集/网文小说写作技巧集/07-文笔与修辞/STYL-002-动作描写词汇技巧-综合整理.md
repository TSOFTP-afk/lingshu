## 核心技巧

动作是人物性格的延伸，避免单一动词（如"走""拿""看""说"），需结合力度、状态、目的选择词汇。核心方法：日常动作区分化（不同性格/情绪的人做同一动作完全不同）、冲突动作层次化（从试探到爆发逐步升级）、细节动作心理化（用微小动作暗示内心状态）。

## 详细说明

### 一、日常动作的词汇升级

**不要只用"走"——根据人物状态选择**：

- 趔趄（失衡）、逡巡（犹豫）、疾掠（慌张）、信步（从容）
- 拖着脚步（疲惫）、大步流星（自信）、踮脚（偷偷）、踱步（思考）

**不要只用"拿"——根据方式选择**：

- 攥住（带情绪）、捻起（轻缓）、抄起（急躁）、托举（郑重）
- 一把抓过（急迫）、轻轻拈起（小心）、劈手夺走（暴力）

**不要只用"看"——根据视线选择**：

- 瞥了一眼（漫不经心）、凝望（深情/深思）、扫视（警惕）
- 目光飘了过去（心虚）、视线死死钉在（愤怒）、余光追着（在意）

### 二、冲突动作的层次

**打斗描写从弱到强四个层次**：

| 层次 | 动作特点      | 描述词库           |
| -- | --------- | -------------- |
| 试探 | 轻微动作，观察反应 | 虚晃、游走、试探性地     |
| 交锋 | 正式开打，你来我往 | 格挡、闪避、回击、掣出    |
| 压制 | 一方逐渐占据上风  | 掼倒、碾压、逼退、重创    |
| 终结 | 决定胜负的动作   | 一击贯穿、轰然倒地、尘埃落定 |

**示例**：
拙劣："两人打了起来，最后主角赢了。"
优秀："他虚晃一拳，等对方重心偏移的瞬间，膝盖猛地顶入对方腹部，顺势将人掼倒在地。整个过程不超过三秒。"

### 三、细节动作——以小见大

微小动作暗示心理状态，这是最需要积累的能力：

| 心理状态 | 动作细节                |
| ---- | ------------------- |
| 焦虑   | 指节叩击桌面三次，节奏一次比一次快   |
| 不安   | 把围巾缠了两圈又松开，反复数次     |
| 愤怒   | 指甲掐进掌心，留下月牙形的白印     |
| 犹豫   | 手指悬在门铃上方的三厘米处，迟迟按不下 |
| 心虚   | 眼神飘向他身后那扇窗，就是不看他    |
| 期待   | 脚尖不自觉地来回点地          |

### 四、用动作代替"说"——对话提示语升级

拙劣："他生气地说""她温柔地说"

改法——把提示语换成动作：

- 他把茶杯往桌上一顿："这事没得谈！"（烦躁）
- 指尖绞着衣角，声音发颤："我……我没做过。"（怯懦）
- 她捻灭烟头，冷笑从齿缝里钻出来："你才知道？"（嘲讽）
- 他抬头，目光直直地逼过来："你在骗我。"（压迫感）

## 适用场景

- **场景1**：打斗场景——用层次化动作让战斗有节奏
- **场景2**：情感冲突——用细节动作放大情绪
- **场景3**：日常场景——用日常动作展现人物性格

## 经典案例

**案例作品**：《水浒传》- 施耐庵

鲁智深倒拔垂杨柳——一个"倒拔"动作，比任何性格描述都更能说明他是怎样的人。

## 常见误区

1. **动词雷同**：一页用了8个"说"、6个"走"、5个"看"——读者会产生疲劳。
2. **动作过于华丽**：普通人物的动作写得像武林高手——不合人物身份。
3. **只有动作没有节奏**：打斗场景动作密集无间歇——读者无法呼吸。
