## 核心技巧

网文句式追求的是顺、快、代入感强。核心方法：长句拆短句（一句话不超过50字）、复杂句拆主干+补充、抽象概念转化为具体画面、解释说明转化为动作展示。能用动作表现就少用空泛说明。

## 详细说明

### 一、格式：把拥挤的长句拆成清晰的短句

**技巧1：学会"断句"**

按动作变化、视线变化、情绪变化来停一下，把重要信息单独放出来。

改前：他推开门之后看到客厅里一片狼藉地上到处都是碎玻璃而母亲坐在沙发边低着头一动不动他心里一下就慌了。

改后：他推开门，客厅一片狼藉，地上全是碎玻璃。母亲坐在沙发边，低着头，一动不动。那一瞬间，他心里猛地一慌。

**技巧2：学会"拆句"**

先写最重要的动作，再补人物的心理、原因和状态。拆开后轻重更清楚。

改前：她在看见走廊尽头那扇本该锁着的门竟然半掩着之后，呼吸一下就停住了，站在原地不敢继续往前走，脑子里飞快闪过昨晚听到的那些传言，越想越觉得后背发凉。

改后：她猛地停下脚步，盯住了走廊尽头那扇门。门竟然是半掩着的。她一时没敢再往前走。昨晚听来的那些传言，忽然全涌了上来。

### 二、内容：用简练的语言写出画面

**技巧3：把解释转化为画面或动作**

凡是想告诉读者"他是个什么样的人""他现在是什么感受"，优先考虑用动作表现。

改前：他现在非常生气，因为他觉得自己被羞辱了，所以整个人的情绪都很不好。

改后：他下颌绷紧，手背上的青筋一点点鼓了起来。那句讽刺还在耳边打转，他紧紧盯着对方，一个字都没回。

**技巧4：把抽象概括转化为具体细节**

只有把形容词换成具体细节，读者才会有代入感。

改前：这是一间很破旧的屋子，生活条件很差。

改后：墙皮一块块往下掉，窗框发黑，桌角缺了口，床边那盏灯亮一下灭一下，屋里还飘着一股潮湿的霉味。

**技巧5：将繁复措辞转化为简洁表达**

删除重复描述，合并同类信息，提取最核心意思。

### 三、句式快速自查清单

| 检查项 | 标准 |
|--------|------|
| 句子长度 | 一句话不超过50字 |
| 信息密度 | 一句话只传达一个核心信息 |
| 画面感 | 能用具体细节就不要用抽象形容词 |
| 情绪表达 | 能用动作展示就不要直接说"他很生气" |
| 节奏 | 短句加速，长句减速，按需切换 |

## 适用场景

- **场景1**：写完一章后做句式优化
- **场景2**：描写打斗、紧张场景时用短句加速
- **场景3**：描写环境、情感时用具体细节替代空洞形容词

## 经典案例

**案例作品**：《三体》- 刘慈欣

"不要回答！不要回答！！不要回答！！！"

极简的短句，重复三次，没有多余的描写，却营造出宇宙级的紧张感。这就是短句的力量。

## 常见误区

1. **一句话塞进太多信息**：读者理解成本高，读到一半就想跳过。
2. **喜欢先解释再叙述**：导致画面感弱，读者无法"看到"场景。
3. **同一个意思反复说**：句子啰嗦，读者觉得你在水字数。
