# 10章一个小单元的工业化写作流程

## 基本信息

| 字段       | 内容               |
| -------- | ---------------- |
| **编号**   | RYTH-003         |
| **技巧类型** | 节奏控制             |
| **来源**   | 头条-2026网文工业化写作流程 |
| **收录日期** | 2026-05-28       |
| **适用风格** | 通用               |
| **难度等级** | 进阶               |

## 核心技巧

将百万字长篇拆解成一个个10章的小战役，每个小单元遵循固定循环：冲突爆发（1-3章）→ 压力升级（4-6章）→ 反转铺垫（7-9章）→ 爽点爆发+钩子（第10章）。每一章（2000-3000字）内部也有固定结构：抛矛盾→拉仇恨→主角出手→全场震惊→留钩子。

## 详细说明

### 一、10章单元循环

| 阶段        | 章节    | 核心任务             |
| --------- | ----- | ---------------- |
| 冲突爆发      | 第1-3章 | 被退婚、被追杀、被陷害等事件触发 |
| 压力升级      | 第4-6章 | 对手更强、误会加深、困难翻倍   |
| 反转铺垫      | 第7-9章 | 获得新线索、技能升级、找到突破口 |
| 爽点爆发 + 钩子 | 第10章  | 打脸成功，同时留下新危机钩子   |

### 二、每章万能公式（2500字）

| 段落   | 字数     | 内容                | 要点     |
| ---- | ------ | ----------------- | ------ |
| 抛矛盾  | 前300字  | 承接上章钩子，或抛出新矛盾     | 忌大段回忆  |
| 拉仇恨  | 中间800字 | 通过对话或行动让读者更讨厌反派   | 制造情绪积累 |
| 主角出手 | 中间800字 | 金手指发动/智商碾压/武力爆发   | 这是爽点核心 |
| 全场震惊 | 后300字  | 配角震惊/反派恐惧/美女倾心    | 爽点的反馈  |
| 留钩子  | 最后100字 | 有人推门而入/电话响起/发现新线索 | 无钩子不爆款 |

### 三、大纲不是摆设，是救命绳

**三个必要准备**：

1. **一句话卖点（核心梗）**
   格式：谁（主角）+ 陷入什么死局 + 靠什么翻盘 + 最后爽到什么程度
   示例：普通人被卷入死亡游戏，靠高智商逻辑破局，最终成为规则制定者。
2. **三幕式骨架**（见三幕式结构文档）
3. **人设卡（主角三要素）**

- 目标：必须明确且具体（复仇、变强、活下去），忌模糊
- 缺陷：必须有缺陷（冲动、心软、贪财），完美主角没有成长空间
- 金手指：必须有限制（系统能量耗尽、技能冷却时间），无限制必然战力崩塌

### 四、长篇避坑指南

| 坑        | 表现              | 解法                              |
| -------- | --------------- | ------------------------------- |
| **战力崩塌** | 前期筑基是高手，后期筑基多如狗 | 开书前设定完整境界体系，严格限制每个境界实力上限        |
| **人设坍塌** | 前期杀伐果断，后期圣母心泛滥  | 建立"人设卡"记录核心性格，每次重大决策对照检查        |
| **伏笔不填** | 前期埋太多坑，写到后面自己忘了 | 建立"伏笔追踪表"（Excel），记录章节、内容、预计揭晓时间 |
| **支线跑偏** | 被有趣配角带跑，主线被搁置   | 写之前问：这条支线删掉会影响主线吗？不会就砍掉         |
| **对话注水** | 用大量对话交代剧情、解释设定  | 对话服务于冲突，表面聊A话题，实际试探/对抗B真相       |

### 五、伏笔管理建议

每10万字埋不超过5个主要伏笔，用Excel追踪：

- 伏笔出现的章节
- 伏笔内容
- 预计揭晓章节
- 是否已回收

## 适用场景

- **场景1**：写长篇时防止中途崩盘
- **场景2**：卡文时按单元公式推进下一个10章
- **场景3**：改稿时检测节奏是否合理

## 经典案例

**案例作品**：《凡人修仙传》- 忘语

每个副本（地图）都是一个完整的单元循环，韩立在每个单元中遵循"遇到危机→积累资源→突破瓶颈→击败敌人→获得收益"的循环，让百万字长篇始终有节奏感。

## 常见误区

1. **不会换地图**：在一个地图待太久，读者腻了。建议每30-50万字换地图。
2. **单元之间无关联**：每个单元应该推进主线，不能是毫无关联的独立故事。
3. **钩子忘留**：单元结尾不设钩子，读者高潮后就退出了。
